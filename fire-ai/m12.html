12 AI 브라우저 Aside

모듈 12 (심화 5). AI 브라우저 Aside로 웹 업무 자동화

모듈 11에서 AI 에이전트(Claude Code)가 파일과 코드를 고치고 배포하는 것을 봤습니다. 이번에는 AI가 웹 브라우저를 직접 조작해서 사람이 하던 클릭·입력·내려받기를 대신하는 모습을 봅니다.

두 에이전트 비교

Claude Code (모듈 11) Aside (이번 모듈)
무엇을 조작하나 저장소의 파일·코드 웹사이트 화면 (클릭, 입력, 내려받기)
어디서 일하나 클라우드의 작업 공간 내 PC의 브라우저 (로그인해 둔 사이트 그대로)
잘 맞는 일 기능 추가, 수정, 시험, 커밋·배포 여러 사이트를 오가는 반복 업무, 정기 확인, 자료 내려받기
사람이 하는 일 변경 내용 검토, 미리보기 확인 민감한 동작(결제·게시·메시지 보내기) 승인, 결과 확인

핵심은 모듈 11과 같습니다. AI가 하고, 사람이 승인하고 확인합니다.

Aside 한눈에 보기

  • AI 에이전트가 들어 있는 크롬 계열 브라우저입니다. Mac과 Windows(2026년 9월부터)에서 쓸 수 있습니다.
  • 내가 로그인해 둔 사이트에서 사람처럼 화면을 보고 클릭·입력합니다. 사이트마다 따로 연결 설정을 하지 않아도 됩니다.
  • 루틴(Routine): 정해 둔 일을 반복해서 하게 할 수 있습니다. "매일 아침 ○○ 확인" 같은 자동화에 씁니다.
  • 보안 장치: 작업 기록과 기억은 내 PC에 저장하고, 내장 비밀번호 관리자는 비밀번호를 AI 모델에 보여 주지 않고 로그인합니다. 결제·게시·메시지 보내기 같은 민감한 동작은 사람의 승인을 기다립니다.
  • 요금: 무료 요금제(월 500크레딧, 루틴 3개), 유료 Pro(월 20달러), Max(월 200달러)

시연 (20분)

시연 소재는 우리가 만든 강의평가 화면입니다. 실제 업무 사이트 대신, 모듈 09에서 배포한 강의평가 주소를 쓰면 보안 걱정 없이 보여 줄 수 있습니다.

시연 1. 한 번 시키기

Aside의 에이전트 창에 입력:

https://(내 강의평가 주소).vercel.app 을 열고
과목 "시연과목", 교관 "시연교관"으로 만족도 5, 3, 2 평가를 차례로 제출해 줘.
그다음 결과표에서 "개선 필요"로 표시된 과목과 교관, 평균을 모두 알려 주고,
결과 내려받기 버튼을 눌러 파일을 저장한 뒤 파일 이름을 알려 줘.

교육생이 볼 것:

  • AI가 화면을 보고 입력칸을 찾아 글자를 넣고, 만족도를 고르고, 버튼을 누르는 모습
  • 중간에 허락을 묻는 단계가 나오면 무엇을 하려는지 읽고 승인하는 강사
  • 마지막 보고가 실제 화면과 같은지 확인하는 강사 (시연과목 평균 3.3 → 개선 필요, 파일 이름)

시연 2. 루틴으로 만들기 (자동화)

평가 기간(9월 28일~10월 2일) 동안 매일 오후 4시에 강의평가 주소를 열어서
전체 응답 수와 "개선 필요" 과목·교관 목록을 확인하고, 결과를 세 줄로 정리해 줘.

이 지시가 루틴이 되면 담당자가 매일 열어 볼 필요가 없습니다. 응답이 적은 날은 참여 독려 문자(모듈 3의 안내문)를 보낼 때를 알려 주는 셈입니다. 모듈 6의 스킬이 "일하는 방법"을 적어 둔 것이라면, 루틴은 "언제 할지"까지 정해 둔 것입니다.

행정 업무에 쓸 때의 기준

질문 기준
어떤 사이트에서 써도 되나? 기관 규정이 허용한 곳만. 내부 업무 시스템, 개인정보가 있는 화면은 기본적으로 쓰지 않음
어떤 일을 맡기나? 공개 정보 확인, 내가 만든 도구 점검처럼 틀려도 되돌릴 수 있는 일부터
승인은 누가? 결제·게시·메시지 보내기·삭제는 반드시 사람이 승인
결과는 믿어도 되나? AI의 보고와 실제 화면을 대조. 숫자는 직접 확인

숙제 (개인 PC, 선택)

  1. 개인 PC에 Aside 설치 (공식 사이트 aside.com)
  2. 무료 요금제로 시연 1을 내 강의평가 주소로 따라 해 보기
  3. 내 업무 중 "매일 같은 사이트를 열어 같은 것을 확인하는 일" 하나를 적어 오기. 다음 시간에 루틴으로 만들 수 있을지, 규정상 맡겨도 되는 일인지 함께 따져 봅니다

✅ 확인 질문 (인터뷰)

  1. Claude Code와 Aside는 각각 무엇을 조작하나요?
  2. Aside에게 일을 맡길 때도 사람이 꼭 하는 두 가지는?
  3. 내 업무 중 브라우저 에이전트에게 맡기면 안 되는 일은 무엇일까요? 이유는?
