02 ChatGPT · Claude · GitHub 가입

모듈 2. ChatGPT · Claude · GitHub 가입하기

🎯 이 모듈에서 만들 것: 수업에서 쓸 계정 3개 — ChatGPT, Claude(Team), GitHub

🤔 생각해 보기: ChatGPT와 GitHub은 직접 가입하는데, Claude는 왜 "초대를 수락"할까요? (답은 아래 2-2에 있습니다. 점수 없음)

📌 사전 과제 모듈입니다. 수업 시간에는 다루지 않으니 수업 전에 이 페이지를 보며 혼자 따라 해 주세요. 막히면 첫날 수업 시작 전에 물어보세요.

한눈에 보기: 가입 2개, 수락 1개

Claude 📩 초대 메일 수락 (이미 가입했어도 수락) **11. 4.(수)**까지 왼쪽 아래에 기관 Team 이름이 보인다 2-2
GitHub ✍️ 직접 가입 교육 시작 전날까지 프로필에 내 Username이 보인다 2-3

  • Claude 초대 수락 완료 (Team 이름 확인)
  • GitHub 가입 완료 (Username 적어 둠)

💡 Claude는 따로 가입하지 않아도 됩니다. 초대 메일의 [초대 수락] 을 누르면 바로 쓸 수 있습니다. 이미 Claude를 쓰고 있던 분도 괜찮습니다. 같은 이메일이면 쓰던 계정에 기관 Team이 더해지고, 왼쪽 아래 프로필 메뉴에서 개인 ↔ Team을 골라 씁니다. 다른 이메일로 가입했던 분은 신청 때 적은 업무 계정으로 로그인해야 Team이 보입니다.

모든 가입은 "업무" Chrome 프로필 창에서 진행합니다. 세 서비스 모두 "Google로 계속하기" 를 쓰면 비밀번호를 새로 만들 필요가 없습니다.

2-1. ChatGPT: 직접 가입 (약 5분, 교육 시작 전날까지)

  1. 주소창에 chatgpt.com 입력
  2. [회원 가입] (또는 Sign up) 클릭
  3. [Google로 계속하기] → "업무" 계정 선택 → [계속]
  4. 이름, 생년월일 등 기본 정보 입력 → [동의]
  5. 처음 나오는 안내 창은 읽고 [확인] 또는 [다음]

✅ 성공 확인: 가운데에 "무엇을 도와드릴까요?" 같은 입력창이 보이면 완료

화면 둘러보기

  • 가운데 입력창: 질문 입력. 왼쪽의 [+] 버튼으로 파일 첨부
  • 왼쪽 사이드바: 지난 대화 목록, 새 채팅, 프로젝트
  • 오른쪽 위/왼쪽 아래 프로필: 설정 → 언어, 개인 맞춤 설정

2-2. Claude: 초대 수락 (약 5분)

이 과정은 기관이 준비한 Claude Team(유료) 계정을 씁니다. 따로 가입할 필요 없이 초대를 수락합니다. 이미 Claude를 쓰던 분도 똑같이 수락하면 됩니다.

  1. 교육 신청 때 부서에 알린 업무 구글 계정 이메일로 초대가 갑니다
  2. 그 메일함으로 Claude(Anthropic) 초대 메일이 옵니다 → [초대 수락] (Accept invite). 초대 메일은 11. 2.(월)~4.(수) 중에 오고, 11. 4.(수)까지 수락합니다
    • 📱 휴대폰에서 하세요. 기관 PC(행정망)에서는 Gmail이 열리지 않습니다. 휴대폰 Gmail 앱에 업무 계정을 추가하거나(Gmail 앱 → 오른쪽 위 프로필 → 다른 계정 추가), 휴대폰 인터넷 창에서 gmail.com 에 업무 계정으로 로그인해 메일을 엽니다. 집 PC에서 해도 됩니다
    • 휴대폰에서 한 번 수락해 두면, 수업 날 강의장 PC에서는 claude.ai → [Google로 계속하기] → 같은 업무 계정만 고르면 Team 화면이 바로 나옵니다
  3. [Google로 계속하기] → 초대받은 그 "업무" 계정 선택
  4. 처음이면 이름(부르는 이름) 입력, 약관 동의 (이미 쓰던 분은 건너뜀). 화면에 따라 휴대폰 번호 인증이 나올 수 있습니다

✅ 성공 확인: 왼쪽 아래 프로필에 기관 Team 이름이 보이고, 가운데 입력창이 보이면 완료

⚠️ 초대받지 않은 다른 구글 계정으로 로그인하면 무료 개인 화면이 나옵니다. 이미 개인 Claude 계정이 있던 분은 왼쪽 아래 프로필 메뉴에서 Team 쪽을 골라 주세요. 초대 메일이 안 보이면 스팸함·프로모션함을 확인하고, 그래도 없으면 담당자에게 다시 보내 달라고 하세요.

화면 둘러보기

  • 입력창의 [+] 버튼: 파일·사진 첨부
  • 왼쪽 사이드바: 대화 목록(Chats), 프로젝트(Projects)
  • 왼쪽 아래 프로필: 설정 → 언어, 개인 선호(답변 스타일)

2-3. GitHub: 직접 가입 (약 10분, 교육 시작 전날까지)

GitHub은 파일과 고친 기록을 보관하는 창고입니다. 2일차 오전에 Claude Code(AI)가 이 창고에 내 화면을 만들어 넣습니다(모듈 12). 지금은 가입만 해 두면 됩니다.

  1. 주소창에 github.com 입력 → [Sign up]
  2. [Continue with Google] → "업무" 계정 선택 (버튼이 없으면 업무 Gmail로 이메일 가입 → 메일로 온 8자리 인증 코드 입력)
  3. Username 정하기 → 퍼즐 인증 → 설문은 Skip → 요금제는 Free

✅ 성공 확인: 오른쪽 위 프로필 아이콘을 누르면 내 Username이 보이면 완료. Username을 수첩에 적어 두세요.

Gmail 주소 GitHub Username
쓸 수 있는 글자 영문 소문자, 숫자, 마침표(.) 영문, 숫자, 하이픈(-)
예시 hong.gildong.work hong-gildong

⚠️ GitHub은 마침표 대신 하이픈을 씁니다. 나중에 2단계 인증(2FA) 설정을 요구하면 인증 앱으로 설정하고 복구 코드는 따로 저장하세요.

정리하면

  • 무료로도 이 과정의 03~07(채팅, 프로젝트 5개, 스킬, 미리보기)은 대부분 해 볼 수 있습니다. 다만 사용량이 적어 실습이 몰리면 한도에 걸리기 쉽습니다.
  • Claude Code(12) 는 유료(Pro 이상)부터 됩니다.
  • Team 은 Pro 기능에 함께 쓰는 기능(프로젝트 공유, 스킬 일괄 배포)과 관리 기능이 더해진 것입니다. 기관 교육·부서 단위로 쓸 때 맞는 요금제입니다.

꼭 알아 둘 주의사항

  • AI는 틀릴 수 있습니다. 숫자, 법령, 날짜, 사람 이름은 반드시 원문으로 확인합니다.
  • 민감정보를 넣지 않습니다. 주민번호, 환자·민원인 정보, 내부 기밀 문서는 업로드 금지. 소속 기관의 AI 사용 지침이 있다면 그것이 우선입니다.
  • 설정에서 대화 내용을 모델 학습에 쓰지 않도록 하는 옵션이 있는지 함께 확인합니다. (메뉴 위치는 서비스 업데이트에 따라 바뀔 수 있습니다)
