# PRD: 구내식당 메뉴 만족도 집계 (프로토타입)

| 항목 | 내용 |
|---|---|
| 작성자 | 총무과 홍길동 (예시) |
| 작성일 | 2026-10-01 |
| 버전 | v0.1 (프로토타입) |
| 상태 | 초안 |

---

## 1. 배경·문제

- 구내식당 메뉴 만족도를 **매주 네이버 폼**으로 받는다. 응답은 잘 모이지만, 주간 결과보고에 넣을 **메뉴·식사별 평균표와 개선 필요 메뉴**는 담당자가 결과를 엑셀로 내려받아 다시 계산·정리한다.
- 한 주 메뉴가 20여 개, 이용자가 약 150명이라 엑셀에서 메뉴별로 나누고 평균을 내는 데 **매주 두세 시간**이 걸린다. 수식 범위를 잘못 잡아 틀리는 경우도 있다.
- 주마다 폼을 복사해 메뉴 이름을 고치는 일도 반복된다.
- 같은 메뉴가 **점심·저녁에 모두** 나오는 날이 있다 (조리 시간과 담당이 다름).
- 결과 정리가 늦어져 **다음 주 식단 조정**에 반영할 시간이 부족하다.

## 2. 목표

- 이용자가 만족도를 입력하면 **메뉴별 응답 수와 평균이 바로** 계산된다.
- 평균이 낮은 메뉴는 **"개선 필요"로 자동 표시**되어 주간 결과보고에 그대로 옮길 수 있다.
- 이번 프로토타입의 목표: **입력 → 집계 → 개선 필요 표시 흐름을 보여 주고 의견을 받는 것** (정식 시스템 아님)

## 3. 사용자

| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| 이용자 (교직원·교육생 약 150명) | 식사 후, 휴대폰으로 평가 | 빠르고 **익명으로** 평가하기 |
| 급식 담당자 (영양사) | 주간 결과보고, 다음 주 식단 조정 | 메뉴별 평균과 개선 필요 메뉴를 한눈에 보기 |

## 4. 핵심 기능

| 우선순위 | 기능 | 설명 |
|---|---|---|
| 필수 | 평가 입력 | 메뉴 이름과 만족도(1~5점)를 고르고 [평가 제출] |
| 필수 | 메뉴별 집계 | **메뉴별로** 응답 수와 평균(소수 첫째 자리)을 표로 보여 줌 |
| 필수 | 개선 필요 판정 | 평균 **3.5 미만**이면 "개선 필요", 그 이상은 "양호" |
| 필수 | 요약 숫자 | 전체 응답 수 / 평가 메뉴 수 / 개선 필요 메뉴 수 |
| 필수 | 점수 검사 | 1~5점이 아니거나 메뉴를 비우면 안내 문구를 보여 주고 막기 |
| 있으면 좋음 | 마지막 응답 취소 | 잘못 낸 마지막 응답 하나를 지우기 |
| 있으면 좋음 | 전체 초기화 | 다음 주 조사를 위해 전부 지우기 (실수 방지를 위해 두 번 눌러 확인) |

## 5. 화면·흐름

```
[화면 위] 조사 주차 · "평균 3.5 미만은 개선 필요로 표시" 안내
[요약]   응답 N | 평가 메뉴 N | 개선 필요 N
[입력]   메뉴 [__________]  만족도 [1~5 ▼] [평가 제출]
[결과표] 메뉴 | 응답 수 | 평균 | 양호/개선 필요   (평균이 낮은 메뉴부터)
```

1. 이용자가 메뉴 이름을 입력하고 만족도를 고른 뒤 [평가 제출]
2. 결과표에서 그 메뉴의 응답 수와 평균이 바로 바뀌고, 요약 숫자도 바뀜
3. 메뉴를 비우거나 만족도를 고르지 않으면 "메뉴와 만족도를 입력한 뒤 제출하세요." 안내
4. 처음 열었을 때는 **예시 응답**을 "(예시)" 표시와 함께 보여 줌

## 6. 범위 밖 (이번에 하지 않는 것)

- 로그인, 본인 확인 (익명 평가)
- **여러 기기 간 데이터 공유** — 기록은 각 브라우저에만 저장 (데이터베이스 연결은 2차)
- 한줄의견(서술형) 입력과 분석 — AI 요약 실습으로 따로 다룸
- 항목별(맛·양·온도·위생) 세부 평가
- 그래프, 엑셀 내보내기

## 7. 성공 기준

- [ ] 휴대폰 화면(폭 약 400px)에서 가로 스크롤 없이 모두 보인다
- [ ] 메뉴와 만족도를 고르고 버튼 한 번으로 결과표에 반영된다
- [ ] 평균 3.5 미만 메뉴는 "개선 필요"로 표시된다
- [ ] 1~5점이 아니거나 메뉴가 비어 있으면 제출되지 않고 안내 문구가 나온다
- [ ] 새로고침해도 기록이 남아 있다 (같은 브라우저)
- [ ] 급식 담당자(영양사)와 총무과 직원 3명에게 보여 주고 개선 의견을 받는다
