# PRD: 우리 가족 여행 준비물 체크 (프로토타입)

| 작성일 | 2026-10-20 |
| 버전 | v0.1 (프로토타입) |

---

## 1. 배경·문제

- 가을 주말에 **경주로 2박 3일** 가족 여행을 간다. 가족은 **나 · 배우자 · 아이(초등 3학년) · 할머니(75세)** 4명이고, 광주에서 자가용으로 간다.
- 준비물은 지금 **가족 단톡방**에 각자 생각나는 대로 올린다. 메시지가 쌓이면 무엇을 챙겼는지 아무도 모르고, 출발 날 아침마다 꼭 하나씩 빠진다.
- 지난 여행에서는 **아이 멀미약**을 빠뜨려 휴게소마다 멈췄다.
- 가족마다 챙길 것이 다르다. 할머니는 **혈압약·무릎 보호대·지팡이**, 아이는 **멀미약·여벌 옷**이 꼭 필요하다.
- 챙겼는지 확인하려고 출발 전날 밤 단톡방을 처음부터 다시 읽는다.

## 2. 목표

- 준비물을 **누구 것인지와 함께** 적어 두고, 챙기면 **체크 한 번**으로 표시한다.
- **가족별로** 챙김률이 바로 보이고, 덜 챙긴 사람은 **"서둘러요"** 로 표시된다.
- 이번 프로토타입의 목표: **적기 → 체크 → 가족별 챙김률 표시 흐름을 보여 주고 가족 의견을 받는 것** (정식 앱 아님)

## 3. 사용자

| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| 여행 담당 (나) | 출발 일주일 전부터 준비 | 누구 것이 빠졌는지 한눈에 보기 |
| 가족 | 출발 전날 짐 싸기 | 휴대폰으로 열어 바로 체크하기 |

## 4. 핵심 기능

| 우선순위 | 기능 | 설명 |
|---|---|---|
| 필수 | 준비물 추가 | 준비물 이름과 **누구 것**(가족 전체 / 나 / 배우자 / 아이 / 할머니)을 고르고 [추가] |
| 필수 | 챙김 체크 | 준비물마다 체크박스. 누르면 챙김 ↔ 아직 |
| 필수 | 가족별 집계 | **누구 것이 같은 준비물끼리** 전체·챙김·챙김률(%)을 표로 보여 줌 |
| 필수 | 상태 표시 | 챙김률 **50% 미만이면 "서둘러요"**, 50% 이상이면 "순조로움", 100%면 "다 챙김" |
| 필수 | 요약 숫자 | 전체 / 챙김 / 남은 것 |
| 필수 | 입력 검사 | 준비물 이름을 비우면 안내 문구를 보여 주고 막기 |
| 있으면 좋음 | 마지막 추가 취소 | 잘못 적은 마지막 준비물 하나를 지우기 |
| 있으면 좋음 | 전체 초기화 | 다음 여행을 위해 전부 지우기 (실수 방지를 위해 두 번 눌러 확인) |
| 있으면 좋음 | 목록 내려받기 | 준비물 목록을 CSV로 내려받기 (엑셀에서 열림) |

## 5. 화면·흐름

```
[화면 위] 우리 가족 경주 여행 준비물 · "챙김률 50% 미만은 서둘러요"
[요약]   전체 N | 챙김 N | 남은 것 N
[입력]   준비물 [__________]  누구 것 [가족 전체 ▼] [추가]
[가족별] 누구 | 전체 | 챙김 | 챙김률 | 상태   (챙김률이 낮은 사람부터)
[목록]   ☐ 준비물 이름 · 누구 것   (챙기지 않은 것부터)
```

1. 준비물 이름을 적고 누구 것인지 고른 뒤 [추가]
2. 목록에 한 줄이 생기고, 가족별 표와 요약 숫자가 바로 바뀜
3. 챙긴 준비물은 체크 → 그 사람의 챙김률이 올라감
4. 준비물 이름을 비우면 "준비물 이름을 적은 뒤 추가하세요." 안내
5. 처음 열었을 때는 **예시 준비물**을 "(예시)" 표시와 함께 보여 줌

## 6. 범위 밖 (이번에 하지 않는 것)

- 여행 일정·예산 관리 — 일정표는 AI 스킬로 따로 만듦
- 사진 첨부, 알림
- 인쇄

## 7. 성공 기준

- [ ] 휴대폰 화면(폭 약 400px)에서 가로 스크롤 없이 모두 보인다
- [ ] 준비물 이름과 누구 것을 고르고 버튼 한 번으로 목록에 추가된다
- [ ] 체크하면 챙김률이 바로 바뀌고, 50% 미만이면 "서둘러요"로 표시된다
- [ ] 준비물 이름이 비어 있으면 추가되지 않고 안내 문구가 나온다
- [ ] 새로고침해도 기록이 남아 있다 (같은 브라우저)
- [ ] **가족 전체로는 순조로워도, 덜 챙긴 사람은 따로 "서둘러요"로 보인다**
- [ ] 가족 3명에게 보여 주고 의견을 받는다
