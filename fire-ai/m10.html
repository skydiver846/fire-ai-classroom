모듈 10 (심화 2). 프로토타입을 웹에 공개하기 (GitHub + Vercel)

이 모듈 실습 파일

  • 강의평가 집계 완성본 (배포 실습용 index.html)내려받기 열어 보기

모듈 7에서 Claude로 만든 강의평가 집계 화면을 누구나 휴대폰으로 여는 웹 주소로 공개합니다. 설치 없이 웹 브라우저만으로, 비용 0원으로 진행합니다. 모든 작업은 파란 "업무" Chrome 프로필 창에서 합니다.

흐름과 낱말 4개

 index.html ──(올리기 = 커밋·푸시)──▶ GitHub 창고 ──(자동 연결)──▶ Vercel ──▶ https://내주소.vercel.app
 (내 컴퓨터)                           (기록·보관)                  (공개)     (누구나 접속)
낱말 한 줄 설명 비유
저장소 (Repository) 프로젝트 파일과 변경 기록을 담는 곳 프로젝트 상자
커밋 (Commit) 변경 내용을 메모와 함께 기록 저장 + 메모
푸시 (Push) 내 컴퓨터의 기록을 GitHub로 올림 택배 발송
배포 (Deploy) 웹 주소로 공개 가게 오픈

💡 웹 브라우저 방식에서는 GitHub 웹사이트에 파일을 올리는 순간 커밋과 푸시가 한 번에 일어납니다. 오늘은 "올리기 = 커밋 + 푸시"로 묶어 설명하고, Git 프로그램을 쓰면 둘이 나뉜다는 것만 한 줄로 예고합니다.

도구 하는 일 비유
GitHub 파일 보관 + 변경 기록. 고치는 곳 창고 + 변경 일지
Vercel GitHub의 파일을 웹 주소로 공개. 보여 주는 곳 진열대

0. 준비: index.html 파일 만들기 (5분)

웹사이트의 대문 파일 이름은 반드시 index.html 이어야 합니다.

방법 1: Claude에서 내려받기 (다운로드 버튼이 보이면)

  • 프로토타입 대화 → 미리보기 창 또는 코드 블록의 다운로드 → 파일 이름을 index.html 로 변경

방법 2: 메모장에 저장하기

  1. Claude 답변 코드 블록 오른쪽 위 복사 → 메모장에 Ctrl + V
  2. 파일 → 다른 이름으로 저장
    • 파일 이름: index.html
    • 파일 형식: 모든 파일 (*.*) ← 중요
    • 인코딩: UTF-8
  3. 저장 위치: 문서 > AI업무자료 > 03_AI결과물

✅ 저장한 파일을 더블클릭해 Chrome에서 강의평가 화면이 열리면 준비 완료

⚠️ 가장 흔한 실수: 파일 형식을 "텍스트 문서"로 두면 index.html.txt 가 됩니다. 파일 탐색기 [보기] → [파일 확장명] 을 켜 두세요. 인코딩이 UTF-8이 아니면 한글이 깨집니다.

1. GitHub 계정 만들기 (10분)

📌 사전 과제: 이 단계(GitHub 가입)는 3일차 수업 전에 미리 해 오세요. 수업에서는 로그인만 확인하고 2단계부터 시작합니다.

  1. github.com → [Sign up]
  2. [Continue with Google] → 업무 계정 선택 (버튼이 없으면 업무 Gmail로 이메일 가입 → 8자리 인증 코드)
  3. Username 정하기 → 퍼즐 인증 → 설문 Skip → 요금제 Free
  4. ✅ 오른쪽 위 프로필 아이콘을 누르면 내 Username이 보이면 완료

Username은 웹 주소에 그대로 들어갑니다: https://github.com/hong-gildong

Gmail 주소 GitHub Username
쓸 수 있는 글자 영문 소문자, 숫자, 마침표(.) 영문, 숫자, 하이픈(-)
예시 hong.gildong.work hong-gildong

⚠️ Gmail과 규칙이 다릅니다. GitHub은 마침표 대신 하이픈을 씁니다. 시간이 지나면 2단계 인증(2FA) 설정을 요구합니다. 인증 앱으로 설정하고 복구 코드는 반드시 따로 저장하게 하세요.

4. Vercel 계정 만들기 (3분)

  1. vercel.com → [Sign Up]
  2. 플랜: Hobby (개인 프로젝트, 무료)
  3. 이름 입력 → [Continue with GitHub] → [Authorize Vercel]
 Google 계정 ──▶ GitHub 가입   (모듈 1의 열쇠로)
 GitHub 계정 ──▶ Vercel 가입   (GitHub이 열쇠가 됨 → 처음부터 연결)

⚠️ Pro(유료)를 고르면 결제 정보 입력이 나옵니다. Hobby를 고르게 하세요. Hobby는 개인·비상업적 용도가 조건이므로, 기관의 정식 서비스로 운영할 때는 약관과 요금제를 따로 검토해야 합니다.

5. 배포하기 (5분)

  1. 대시보드 [Add New…] → [Project]
  2. Import Git Repository 목록에서 lecture-eval → [Import]
  3. 설정은 그대로 (Framework Preset: Other) → [Deploy]
  4. 1분 내외로 🎉 축하 화면 → [Continue to Dashboard]

목록에 저장소가 안 보이면 → 목록 아래 Adjust GitHub App Permissions (또는 [Install]) → Only select repositories → lecture-eval 선택 → 저장

📱 휴대폰으로 열기: QR 만들기

데스크톱 강의에서 QR은 자료 배포용이 아니라 배포한 강의평가 화면을 교육생 휴대폰으로 열어 평가해 보는 용도입니다. 링크를 PC끼리 나눌 때는 PC 메신저나 메일을 씁니다.

배포된 Domains 주소를 Chrome에서 연 상태에서:

방법 하는 법
① 오른쪽 클릭 페이지 빈 곳 오른쪽 클릭 → 이 페이지의 QR 코드 생성
② 메뉴 오른쪽 위 ⋮ → 전송, 저장, 공유 → QR 코드 만들기
  • 휴대폰 카메라로 찍으면 열립니다. [다운로드] 로 이미지 저장도 가능 (메뉴 이름은 Chrome 버전에 따라 다를 수 있음)
  • 교육생끼리 QR을 교환해 서로의 화면에 평가를 내 보게 하면 반응이 좋습니다

⚠️ Deployment 주소로 QR을 만들면 다른 사람 휴대폰에서 Vercel 로그인 화면이 뜰 수 있습니다. "QR은 Domains 주소로"를 꼭 짚어 주세요.

6. 수정 → 커밋 → 자동 재배포 (5분)

고치는 곳은 GitHub입니다. Vercel에는 편집 기능이 없습니다.

● Add files via upload              Ready                  10분 전

🎯 핵심: 커밋만 하면 배포는 자동입니다. Vercel 화면의 문장 "To update your Production Deployment, push to the main branch." 가 바로 이 뜻입니다. 고칠 때 <, >, " 같은 기호는 건드리지 말고 한글 글자만 바꾸게 하세요. 화면이 깨지면 Instant Rollback으로 이전 배포로 즉시 되돌리는 시연 기회로 씁니다.

⭐ Claude Code로 한 번 더 (선택): 손으로 제목을 고쳐 본 뒤, 같은 수정을 Claude Code(claude.ai/code)에게 말로 맡겨 봅니다. 예: "index.html의 제목을 제13기 강의평가 결과로 바꿔 줘". 자세한 방법은 12 Claude Code. 시간이 부족하면 모듈 12에서 한꺼번에 합니다.

7. 마무리: 장부는 공유되지 않는다

교육생끼리 서로의 QR로 평가를 낸 뒤 묻습니다. "짝꿍 휴대폰 결과표에 내가 낸 평가가 들어 있나요?" → 안 들어 있습니다. 응답 수가 늘지 않습니다. 기록이 각자의 브라우저에만 저장되기 때문입니다. 40명이 내면 결과가 40군데로 흩어집니다.

 지금:     [내 휴대폰 장부]   [짝꿍 휴대폰 장부]   ← 따로따로
 다음 회차: [내 휴대폰] ─┐
            [짝꿍 휴대폰] ┼──▶ 데이터베이스 (공용 장부)  ← 모두가 같은 결과표
            [담당자 PC] ─┘

다음 회차에서 Firebase(Google 서비스, 업무 Google 계정으로 시작)를 연결해 모든 응답이 한곳에 모이는 강의평가 시스템으로 만듭니다.
