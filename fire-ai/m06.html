06 스킬 만들기

모듈 6. 스킬 만들기: Markdown으로 쓰는 나만의 업무 매뉴얼

이 모듈 실습 파일

  • PRD 인터뷰 스킬 (Claude에 바로 올리는 ZIP)내려받기
  • PRD 인터뷰 스킬 원본 SKILL.md내려받기
  • 문제출제 의뢰서 (실습용 예시)내려받기
  • 교재 발췌: 연소와 소화의 기초 (실습용)내려받기
  • 객관식 문제카드 빈 양식 (별지 제4호서식)내려받기
  • 문제출제 스킬 (조직 배포가 안 됐을 때 개인 등록용 ZIP)내려받기

모듈 3에서 프롬프트, 파일, 프로젝트를 배웠고, 모듈 4에서 Markdown 파일을 만들었습니다. 그리고 모듈 5에서는 PRD 인터뷰를 받으려고 긴 프롬프트를 찾아 붙여넣었습니다. 다음에 또 기획할 때도 그 글을 다시 찾아야 합니다.

이번 모듈은 그 불편을 없앱니다. 자주 하는 일의 "방법"을 Markdown 파일로 적어 AI에게 맡기는 것, 이것이 스킬입니다. 첫 실습은 방금 쓴 PRD 인터뷰 프롬프트를 스킬로 바꾸는 것입니다.

AI에게 건네는 것의 단계

단계 무엇을 건네나 얼마나 오래 쓰나 비유 배운 곳
프롬프트 이번 지시 대화 한 번 구두 지시 모듈 3, 5
파일 건네기 참고 자료 대화 한 번 서류 첨부 모듈 3
프로젝트(폴더) 지침 + 자료 묶음 그 프로젝트 안에서 담당자 전용 서류함 모듈 3
스킬 일하는 방법 자체 어느 대화에서든. 필요할 때 AI가 알아서 꺼냄 업무 매뉴얼(SOP) 이번 모듈

이 과정의 진행 (Claude Team)

Team 계정이라 모두 스킬을 Claude에 등록해서 씁니다(6-3). 무료 계정에서 쓰는 대체 방법도 6-3 끝에 참고로 남겨 두었습니다. 회사 밖에서 무료 계정으로 쓸 때 기억해 두세요.

6-1. 스킬은 어떻게 생겼나 (10분)

스킬은 폴더 하나입니다. 그 안에 SKILL.md 라는 Markdown 파일이 꼭 있어야 합니다.

📁 prd-interview          ← 스킬 폴더 (이름 = 스킬 이름)
 └─ 📄 SKILL.md           ← 필수. 이름, 언제 쓰는지, 일하는 순서
 └─ 📄 (참고 파일들)       ← 선택. 양식, 예시 문서 등

SKILL.md 는 두 부분으로 되어 있습니다.

---
name: prd-interview
description: 사용자가 새 업무 도구를 기획하거나 "PRD 써 줘"라고 할 때 사용한다. ...
---

# PRD 인터뷰
1. 한 번에 질문은 1~2개만 한다.
2. ...
부분 무엇을 쓰나 규칙
위쪽 --- 사이 (속성) name: 스킬 이름 영문 소문자·숫자·하이픈(-)만 (GitHub Username 규칙과 비슷)
description: 무엇을 하고 언제 쓰는지 AI는 이 문장을 보고 스킬을 꺼낼지 판단합니다. "언제"가 빠지면 스킬이 동작하지 않습니다
아래쪽 본문 일하는 순서, 양식, 지킬 것 모듈 4의 Markdown 그대로. 모듈 3의 프롬프트 공식(역할·목표·맥락·형식·조건)을 문서로 적은 것

6-2. 옵시디언에서 SKILL.md 쓰기 (15분)

  1. 옵시디언 보관소에 98_스킬 폴더를 만들고, 그 안에 prd-interview 폴더를 만듭니다
  2. prd-interview 폴더에서 [새 노트] → 제목을 정확히 SKILL (대문자)로
  3. 실습 파일 스킬 예시 파일 의 내용을 붙여넣기
  4. 맨 위 --- 사이 부분이 옵시디언에서 속성(Properties) 상자로 보이면 정상입니다
📁 AI업무자료
 ├─ 📁 01_기획(PRD)
 ├─ 📁 02_참고자료
 ├─ 📁 03_AI결과물
 ├─ 📁 98_스킬
 │   └─ 📁 prd-interview
 │       └─ 📄 SKILL.md     ← 이번 모듈에서 만든 것
 └─ 📁 99_프롬프트
  1. Windows 파일 탐색기에서 문서 > AI업무자료 > 98_스킬 > prd-interview 를 열어 파일 이름이 SKILL.md 인지 확인 (확장자 표시를 켜 두세요)

6-3. Claude에 등록하고 써 보기 (10분)

스킬 등록

  1. 파일 탐색기에서 prd-interview 폴더를 오른쪽 클릭 → 압축(ZIP)
    • Windows 11: 압축 대상 → ZIP 파일 / Windows 10: 보내기 → 압축(ZIP) 폴더
    • ⚠️ 폴더 안의 SKILL.md가 아니라 폴더 자체를 압축합니다
  2. Claude 왼쪽 아래 프로필 → 설정 → 기능(Capabilities) → 스킬(Skills)
    • 코드 실행·파일 만들기 같은 기능을 먼저 켜야 스킬 메뉴가 보이는 경우가 있습니다
  3. [스킬 업로드] → prd-interview.zip 선택 → 목록에서 켜기
  4. 새 대화에서 아무 설명 없이 입력:
교육 일정을 한눈에 관리하는 도구를 기획하고 싶어
  1. Claude가 스킬을 꺼내 쓰면 화면에 스킬 사용 표시가 나오고, "배경부터 여쭤볼게요"처럼 질문을 1~2개씩 하기 시작합니다 ✅

참고: 무료 계정이라면 같은 파일을 다르게 건네기

방법 하는 법
프로젝트 지침으로 모듈 3에서 만든 프로젝트의 지침 칸에 SKILL.md 본문(아래쪽)을 붙여넣기 → 그 프로젝트 안에서 "기획하고 싶어"
파일로 첨부 새 대화에 SKILL.md를 첨부하고 "이 파일의 방법대로 진행해 줘. 교육 일정 관리 도구를 기획하고 싶어"

차이점: 스킬은 어느 대화에서든 AI가 알아서 꺼내고, 무료 방법은 내가 건네야 합니다. 그래도 매뉴얼을 파일로 한 번 써 두면 매번 다시 쓸 필요가 없다는 점은 같습니다.

6-4. (선택) Claude에게 스킬을 만들어 달라고 하기 (5분)

스킬도 AI와 함께 만들 수 있습니다.

과정이 끝날 때마다 쓰는 "강의평가 결과보고서"를 우리 양식으로 써 주는 스킬을 만들어 줘.
양식: 제목 / 1. 개요(과정·기간·응답률) / 2. 결과 요약(전체 평균) /
      3. 개선 필요 과목(평균 3.5 미만, 표) / 4. 주요 의견 / 5. 조치 계획(표)
- name은 eval-report, SKILL.md 하나로
- description에 "언제 쓰는지"를 꼭 넣어 줘
- 자료에 없는 숫자나 조치 일정은 [확인 필요]로 표시하게 해 줘

결과로 나온 SKILL.md는 옵시디언 98_스킬/eval-report/ 에 저장합니다. 이 스킬은 모듈 7의 결재 보고서 실습과, 과정이 끝날 때마다 쓰는 실제 결과보고서에 그대로 쓸 수 있습니다.

6-5. 조직 배포: 문제출제 스킬 받아 쓰기 (15분)

지금까지는 내가 만든 스킬을 나만 썼습니다. Team 계정에서는 관리자가 스킬을 조직 전체에 배포할 수 있습니다. 부서 공식 업무 매뉴얼을 한 번 나눠 주는 것과 같습니다.

6-3 개인 등록 6-5 조직 배포
누가 올리나 나 관리자 한 명
누가 쓰나 나만 Team 멤버 전원
고칠 때 내가 다시 올림 관리자가 고치면 전원에게 반영

이번에 받는 스킬: quiz-generator (소방학교 문제출제)

교재·법령·교범을 주면 객관식 문항 → 중앙소방학교 문제카드(hwpx) → 정답지까지 만들어 주는 스킬입니다. 어느 담당과목이든 같은 6단계로 일합니다.

① 자료 파악 (1차 소스와 AI 요약 구분) → ② 출제 계획 (난이도·분야 배분) → ③ 문항 초안
→ ④ 근거 검증 (확인 안 되면 지어내지 않음) → ⑤ 문제카드·정답지 만들기 → ⑥ 최종 점검

prd-interview 는 SKILL.md 한 장이었지만, 이 스킬은 양식 파일과 계산 스크립트까지 들어 있는 폴더입니다. 스킬이 업무 매뉴얼에서 업무 도구로 커진 모습입니다.

📁 quiz-generator
 ├─ 📄 SKILL.md                 ← 6단계 절차, 지킬 원칙
 ├─ 📁 references               ← 근거 검증 방법, 문항 품질 기준, 문제카드 양식(hwpx)
 └─ 📁 scripts                  ← 문항 배분 계산, 문제카드 만들기

실습

  1. 설정 → 스킬 목록에 quiz-generator 가 보이는지 확인합니다 (관리자가 배포해 둔 것)
  2. 실습 파일 두 개를 내려받습니다: 출제 의뢰서, 교재 발췌
  3. Claude 새 대화에 두 파일을 첨부하고 한 문장만 입력합니다
첨부한 출제 의뢰서대로 교재 발췌를 범위로 문제카드를 만들어 줘
  1. Claude가 과정명·과목명·출제일자·소속·성명을 먼저 물어보는지 확인합니다. 소속과 성명은 예시 값(예: 교육운영팀, 홍길동)으로 답합니다
  2. 결과로 나온 문제카드(.hwpx) 와 정답지를 내려받아 확인합니다

확인할 것

□ 의뢰서대로 5문항, 난이도 상 1 · 중 3 · 하 1 인가?
□ 난이도 칸에 해당 값만 【 】 표시가 되어 있는가? (예: 상ㆍ【중】ㆍ하)
□ 출제근거가 교재의 어느 부분인지 적혀 있는가?
□ 교재에 없는 수치나 내용이 들어가지 않았는가?
□ 해설은 문제카드가 아니라 정답지에만 있는가?

좋은 스킬 체크리스트

□ description에 "무엇을"과 "언제"가 모두 있다
□ 스킬 하나에 일 하나 (PRD 인터뷰 + 보고서 작성을 한 스킬에 섞지 않기)
□ 순서가 번호로 적혀 있다
□ "지어내지 말 것([확인 필요])" 같은 지킬 것이 있다
□ 개인정보·비밀번호·내부 기밀이 들어 있지 않다
