회차별 과제: 수업 사이 일주일, 내 업무에 써 보기

이 과정은 4주 동안 주 1회 진행합니다. 회차 사이 일주일은 배운 것을 실제 업무에 써 보는 시간입니다. 과제 결과는 다음 회차의 재료가 되니, 짧게라도 꼭 해 와 주세요. 각 회차 첫 10분에 함께 확인합니다.

주차 수업 다음 주까지 할 과제
1주차 1회차 (4시간): 프롬프트·프로젝트, 옵시디언, PRD 과제 ① 내 PRD 완성 + 내 업무 프로젝트 써 보기
2주차 2회차 (4시간): 스킬, 결과물 만들기, AI 브라우저, 화면 뜯어보기 과제 ② 내 스킬을 실제 업무에 3번 쓰기 + GitHub 가입
3주차 3회차 (4시간): 웹 배포, Claude Code로 내 화면 만들기 과제 ③ 내 화면 한 번 더 고치기 + 동료 1명에게 써 보게 하기
4주차 성과 공유 (1시간) 한 사람씩 "한 달 동안 AI로 줄인 일" 소개

모든 과제에 공통

  • 개인정보, 내부 문서, 비공개 자료는 넣지 않습니다. 공개해도 되는 자료나 예시로 바꿔서 씁니다.
  • 결과는 옵시디언 03_AI결과물 폴더에 날짜를 붙여 저장해 두세요. 4주차 발표 자료가 됩니다.
  • 막히면 혼자 고민하지 말고 다음 회차에 그대로 가져오세요. 막힌 지점도 좋은 발표 거리입니다.

과제 ① 1회차 뒤: 내 PRD 완성 + 내 업무 프로젝트 써 보기 (약 1시간)

  1. 모듈 05에서 시작한 내 PRD를 끝까지 씁니다. [확인 필요] 를 모두 채우고, 6번 범위 밖과 7번 성공 기준을 꼭 적습니다.
  2. 모듈 03의 방법으로 Claude에 내 업무 프로젝트를 하나 만듭니다 (예: "교육 일정 관리", "출장·복무 정리").
    • 파일: 공개해도 되는 업무 자료(양식, 일정표, 공개 규정 등)
    • 지침: 내 업무에 맞게 고친 지침
  3. 일주일 동안 그 프로젝트에서 실제 업무 질문을 3번 이상 해 봅니다.

2회차에 가져올 것

□ 완성한 내 PRD (옵시디언 01_기획(PRD) 폴더)
□ 내 업무 프로젝트 이름과, 써 보니 좋았던 점 / 아쉬웠던 점 한 줄씩

내 PRD는 3회차에 내 화면으로 만들어집니다. 기능이 많으면 3~5개로 줄여 두세요.

과제 ② 2회차 뒤: 내 스킬을 실제 업무에 3번 쓰기 + GitHub 가입 (약 1시간)

  1. 모듈 06-6에서 만든 내 업무 스킬을 실제 문서 작업에 3번 이상 불러 씁니다.
  2. 쓸 때마다 고칠 점을 한 줄씩 메모하고, SKILL.md를 고쳐 다시 등록해 봅니다 (모듈 06-3 방법).
  3. 3회차 준비: GitHub 가입 (모듈 10의 "1. GitHub 계정 만들기", 업무 구글 이메일로)

3회차에 가져올 것

□ 고친 내 SKILL.md, 사용 메모 3줄
□ GitHub 아이디와 비밀번호 (로그인되는지 확인)

시간이 남으면 모듈 07의 결재 보고서 프롬프트를 내 PRD로 실행해 보세요. 실제 결재 보고에 쓸 초안이 나옵니다.

과제 ③ 3회차 뒤: 내 화면 한 번 더 고치기 + 동료에게 써 보게 하기 (약 1시간)

  1. 모듈 12에서 만든 내 화면(또는 공공데이터 화면)을 Claude Code로 한 번 더 고칩니다. 예: 빠진 기능 하나 추가, 안내 문구 넣기
  2. 미리보기 주소에서 확인한 뒤 합치기 (모듈 12의 6단계)
  3. 동료 1명에게 운영 주소를 보내 써 보게 하고 의견을 하나 받습니다

4주차에 가져올 것

□ 내 화면 운영 주소 (휴대폰으로 열리는지 확인)
□ 동료 의견 한 줄, 그 의견을 반영했는지

4주차 성과 공유 (1시간)

한 사람당 2~3분, 아래 세 가지만 이야기합니다.

질문 예시
한 달 동안 AI로 줄인 일은? "주간 보고서를 스킬로 만들어 매주 30분 줄였다"
가장 쓸모 있었던 것은? (프로젝트 / 스킬 / 내 화면 / AI 브라우저) "프로젝트에 규정을 넣어 두니 질문할 때 편했다"
아직 막힌 것은? "엑셀 파일을 넣으면 숫자를 틀릴 때가 있다"

좋은 스킬은 조직 전체에 배포해 모두가 쓸 수 있게 할 수 있습니다(모듈 06-5). 발표에서 나온 스킬 중 함께 쓰면 좋을 것을 골라 봅니다.
