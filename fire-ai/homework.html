  5. (선택) 말로 만드는 내 업무 도구: 몸풀기(03)처럼 HTML 파일 하나로 업무 도구를 만들어 봅니다. 예: 교육 일정·과정 운영 일정을 캘린더와 간트차트로 보는 화면. 모듈 09 응용 실습의 3D 방 꾸미기도 좋습니다(완성 예시는 실습 파일에 있음)
일정을 등록하면 월간 캘린더에, 프로젝트를 등록하면 간트차트에 보여 주는
일정 관리 화면을 HTML 파일 하나로 만들어 줘.
- 등록 창에서 "일정" / "프로젝트"를 고른다
- 일정: 제목, 날짜, 시작·종료 시간, 색, 메모 → 캘린더에 표시, 날짜를 누르면 그날 일정 목록
- 프로젝트: 제목, 시작일, 종료일, 진행률, 색 → 간트차트 막대, 끌어서 기간 이동·조절, 오늘 표시선
- 브라우저에 자동 저장, 삭제 후 되돌리기
- 부드러운 애니메이션, 깔끔한 디자인
- HTML·CSS·JavaScript만, 외부 라이브러리 없이
  • 내려받아 더블클릭하면 바로 열립니다. 쓸 만하면 모듈 12처럼 GitHub에 올려 주소로 공개합니다.
  • 일정은 그 브라우저에만 저장됩니다. 실제 개인정보·내부 일정은 넣지 말고 연습용 내용으로 씁니다.
