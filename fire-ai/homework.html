과제 안내: 1일차 저녁과 과정 뒤, 내 업무에 써 보기

이 과정은 2일 연속, 총 12시간(하루 6교시)입니다. 1일차 저녁에 짧은 과제를 하고, 과정이 끝난 뒤에는 배운 것을 실제 업무에 써 보는 과제를 합니다.

언제 과제 시간
1일차 저녁 내 PRD 마무리 + 내 스킬 한 번 써 보기 약 30분
과정 뒤 (구독 기간 동안) 내 화면 한 번 더 고치기 + 내 스킬을 실제 업무에 3번 쓰기 틈틈이
과정 뒤 (선택) 성과 공유: 한 사람씩 "AI로 줄인 일" 소개 1시간

모든 과제에 공통

  • 개인정보, 내부 문서, 비공개 자료는 넣지 않습니다. 공개해도 되는 자료나 예시로 바꿔서 씁니다.
  • 결과는 옵시디언 03_AI결과물 폴더에 날짜를 붙여 저장해 두세요. 성과 공유 발표 자료가 됩니다.
  • 막히면 혼자 고민하지 말고 2일차 아침이나 성과 공유 때 그대로 가져오세요.

1일차 저녁 과제 (약 30분)

  1. 모듈 05에서 쓴 내 PRD를 마무리합니다.
    • [확인 필요] 를 채우고, 4번 핵심 기능은 3~5개로 줄입니다.
    • 6번 범위 밖에 "로그인, 여러 사람 공유(데이터베이스)"를 넣고, 7번 성공 기준을 체크할 수 있는 문장으로 씁니다.
  2. 모듈 06-6에서 만든 내 업무 스킬을 실제 문서 하나에 한 번 불러 써 봅니다. 고칠 점이 있으면 한 줄 메모합니다.

2일차에 가져올 것

□ 마무리한 내 PRD (옵시디언 01_기획(PRD) 폴더)
□ 내 스킬을 써 본 소감 한 줄
□ GitHub 로그인이 되는지 (사전 과제에서 가입)

내 PRD는 2일차 오후에 내 화면으로 만들어집니다. 오늘 저녁 다듬은 만큼 결과가 좋아집니다.

과정 뒤 과제 (구독 기간 동안)

  1. 모듈 12에서 만든 내 화면(또는 공공데이터 화면)을 Claude Code로 한 번 더 고칩니다. 미리보기 주소에서 확인한 뒤 합치기 (모듈 12의 6단계)
  2. 동료 1명에게 운영 주소를 보내 써 보게 하고 의견을 하나 받습니다.
  3. 내 업무 스킬을 실제 업무에 3번 이상 쓰고, 쓸 때마다 고칠 점을 반영해 다시 등록합니다 (모듈 06-3 방법).
  4. 모듈 03의 방법으로 내 업무 프로젝트를 하나 만들어 업무 질문에 써 봅니다.

성과 공유에 가져올 것

□ 내 화면 운영 주소 (휴대폰으로 열리는지 확인)
□ 동료 의견 한 줄, 그 의견을 반영했는지
□ 내 스킬 사용 메모 3줄

과정 뒤 성과 공유 (선택, 1시간)

한 사람당 2~3분, 아래 세 가지만 이야기합니다.

질문 예시
과정 뒤 AI로 줄인 일은? "주간 보고서를 스킬로 만들어 매주 30분 줄였다"
가장 쓸모 있었던 것은? (프로젝트 / 스킬 / 내 화면 / AI 브라우저) "프로젝트에 규정을 넣어 두니 질문할 때 편했다"
아직 막힌 것은? "엑셀 파일을 넣으면 숫자를 틀릴 때가 있다"

좋은 스킬은 조직 전체에 배포해 모두가 쓸 수 있게 할 수 있습니다(모듈 06-5). 발표에서 나온 스킬 중 함께 쓰면 좋을 것을 골라 봅니다.
