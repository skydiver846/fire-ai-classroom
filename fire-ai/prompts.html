프롬프트 모음 파일(.md) 내려받기 내 업무 폴더(문서 > AI업무자료 > 99_프롬프트)에 넣어 두면 수업 뒤에도 쓸 수 있습니다.

프롬프트 모음 (수업 중 복사해서 사용)

기본 공식

[역할] 너는 ___야.
[목표] ___을 해 줘.
[맥락] 배경은 ___.
[형식] ___ 모양으로 (분량: ___).
[조건] ___은 지키고, 모르는 내용은 [확인 필요]로 표시해.

몸풀기: 공학용 계산기 (모듈 3, Claude)

공학용 계산기를 HTML 파일 하나로 만들어 줘.
- 사칙연산, 괄호, 제곱, 제곱근, sin·cos·tan(도 단위), log, π
- 버튼은 크게, 키보드로 숫자 입력도 되게
- 계산 기록을 아래에 5줄까지 보여 줘
- 외부 라이브러리 없이 파일 하나로

내려받은 .html 파일을 더블클릭하면 설치 없이 바로 열립니다.

몸풀기: 폭탄 뽑기 게임 (모듈 3, ChatGPT)

회식·워크숍에서 쓸 '폭탄 뽑기' 게임을 HTML 파일 하나로 만들어 줘.
- 참가자 이름을 쉼표로 입력하면 차례가 순서대로 돌아가
- 카드 12장 중 1장에 폭탄이 숨어 있어. 차례인 사람이 카드를 누르면 뒤집혀
- 폭탄이 나오면 화면이 흔들리고 "펑! ○○○ 당첨"을 크게 보여 줘
- 다시 하기 버튼, 카드 수 조절(6~30장)
- 외부 라이브러리 없이 파일 하나로
캔버스에서 바로 실행해 볼 수 있게 해 줘.

몸풀기: 화면 캡처로 지뢰찾기 (모듈 3, Claude)

Windows 키 + Shift + S로 화면을 캡처해 입력창에 Ctrl + V로 붙여 넣은 뒤:

붙여 넣은 화면처럼 동작하는 지뢰찾기 게임을 HTML 파일 하나로 만들어 줘.
- 9×9 칸, 지뢰 10개, 첫 클릭은 절대 지뢰가 아니게
- 왼쪽 클릭은 열기, 오른쪽 클릭은 깃발, 빈칸을 열면 주변도 자동으로 열기
- 위쪽에 남은 지뢰 수, 걸린 시간, 다시 하기 버튼(웃는 얼굴)
- 색과 칸 테두리는 그림과 비슷하게

몸풀기: 우리 집 여행 담당 캐릭터 이모티콘 (모듈 3, ChatGPT 앱)

휴대폰 ChatGPT 앱에서 설정 → 데이터 제어 → "모델 개선"을 끈 뒤, 내 사진 1장을 첨부합니다(사진 없이 해도 됩니다).

첨부한 내 사진을 바탕으로 "우리 집 여행 담당" 캐리커처 캐릭터를 만들어 줘.
여행 가방을 메고 지도를 든 모습으로, 카카오톡 이모티콘 4개를 한 장에 2×2로 그려 줘.
- 표정과 글자: "출발~!", "준비물 챙겼어?", "서둘러요!", "확인했습니다!"
- 큰 머리, 작은 몸, 굵은 외곽선, 밝은 색
- 흰 배경, 한글 글자는 크고 또렷하게

사진 없이 할 때 첫 줄: 안경을 쓰고 웃는 얼굴의 "우리 집 여행 담당"을 귀여운 캐리커처 캐릭터로 만들어 줘.

4개를 하나씩 따로 정사각형 그림으로 나눠 줘

같은 캐릭터로 "도착!", "수고하셨습니다", "잠시만요" 3개를 더 그려 줘

저장한 그림은 카톡 채팅방 [+] → 앨범으로 보냅니다. 다른 사람(특히 아이)의 사진은 올리지 않습니다. 가족 캐릭터는 과정 뒤에 사진 없이 말로만:

같은 그림체로 초등학생 아이와 무릎이 불편한 할머니 캐릭터를 더해 가족 4명 그림을 그려 줘

되묻기 (모듈 3)

내가 빠뜨린 정보가 있으면 먼저 질문해 줘

나쁜 예시: 한 줄 요청 (모듈 3)

경주 여행 일정 짜 줘

좋은 지시 예시: 가족 단톡방 경주 여행 일정 안내 (모듈 3)

[역할] 너는 가족 여행을 꼼꼼히 챙기는 여행 도우미야.
[목표] 가족 단톡방에 올릴 경주 2박 3일 일정 안내를 써 줘.
[맥락] 가을 주말(금~일), 광주에서 자가용으로 약 3시간. 가족 4명: 나, 배우자, 아이(초등 3학년),
       할머니(75세, 무릎이 불편해 오래 걷기·계단이 어려움). 숙소는 보문단지 근처.
[형식] 인사 1줄, 날짜별 일정은 표(시간·장소·이동·메모), 끝에 꼭 챙길 것 3가지.
[조건] 휴대폰에서 읽기 쉽게 짧게, 하루 2곳 정도로 쉬엄쉬엄. 입장료·운영시간처럼 확인되지 않은 내용은 [확인 필요]로 표시.

파일 요약 (모듈 3)

첨부한 문서를 읽고
1) 핵심 내용 3줄 요약
2) 실제로 해야 할 일(To-do) 목록
3) 문서에서 모호하거나 빠진 부분
을 표로 정리해 줘. 문서에 없는 내용은 지어내지 마.

실습 파일: 📎 예시 PRD 파일 내려받기 (빠진 부분: 누구 것인지 구분)

후기 요약 (모듈 3)

실습 파일: 📎 경주 여행 후기 파일 내려받기

첨부한 경주 여행 후기를 장소별로 정리해 줘.
- 장소마다 "좋았던 점 / 주의할 점"을 1~2줄로 요약
- 할머니(75세, 무릎 불편)와 아이(초등 3학년)에게 맞는지 ○·△·✕로 표시
- 후기에 없는 내용은 만들지 말고, 표로 정리해 줘

관광지 안내 요약: 없는 정보는 비워 두기 (모듈 3)

실습 파일: 📎 경주 관광지 안내 파일 내려받기

첨부한 자료에서 장소별 주차·걷기·계단 정보만 표로 정리해 줘.
자료에 없는 정보(입장료, 운영시간, 주차 요금 등)는 지어내지 말고 [확인 필요]라고 써 줘.

표 곳곳에 [확인 필요]가 보이면 성공입니다.

프로젝트 지침 (모듈 3)

너는 우리 가족 여행을 돕는 도우미야.
- 우리 가족: 나, 배우자, 아이(초등 3학년, 차멀미 있음), 할머니(75세, 무릎이 불편해 오래 걷기·계단이 어려움).
- 일정을 짤 때는 하루 2곳 이내로 하고, 계단·오르막이 많은 곳은 빼거나 대안을 함께 적는다.
- 편하게 반말로 답해도 된다. 일정·준비물·장소 비교는 표로 정리한다.
- 프로젝트에 올린 파일 내용을 우선 근거로 삼고, 확인되지 않은 요금·운영시간은 [확인 필요]로 표시한다.
- 답 끝에 "다음에 할 일" 1~3개를 제안한다.

프로젝트 효과 확인 (모듈 3)

"우리 가족 여행" 프로젝트 (파일 3개 + 지침을 넣은 뒤), 짧게 물어도 가족 조건이 반영되는지 봅니다:

둘째 날 비 오면?

내 업무용 프로젝트:

이 프로젝트에서 내가 도움받을 수 있는 일 3가지를 제안하고, 각각 어떤 파일을 넣어 두면 좋을지 표로 알려 줘

맛보기: 한 줄로 시키면? (모듈 5-0)

출석 관리 화면 만들어 줘

일부러 한 줄만 씁니다. 나온 화면이 우리 업무와 어디가 다른지 보고, PRD가 왜 필요한지 확인합니다.

PRD 인터뷰 (모듈 5, 스킬이 없을 때)

너는 경험 많은 기획자야. 나는 "[내가 만들고 싶은 것]"을 기획하려고 해.
PRD를 쓰기 위해 나를 인터뷰해 줘.
- 한 번에 질문 1~2개만 해.
- 배경·목표·사용자·핵심 기능·화면 흐름·범위 밖·성공 기준 순서로 물어봐.
- 내가 다 답하면 Markdown 형식의 PRD 한 장으로 정리해 줘.
- 내가 말하지 않은 내용은 [확인 필요]로 표시해.

PRD 인터뷰 스킬 써 보기 (모듈 6-2)

prd-interview 스킬을 등록하고 켠 뒤, 새 대화에서 아무 설명 없이 입력합니다:

우리 가족 여행 준비를 한눈에 보는 도구를 기획하고 싶어

스킬 파일 예시: 📎 스킬 예시 파일 내려받기

스킬 만들어 달라고 하기: 여행 일정표 (모듈 6)

여행 갈 때마다 쓰는 "여행 일정표"를 우리 집 양식으로 써 주는 스킬을 만들어 줘.
양식: 제목 / 1. 개요(인원·기간·이동) / 2. 날짜별 일정(표: 시간·장소·이동·메모) /
      3. 가족별 주의점 / 4. 준비물 / 5. 예산(표)
- name은 trip-plan
- description에 "언제 쓰는지"를 꼭 넣어 줘
- 입장료·운영시간처럼 확인하지 않은 요금과 시간은 [확인 필요]로 표시하게 해 줘
- 바로 올릴 수 있게 trip-plan 폴더째 ZIP 파일로 만들어 줘

⭐ trip-plan 스킬이 있으면 일정표는 한 문장이면 됩니다: 제주 2박 3일 우리 가족 여행 일정표 써 줘

내 스킬 만들어 달라고 하기 (모듈 6)

내가 매번 같은 양식으로 쓰는 "[문서 이름]"을 내 양식으로 써 주는 스킬을 만들어 줘.
양식: [제목 / 1. ○○ / 2. ○○ / 3. ○○ 처럼 내 양식의 칸을 적기]
- name은 영문 소문자와 하이픈으로 (예: weekly-report, family-event, weekly-menu)
- description에 "언제 쓰는지"를 꼭 넣어 줘
- 자료에 없는 숫자나 날짜는 [확인 필요]로 표시하게 해 줘
- 바로 올릴 수 있게 폴더째 ZIP 파일로 만들어 줘

오디오 해설: 차에서 듣는 경주 라디오 (모듈 7, Gemini Notebook 스튜디오)

초등학교 3학년 아이가 경주 가는 차 안에서 듣는 라디오처럼 만들어 줘.
첨성대, 동궁과 월지, 국립경주박물관 이야기를 쉬운 말로, 퀴즈를 섞어서.
소스에 없는 요금이나 운영시간은 말하지 마.

슬라이드 만들기 (모듈 7, Gemini Notebook 스튜디오)

우리 가족(나, 배우자, 초등 3학년 아이, 75세 할머니)에게 경주 2박 3일 여행을 소개하는 5장짜리 자료로 만들어 줘.
1장: 여행 한눈에 보기(언제, 어디, 숙소), 2장: 할머니가 걷기 편한 곳, 3장: 아이가 좋아할 곳,
4장: 비 오는 날 바꿀 곳, 5장: 각자 챙길 준비물.
소스에 없는 요금·운영시간은 쓰지 마.

인포그래픽 만들기 (모듈 7, Gemini Notebook 스튜디오)

경주에서 가 볼 만한 곳을 "할머니가 걷기 편한 곳 / 아이가 좋아할 곳 / 비 오는 날 갈 곳"
세 묶음으로 나눈 한 장 그림으로 만들어 줘.
아래에는 꼭 챙길 준비물 3개(할머니 혈압약, 아이 멀미약, 얇은 겉옷)를 넣어 줘.
가을 단풍색을 강조색으로, 글자는 크게. 요금·시간은 넣지 마.

자료로 묻기 (모듈 7, Gemini Notebook 채팅창)

관광지 안내와 후기를 바탕으로, 무릎이 불편한 할머니와 초등 3학년 아이가
함께 가기 좋은 곳과 피하면 좋을 곳을 표로 정리해 줘. 이유도 함께 적어 줘.

둘째 날 비가 오면 어디로 바꾸면 좋을까? 자료에 있는 장소로만 답해 줘.

PRD 검토 (모듈 7, Gemini Notebook 채팅창)

PRD의 배경, 핵심 기능, 화면·흐름, 성공 기준이 서로 맞는지 비교해 줘.
배경에 적힌 내용 중 기능에 빠진 것이 있으면 알려 줘.

가족 단톡방용 여행 안내 한 장 (모듈 7-2, Claude)

첨부한 관광지 안내와 후기를 바탕으로 가족 단톡방에 올릴 경주 2박 3일 여행 안내를 한 장으로 써 줘.
형식: 제목 / 한 줄 요약 / 날짜별 일정(표: 시간·장소·이동·메모) / 각자 챙길 것 / 비 오면 / 출발 시각과 모이는 곳.
할머니는 오래 걷기와 계단이 어렵고, 아이는 차멀미가 있어. 휴대폰으로 읽기 쉽게 짧게.
자료에 없는 요금·운영시간은 만들지 말고 [확인 필요]로 표시해.

이어서 같은 대화에서:

같은 안내를 둘째 날 비가 오는 경우로 바꿔 줘.
실내 장소로만 바꾸고, 바뀐 부분은 굵게 표시해 줘.

업무에서는 같은 방법으로 결재 보고서를 한 장으로 씁니다.

내 화면 시안 (모듈 7-3, Claude, 내 PRD 첨부)

첨부한 PRD를 읽고, 핵심 기능(필수)만 동작하는 프로토타입 웹 화면을 만들어 줘.
- HTML 파일 하나로, 설치 없이 브라우저에서 바로 열리게
- 휴대폰 화면에서도 보기 좋게
- "범위 밖" 기능은 넣지 마

일정 캘린더 + 프로젝트 간트차트 (모듈 9 응용 실습 A, 과정 뒤 과제)

일정을 등록하면 월간 캘린더에, 프로젝트를 등록하면 간트차트에 보여 주는
일정 관리 화면을 HTML 파일 하나로 만들어 줘.
- 등록 창에서 "일정" / "프로젝트"를 고른다
- 일정: 제목, 날짜, 시작·종료 시간, 색, 메모 → 캘린더에 표시, 날짜를 누르면 그날 일정 목록
- 프로젝트: 제목, 시작일, 종료일, 진행률, 색 → 간트차트 막대, 끌어서 기간 이동·조절, 오늘 표시선
- 브라우저에 자동 저장, 삭제 후 되돌리기
- 부드러운 애니메이션, 깔끔한 디자인
- HTML·CSS·JavaScript만, 외부 라이브러리 없이

3D 방 꾸미기 (모듈 9 응용 실습 B)

3D로 방을 꾸미는 화면을 HTML 파일 하나로 만들어 줘.
- three.js 사용
- 바닥과 벽 두 면. 빈 곳을 끌면 방이 돌아가고, 휠로 확대·축소
- 가구 버튼(침대, 소파, 책상, 의자, 책장, 탁자, 화분, 스탠드, 러그)을 누르면 방에 놓이고, 끌어서 옮김 (벽 밖으로는 못 나감)
- 선택한 가구: 색 바꾸기, R 키로 돌리기, Delete 키로 지우기
- 벽 색, 바닥(마루·타일·단색), 낮·밤 바꾸기
- 브라우저에 저장, 사진(PNG)으로 저장

하얀 화면이면 F12 → Console에서 three.js를 인터넷에서 불러오지 못했는지 확인합니다.
