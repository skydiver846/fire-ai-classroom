01 구글 업무 계정 만들기

모듈 1. 업무용 Google 계정 만들기

📌 사전 과제 모듈입니다. 수업 시간에는 다루지 않으니 수업 전에 이 페이지를 보며 혼자 따라 해 주세요. 막히면 첫날 수업 시작 전에 물어보세요. 만든 업무 계정 이메일은 Claude Team 초대를 받기 위해 담당자에게 제출합니다(사전 과제 안내).

왜 업무용 계정을 따로 만드나요?

개인 메일·사진이 든 계정과 업무·강의용 계정을 나누면 자료가 섞이지 않고, AI 서비스에 개인 정보가 딸려 가지 않습니다.

계정 이름 예시 이 과정에서
개인 (이미 있으면) hong.gildong@gmail.com 그대로 둡니다. 새 계정의 복구 이메일로만 씀
업무 (새로 만들기) hong.gildong.work@gmail.com ChatGPT·Claude·Gemini Notebook·GitHub 가입, Claude Team 초대 받기

개인 Google 계정이 없다면 업무 계정 하나만 만들면 됩니다.

1-1. 업무 계정 만들기 (약 7분)

① 가입 화면 열기

  • Chrome 주소창에 accounts.google.com/signup 입력
  • 또는 google.com → 오른쪽 위 [로그인] → [계정 만들기] → [개인용]

② 이름 → 성, 이름 입력 → [다음]

③ 생년월일·성별 → 입력 → [다음]

④ Gmail 주소 정하기 (가장 오래 고민하는 단계)

  • 추천 주소 대신 [나만의 Gmail 주소 만들기] 선택

  • 영문 소문자, 숫자, 마침표(.)만 사용 가능. 한글, 띄어쓰기, _, - 는 불가

  • 주소는 나중에 바꿀 수 없습니다. 정하면 바로 종이에 적기

  • 개인 계정이 있다면 같은 이름 + .work 로 지으면 구분하기 쉽습니다 (예: hong.gildong.work)

  • "이미 사용 중"이면 실패가 아니라 누가 먼저 쓰는 것. 끝에 기수 번호·생일 숫자 등을 붙여 재시도 (예: hong.gildong119)

  • ⚠️ Gmail은 마침표를 구분하지 않습니다. hong.gildong 과 honggildong 은 같은 주소라, 마침표 위치만 바꿔서는 새 주소가 되지 않습니다

⑤ 비밀번호 → 영문·숫자·기호 섞어 8자 이상 → 확인칸에 한 번 더

  • 나만 아는 문장에서 만들면 외우기 쉽습니다 (예: "소방학교 119기 화이팅!" → Sobang119!fighting)
  • 비밀번호 표시를 켜서 두 칸이 같은지 확인. 한/영 키가 한글로 되어 있어 틀리는 경우가 가장 많습니다

⑥ 전화번호 인증 → 문자로 온 6자리 코드 입력

  • 화면에 따라 [건너뛰기]가 보이기도 하지만, 분실 시 복구를 위해 등록 권장

⑦ 복구 이메일 → 개인 계정을 넣어 두면 비밀번호를 잊어도 되찾을 수 있음 (개인 계정이 없으면 [건너뛰기])

⑧ 검토 → 약관 [동의]

⑨ 확인 ✅ google.com 오른쪽 위에 이름 첫 글자 동그라미가 보이면 성공

1-2. Chrome "업무" 프로필 만들기 (약 5분)

개인 계정과 업무 계정을 한 창에서 바꿔 쓰면 "어느 계정으로 로그인했지?"가 계속 헷갈립니다. Chrome 프로필을 만들면 업무 계정만 쓰는 별도 창이 생깁니다.

  1. Chrome 오른쪽 위 프로필 아이콘 (주소창 오른쪽) 클릭
  2. [추가] → [로그인] → 업무 계정으로 로그인
  3. 프로필 이름 업무, 색상 파랑으로 지정
  4. 작업 표시줄에 파란 창이 따로 생기면 완료

💡 이후 모든 모듈은 파란 "업무" 프로필 창에서 진행합니다. ChatGPT, Claude, Gemini Notebook, (심화) GitHub·Vercel 가입도 모두 이 창에서 합니다.

자주 막히는 곳

상황 해결
"이 전화번호는 너무 많이 사용되었습니다" 한 번호로 만들 수 있는 계정 수에 제한이 있습니다. 시간을 두고 다시 하거나 담당자에게 알려 주세요
같은 강의장에서 인증이 계속 실패 같은 와이파이에서 짧은 시간에 가입이 몰리면 생길 수 있습니다. 휴대폰 데이터(핫스팟)로 바꿔 시도
인증 문자가 안 옴 1분 기다린 뒤 재전송. 국가 번호가 +82인지 확인
이미 업무용으로 쓰는 Google 계정이 있음 새로 만들지 않고 그 계정을 업무 계정으로 써도 됩니다
강의장(공용) PC에서 Chrome 프로필을 만듦 동기화는 [취소], 수업 후 프로필 삭제 (프로필 아이콘 → 톱니바퀴 → 해당 프로필 ⋮ → 삭제)

✅ 확인 질문 (인터뷰)

  1. Chrome 오른쪽 위 프로필 아이콘을 눌렀을 때 "업무" 프로필이 보이나요?
  2. "업무" 프로필 창에서 Gmail 받은편지함이 열리나요?
  3. 업무 계정의 주소와 비밀번호를 안전한 곳에 적어 두었나요?
