04 옵시디언 (선택)

선택 자료 04. 옵시디언 설치와 MD 파일 만들기 (수업 외)

📌 수업에서는 다루지 않는 선택 자료입니다. 과정 뒤, 내 업무 폴더(문서 > AI업무자료)의 MD 파일을 더 편하게 보고 고치고 싶을 때 따라 해 보세요. 옵시디언은 설치가 필요한 프로그램이라, 기관 PC에서는 설치가 허용되는지 먼저 확인합니다.

🎯 이 모듈에서 만들 것: 내 보관소와 첫 MD 파일 (AI 답을 저장해 두고 다시 건네기)

🤔 생각해 보기: AI가 써 준 좋은 답을 다음 주에 다시 쓰려면 어디에 두어야 할까요? (답은 이 모듈에서 찾아보세요. 점수 없음)

옵시디언(Obsidian)이란?

  • 내 컴퓨터 폴더 안의 Markdown(.md) 파일을 편하게 쓰고 연결하는 무료 메모 앱
  • 파일이 내 컴퓨터에 그대로 저장됩니다. 앱을 지워도 파일은 남습니다.
  • 그대로 ChatGPT·Claude·Gemini Notebook에 올릴 수 있어 AI용 자료 창고로 좋습니다.

Markdown(MD)이란?

기호 몇 개로 제목·목록·표를 표시하는 아주 단순한 글쓰기 규칙입니다. 메모장으로도 열리고, AI가 구조를 정확히 이해합니다.

4-1. 설치 (Windows, 약 5분)

  1. Chrome에서 obsidian.md 접속
  2. [Download] → Windows용 설치 파일(.exe) 다운로드
  3. 다운로드한 파일 실행 → 설치가 자동으로 진행됩니다
    • "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]
  4. 설치가 끝나면 옵시디언이 자동으로 열립니다

💡 옵시디언은 가입 없이 바로 쓸 수 있습니다. 동기화(Sync)·게시(Publish)는 유료 부가 기능이며 이번 수업에는 필요 없습니다.

맛보기: AI가 만든 체크리스트를 옵시디언에서 체크하기 (3분)

보관소를 만들기 전에, 옵시디언이 왜 편한지 먼저 손으로 느껴 봅니다.

  1. Claude에 입력: 내일 할 일 5개를 Markdown 체크리스트로 만들어 줘. 업무용 예시로.
  2. 옵시디언 첫 화면의 새 노트(Ctrl + N)에 붙여넣기
  3. 읽기 보기(오른쪽 위 책 아이콘, 또는 Ctrl + E)로 바꾸면 네모 칸이 생깁니다 → 눌러서 체크 ✅

AI가 쓴 글이 그대로 쓸 수 있는 문서가 됩니다. 이것이 MD 파일의 힘입니다. 이 노트는 4-2에서 보관소를 만든 뒤 옮겨도 되고 지워도 됩니다.

4-2. 보관소(Vault) 만들기

보관소 = 옵시디언이 관리하는 폴더 하나입니다.

  1. 첫 화면에서 [Create new vault] (새 보관소 만들기) → [Create]
  2. Vault name: AI업무자료
  3. Location: [Browse] → 문서(Documents) 폴더 선택
  4. [Create] 클릭

한국어로 바꾸기

  • 왼쪽 아래 톱니바퀴(Settings) → General(일반) → Language → 한국어 → 앱 다시 시작

폴더 구조 만들기 (모듈 3에서 설계한 구조)

  • 왼쪽 파일 탐색기 위 [새 폴더] 아이콘으로 아래 4개 생성
📁 AI업무자료
 ├─ 📁 01_기획(PRD)
 ├─ 📁 02_참고자료
 ├─ 📁 03_AI결과물
 └─ 📁 99_프롬프트

✅ Windows 파일 탐색기에서 문서 > AI업무자료 를 열어 보면 똑같은 폴더가 실제로 있습니다. "옵시디언 = 내 폴더를 보는 창"임을 꼭 확인시켜 주세요.

4-3. 첫 MD 파일 만들기

  1. 99_프롬프트 폴더에서 마우스 오른쪽 → [새 노트]
  2. 제목: 자주 쓰는 프롬프트
  3. 아래 내용을 그대로 따라 입력합니다
# 자주 쓰는 프롬프트

## 문서 요약
- 핵심 3줄 요약
- 해야 할 일 목록
- **문서에 없는 내용은 지어내지 말 것**

## 안내문 작성
| 요소 | 내용 |
|---|---|
| 역할 | 교육운영 담당자 |
| 형식 | 제목 + 5개 항목 |

- [ ] 결과는 원문과 대조하기
  1. Ctrl + E 를 눌러 편집 ↔ 읽기 보기를 전환해 봅니다

4-4. Markdown 문법은 3가지만

쓰는 법 결과 용도
# 제목 큰 제목 문서 제목 (## 은 소제목)
- 항목 • 항목 목록
**굵게** 굵게 강조

나머지(표, 체크리스트 등)는 외우지 않아도 됩니다. AI에게 "Markdown으로 정리해 줘"라고 하면 알아서 씁니다. 우리는 읽을 줄 알면 충분합니다.

옵시디언 전용 기능 하나: [[파일이름]] 을 쓰면 다른 노트로 가는 링크가 됩니다. 이 강의자료도 그렇게 연결되어 있습니다.

4-5. AI 결과물을 MD로 저장하기

ChatGPT·Claude의 답을 옵시디언에 보관하는 방법:

  1. 답변 아래 [복사] 아이콘 클릭 (서식이 Markdown으로 복사됩니다)
  2. 옵시디언 03_AI결과물 폴더에 새 노트 → 붙여넣기(Ctrl + V)
  3. 제목에 날짜를 붙이면 찾기 쉽습니다. 예: 2026-10-24 경주 여행 일정

답변을 마우스로 드래그해 복사하면 표가 깨질 수 있습니다. 반드시 복사 아이콘을 쓰게 하세요.

4-6. 실습 파일을 보관소로 옮기기

모듈 3에서 다운로드 폴더에 받은 PRD_경주 여행 준비물.md 를 보관소로 옮깁니다.

  1. 파일 탐색기 다운로드 폴더에서 파일을 잡고 → 옵시디언 왼쪽 01_기획(PRD) 폴더 위에 끌어다 놓기
    • 어려우면 탐색기에서 잘라내기(Ctrl + X) → 문서 > AI업무자료 > 01_기획(PRD) 에 붙여넣기(Ctrl + V)
  2. 옵시디언에서 열어 보면 모듈 3에서 AI에게 건넨 파일이 표와 체크박스로 보입니다
  3. 자주 쓰는 프롬프트 노트 맨 아래에 [[PRD_경주 여행 준비물]] 를 입력해 링크 만들기 체험
  4. 모듈 3 추가 실습에서 받은 경주 여행 후기_예시.md 가 있으면 02_참고자료 폴더로 옮기기 (모듈 7에서 Gemini Notebook 자료로 함께 씁니다)

모듈 4를 마친 보관소 모습

자주 막히는 곳

상황 해결
설치 파일 실행 시 경고 [추가 정보] → [실행]. 공식 사이트(obsidian.md)에서 받은 파일인지 확인
보관소를 어디 만들었는지 모름 왼쪽 아래 보관소 이름 클릭 → [보관소 관리] → 경로 확인
표가 표로 안 보임 표 위아래에 빈 줄이 있는지, 둘째 줄 |---|---| 가 있는지 확인
# 을 쳤는데 제목이 안 됨 # 뒤에 띄어쓰기가 있어야 합니다
| 기호를 못 찾음 Shift + 원화(₩) 또는 역슬래시(\) 키
문법 실습을 복사·붙여넣기로 함 직접 타이핑해야 기호가 모양으로 바뀌는 순간을 볼 수 있습니다
기관 PC라 설치가 막힘 옆 사람 화면으로 함께 보며 진행하고, 수업 후 전산 담당자에게 설치 허용 요청. 그동안은 메모장에서 .md 확장자로 저장해도 실습 가능
