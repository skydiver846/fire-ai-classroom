모듈 3. 프롬프트 · 파일 건네기 · 폴더(프로젝트) 활용

🎯 이 모듈에서 만들 것: 말로 만든 계산기 프로그램(HTML) 과 그 웹 주소, 가족 단톡방에 올릴 여행 일정 안내, "우리 가족 여행" 프로젝트 체험과 내 업무 프로젝트

🤔 생각해 보기: AI에게 "경주 여행 일정 짜 줘"라고만 하면, AI는 무엇을 모를까요? (답은 이 모듈에서 찾아보세요. 점수 없음)

이 모듈의 핵심 한 줄:

AI의 답은 내가 건네는 것(질문 + 자료 + 맥락)만큼 좋아진다.

건네는 방법 비유 이번 모듈
프롬프트 업무 지시서 3-1
파일 참고 서류 첨부 3-2
프로젝트(폴더) 담당자 전용 서류함 + 업무 매뉴얼 3-3

시작하며: 이런 생각, 해 보신 적 있나요? (1분)

① AI는 검색을 조금 편하게 해 주는 것이다
② 프로그램은 개발자만 만든다
③ 나는 컴퓨터를 잘 못해서 어렵다

하나라도 고개가 끄덕여졌다면 이 과정이 맞습니다. 이틀 동안 이 세 생각이 하나씩 깨지고, 마지막에는 내가 생각한 것을 내가 만들어 쓰는 데까지 갑니다. 마지막 시간에 같은 질문을 다시 하겠습니다.

여는 이야기: 여행길 도우미 (3분)

화면의 QR을 휴대폰으로 찍어 여행길 도우미를 열어 보세요. → https://gwangju-traffic-helper.skydiver846.chatgpt.site/

  • 지난주에 공유한 사이트입니다. 한 번씩 써 보셨나요?
  • 가 보고 싶은 곳을 하나만 검색해 보세요.
  • 이 사이트는 코딩 없이, AI와 대화로 만들었습니다. 이 과정이 끝나면 여러분도 비슷한 것을 만들 수 있습니다.

우리 집 여행 담당이라면 익숙한 장면이 있습니다.

  • 가족 단톡방에 "어디 갈래?" 메시지가 40개 쌓였는데 정해진 것은 없습니다.
  • 블로그 후기를 보느라 인터넷 탭이 20개 열려 있습니다.
  • 출발 날 아침, 꼭 하나씩 준비물이 빠집니다.

이 과정에서는 경주 2박 3일 가족 여행(나 · 배우자 · 아이 초등 3학년 · 할머니 75세)을 준비하는 여행 담당의 이틀을 따라갑니다. 같은 방법을 업무에 어떻게 쓰는지는 모듈마다 끝에서 한 줄로 짚습니다.

3-0. 몸풀기: 말로 만드는 프로그램, HTML 한 장 (15분)

본격적으로 시작하기 전에 AI에게 프로그램을 하나 시켜 봅니다. 코딩은 몰라도 됩니다.

알아 둘 것: AI가 만든 HTML 파일 하나 = 설치 없이 바로 쓰는 프로그램

  • 내려받은 .html 파일을 더블클릭하면 인터넷 창(크롬·엣지)에서 바로 열립니다.
  • 설치도, 관리자 권한도, 인터넷 연결도 필요 없습니다. 파일 하나라 동료에게 그대로 건넬 수 있습니다.
  • 2일차에는 이 파일을 웹 주소로 공개하고(10), 내 업무 화면을 같은 방법으로 만듭니다(12).

① 함께: 공학용 계산기 (Claude, 5분)

Claude 새 채팅에 입력하세요.

공학용 계산기를 HTML 파일 하나로 만들어 줘.
- 사칙연산, 괄호, 제곱, 제곱근, sin·cos·tan(도 단위), log, π
- 버튼은 크게, 키보드로 숫자 입력도 되게
- 계산 기록을 아래에 5줄까지 보여 줘
- 외부 라이브러리 없이 파일 하나로
  1. 오른쪽 미리보기에서 바로 눌러 봅니다. sin 30 = 0.5, √2 ≈ 1.414 가 나오면 성공.
  2. 미리보기 오른쪽 위 다운로드(또는 복사 → 메모장 → 계산기.html로 저장)로 바탕화면에 저장합니다.
  3. 바탕화면의 계산기.html을 더블클릭 → 인터넷 창에서 열리면 내 PC의 프로그램이 된 것입니다.
  4. 고치고 싶으면 말로: "버튼 색을 빨간색 계열로", "단위 변환(℃↔℉) 버튼 추가"

② 골라서 하나: 게임 또는 내 여행 담당 캐릭터 이모티콘 (7분)

A. 폭탄 뽑기 (ChatGPT): 회식·워크숍 복불복용

회식·워크숍에서 쓸 '폭탄 뽑기' 게임을 HTML 파일 하나로 만들어 줘.
- 참가자 이름을 쉼표로 입력하면 차례가 순서대로 돌아가
- 카드 12장 중 1장에 폭탄이 숨어 있어. 차례인 사람이 카드를 누르면 뒤집혀
- 폭탄이 나오면 화면이 흔들리고 "펑! ○○○ 당첨"을 크게 보여 줘
- 다시 하기 버튼, 카드 수 조절(6~30장)
- 외부 라이브러리 없이 파일 하나로
캔버스에서 바로 실행해 볼 수 있게 해 줘.
  • 답이 코드로만 나오면 오른쪽 위 미리보기(실행) 를 누르거나 "캔버스로 열어 줘"라고 이어서 입력합니다.
  • 답이 코드 중간에 끊기면 "이어서 계속 써 줘"라고 입력합니다. 무료 계정은 사용 한도가 차면 멈출 수 있습니다(긴 파일일수록 잘 걸림).

B. 지뢰찾기 (Claude, 화면 캡처로 시키기): 그림 한 장으로 설명하기

  1. 지뢰찾기 화면 그림을 열어 보기 합니다. → 📎 지뢰찾기 화면 그림 내려받기 열어 보기
  2. Windows 키 + Shift + S → 그림 부분을 마우스로 끌어 화면 캡처합니다.
  3. Claude 새 채팅 입력창에 Ctrl + V 로 붙여 넣고 아래를 함께 보냅니다.
붙여 넣은 화면처럼 동작하는 지뢰찾기 게임을 HTML 파일 하나로 만들어 줘.
- 9×9 칸, 지뢰 10개, 첫 클릭은 절대 지뢰가 아니게
- 왼쪽 클릭은 열기, 오른쪽 클릭은 깃발, 빈칸을 열면 주변도 자동으로 열기
- 위쪽에 남은 지뢰 수, 걸린 시간, 다시 하기 버튼(웃는 얼굴)
- 색과 칸 테두리는 그림과 비슷하게
  • 긴 설명 대신 그림 한 장을 건넸습니다. 업무에서도 똑같습니다. 기존 양식, 엑셀 표, 오류 창을 캡처해 붙여 넣으면 AI가 훨씬 정확히 알아듣습니다(3-2에서 이어집니다).

C. 우리 집 여행 담당 캐릭터 이모티콘 (ChatGPT 앱, 휴대폰): 그림도 말로 만든다. 이틀 동안 함께 다닐 내 캐릭터입니다

  1. 휴대폰의 ChatGPT 앱 → 설정 → 데이터 제어 → "모델 개선" 끄기 (내 사진이 학습에 쓰이지 않게)
  2. 내 사진 1장을 첨부하고 아래를 보냅니다. 사진이 싫으면 첫 줄을 안경을 쓰고 웃는 얼굴의 "우리 집 여행 담당"을 귀여운 캐리커처 캐릭터로 만들어 줘. 로 바꿔 사진 없이 해도 됩니다.
첨부한 내 사진을 바탕으로 "우리 집 여행 담당" 캐리커처 캐릭터를 만들어 줘.
여행 가방을 메고 지도를 든 모습으로, 카카오톡 이모티콘 4개를 한 장에 2×2로 그려 줘.
- 표정과 글자: "출발~!", "준비물 챙겼어?", "서둘러요!", "확인했습니다!"
- 큰 머리, 작은 몸, 굵은 외곽선, 밝은 색
- 흰 배경, 한글 글자는 크고 또렷하게
  1. 마음에 들면 이어서: 4개를 하나씩 따로 정사각형 그림으로 나눠 줘 → 그림을 길게 눌러 저장
  2. 카톡에서 쓰기: 채팅방 [+] → 앨범 → 저장한 그림 보내기. 가족 단톡방엔 "출발~!"·"준비물 챙겼어?", 부서 단톡방엔 "확인했습니다!". 이 캐릭터는 07(가족 안내)과 10(준비물 화면 링크)에서 다시 씁니다.
  • 그림 속 한글은 틀리게 그려질 때가 있습니다. 이상하면 "준비물 챙겼어?" 글자를 맞춤법대로 다시 또렷하게 라고 고쳐 달라고 합니다.
  • 키보드 이모티콘 목록에 정식으로 올리려면 카카오 이모티콘 스튜디오에 제안해 심사를 받아야 합니다. 여기서는 그림으로 보내는 나만의 이모티콘입니다.
  • 다른 사람의 사진(가족·동료 포함, 특히 아이 사진)은 올리지 않습니다. 가족 캐릭터도 만들고 싶으면 과정 뒤에 사진 없이 말로만: 같은 그림체로 초등학생 아이와 무릎이 불편한 할머니 캐릭터를 더해 가족 4명 그림을 그려 줘

③ 정리: 내 계산기가 웹 주소가 되는 순간 (3분)

  • 옆 사람과 비교해 보세요. 같은 AI인데 지시가 다르면 결과가 다릅니다. 그 차이를 만드는 방법이 바로 다음 3-1입니다.
  • 오늘 만든 것은 놀이였지만, 2일차에는 같은 방법으로 내 화면을 만들어 휴대폰으로 엽니다.
  • 🔓 처음에 물은 ② "프로그램은 개발자만 만든다" 가 방금 깨졌습니다. 코드는 한 줄도 쓰지 않았습니다.
  • 함께 보기: 앞 화면에서 계산기 파일을 폴더에 넣어 app.netlify.com/drop 에 끌어다 놓으면, 몇 초 만에 웹 주소가 생깁니다. QR을 찍어 내 휴대폰에서 열어 보세요. 방금 말로 만든 프로그램이 누구나 여는 웹사이트가 됐습니다. 2일차에 각자 직접 해 봅니다(모듈 10).
  • 조심할 것: 출처를 모르는 .html 첨부파일은 열지 않습니다(피싱에 자주 쓰입니다). 내가 만들었거나 믿을 수 있는 사람이 준 파일만 엽니다.

쉬는 시간에 해 볼 거리 (선택): ②에서 C를 고르지 않았다면 쉬는 시간에 내 여행 담당 캐릭터 이모티콘을 만들어 보세요. 07·10에서 다시 씁니다. 만든 분은 표정을 더 늘려 봅니다: 같은 캐릭터로 "도착!", "수고하셨습니다", "잠시만요" 3개를 더 그려 줘

3-1. 프롬프트: 좋은 지시의 5요소 (27분)

공식: 역할 · 목표 · 맥락 · 형식 · 조건

요소 질문 예시
역할 누구처럼 답할까? "너는 가족 여행을 꼼꼼히 챙기는 여행 도우미야"
목표 무엇을 원하나? "가족 단톡방에 올릴 경주 2박 3일 일정 안내를 써 줘"
맥락 배경은? "가족 4명, 할머니 75세(무릎 불편), 아이 초3, 가을 주말 금~일, 광주에서 자가용"
형식 어떤 모양으로? "인사 1줄 + 날짜별 일정 표(시간·장소·이동·메모)"
조건 지킬 것은? "하루 2곳 이내, 휴대폰에서 읽기 쉽게, 모르는 요금·시간은 [확인 필요]"

실습: 나쁜 프롬프트 vs 좋은 프롬프트

나쁜 예

경주 여행 일정 짜 줘

좋은 예

[역할] 너는 가족 여행을 꼼꼼히 챙기는 여행 도우미야.
[목표] 가족 단톡방에 올릴 경주 2박 3일 일정 안내를 써 줘.
[맥락] 가을 주말(금~일), 광주에서 자가용으로 약 3시간. 가족 4명: 나, 배우자, 아이(초등 3학년),
       할머니(75세, 무릎이 불편해 오래 걷기·계단이 어려움). 숙소는 보문단지 근처.
[형식] 인사 1줄, 날짜별 일정은 표(시간·장소·이동·메모), 끝에 꼭 챙길 것 3가지.
[조건] 휴대폰에서 읽기 쉽게 짧게, 하루 2곳 정도로 쉬엄쉬엄. 입장료·운영시간처럼 확인되지 않은 내용은 [확인 필요]로 표시.

💡 둘을 Claude에서 새 채팅 2개로 나눠 넣고 나란히 비교합니다. 대부분 "좋은 예"가 바로 쓸 수 있는 결과를 냅니다.

같은 지시, 다른 AI (2분): 방금 "좋은 예"를 ChatGPT에도 그대로 붙여넣어 보세요. 같은 지시인데 표 모양, 말투, 일정 고르는 방식이 조금씩 다릅니다. 어느 쪽이 우리 가족 단톡방에 더 맞는지 골라 보세요. 한 AI의 답이 정답은 아니니, 중요한 일은 두 곳에 물어 비교하는 습관을 들입니다.

💡 기억할 것: AI는 우리 할머니 무릎이 불편한지, 몇 시에 출발하는지 절대 알 수 없습니다. 내가 아는 사실은 내가 건네고, 요금·시간처럼 확인 안 된 것은 [확인 필요]로 남기게 합니다.

대화로 다듬기 (되묻기 기술)

한 번에 완벽하게 쓰려고 하지 않아도 됩니다. 이어서 지시합니다.

  • "둘째 날 일정을 더 짧게"
  • "표에 '쉬는 곳' 칸을 추가해 줘"
  • "단톡방용으로 200자 이내 버전도 만들어 줘"
  • "내가 빠뜨린 정보가 있으면 먼저 질문해 줘" ← 가장 유용한 한 문장

3-2. 파일 건네기 (30분, 후기 요약 포함)

방법

  • 입력창의 [+] 버튼(또는 클립 아이콘) → 파일 선택
  • 또는 파일을 입력창으로 끌어다 놓기(드래그 앤 드롭)

어떤 파일이 잘 되나?

잘 됨 주의
PDF, Word, 텍스트(.txt), Markdown(.md), 엑셀/CSV, 이미지(사진·캡처) 스캔한 흐린 PDF, 암호 걸린 파일, 아주 큰 파일

💡 MD 파일이 특히 좋은 이유: 제목·목록·표 구조가 그대로 전달되어 AI가 문서 구조를 정확히 이해합니다. PRD(05)와 스킬(06)을 MD 파일로 주고받는 이유입니다.

실습 프롬프트 (파일 첨부 후)

첨부한 문서를 읽고
1) 핵심 내용 3줄 요약
2) 실제로 해야 할 일(To-do) 목록
3) 문서에서 모호하거나 빠진 부분
을 표로 정리해 줘. 문서에 없는 내용은 지어내지 마.

연습 파일: 📎 예시 PRD 파일 내려받기 을 첨부해 보세요. 우리 가족 여행 준비물을 체크하는 화면을 만들려고 쓴 기획서(PRD) 초안입니다. 사이트의 [실습 파일 내려받기] 페이지에서 받아 다운로드 폴더에 저장합니다. .md 파일은 더블클릭하지 말고 바로 AI에 올리세요(앱 선택 창이 뜰 수 있습니다).

  • 파일을 올리면 입력창 위에 파일 이름 카드가 생깁니다. 카드만 보내지 말고 파일 + 지시를 함께 보냅니다.

🔍 AI가 찾아 주는 구멍: "누구 것인지 구분이 없는 준비물"

요약표의 3번 "빠진 부분" 에서 AI는 보통 이 PRD의 구멍을 찾아냅니다. 대표적인 것이 누구 것인지 구분입니다. PRD 배경에는 "가족마다 챙길 것이 다르다(할머니 혈압약·무릎 보호대·지팡이, 아이 멀미약·여벌 옷)"고 적혀 있는데, 기능은 준비물을 한 목록으로만 셉니다. 그러면 가족 전체로는 8개 중 6개(75%)를 챙겨 "순조로움" 으로 나오지만, 아이 것은 3개 중 1개(33%)만 챙긴 상태입니다. 정작 서둘러야 할 사람이 화면에서 사라집니다.

실습: 여행 후기 요약

여행 준비에서 시간이 많이 걸리는 일 중 하나가 후기 읽기입니다. 블로그·카페 후기를 탭마다 열어 한 줄씩 읽어야 하기 때문입니다. 예시 파일 📎 경주 여행 후기 파일 내려받기 를 첨부하고 아래처럼 지시합니다.

첨부한 경주 여행 후기를 장소별로 정리해 줘.
- 장소마다 "좋았던 점 / 주의할 점"을 1~2줄로 요약
- 할머니(75세, 무릎 불편)와 아이(초등 3학년)에게 맞는지 ○·△·✕로 표시
- 후기에 없는 내용은 만들지 말고, 표로 정리해 줘

하나 더 (시간이 남으면): 자료에 없는 정보는 비워 두게 하기

📎 경주 관광지 안내 파일 내려받기 를 첨부하고 아래처럼 지시합니다.

첨부한 자료에서 장소별 주차·걷기·계단 정보만 표로 정리해 줘.
자료에 없는 정보(입장료, 운영시간, 주차 요금 등)는 지어내지 말고 [확인 필요]라고 써 줘.

표 곳곳에 [확인 필요] 가 보이면 성공입니다. AI가 요금이나 시간을 숫자로 채웠다면 자료에 없는 것을 지어낸 것입니다. 실제 여행 전에는 공식 누리집에서 확인합니다.

💡 실제 자료(가족 단톡방 대화, 업무 문서 등)를 쓸 때는 이름·연락처·주소를 지우고 올립니다. 모듈 2에서 정한 "민감한 정보는 넣지 않는다" 원칙과 같습니다.

3-3. 폴더처럼 쓰기: 프로젝트 기능 (20분)

매번 같은 자료를 올리고 같은 설명을 반복하는 일을 없애는 기능입니다.

📁 프로젝트: "우리 가족 여행"
 ├─ 📄 지침(Instructions): "너는 우리 가족 여행 도우미야. 가족 조건을 늘 반영하고, 표 활용…"
 ├─ 📎 파일: PRD_경주 여행 준비물.md, 경주 여행 자료_관광지 안내.md, 경주 여행 후기_예시.md
 └─ 💬 대화 1, 대화 2, 대화 3 …  ← 모두 위 지침과 파일을 자동으로 참고

ChatGPT에도 같은 프로젝트 기능이 있습니다. 이 과정에서는 03 이후 Claude 하나로 진행합니다.

① 효과 보기: 팀 공유 프로젝트 (5분)

Claude Team에서는 프로젝트를 팀원과 공유할 수 있습니다. 미리 만들어 둔 "우리 가족 여행 실습" 프로젝트에는 예시 PRD, 관광지 안내, 후기 예시, 아래 "지침 예시"가 들어 있습니다.

  1. Claude 왼쪽 [Projects] → 팀 공유 목록에서 우리 가족 여행 실습 열기
  2. 파일도, 역할도 없이 한 줄만 입력해 보기:
    둘째 날 비 오면?
  3. 같은 프로젝트를 쓰는 옆 사람과 답을 비교해 보기

가족 이야기를 다시 하지 않았는데도 할머니 무릎, 아이 멀미 같은 가족 조건을 반영해 실내 일정을 표로 제안하고, 끝에 "다음에 할 일" 까지 붙어 나오면 지침과 파일이 제대로 동작하는 것입니다.

실제 업무에서는 부서 공용 자료(규정, 양식, 일정표)를 부서 공유 프로젝트 하나에 넣어 두면, 새로 온 직원도 같은 자료와 지침으로 AI를 쓸 수 있습니다.

② 만들기 연습: 내 업무 프로젝트 (10분)

만드는 연습은 내 업무 프로젝트 하나로 합니다. "교육 일정 관리", "출장·복무 정리"처럼 실제 내 업무 이름으로 만듭니다.

  1. 만들기: 왼쪽 사이드바 [Projects] → [+ 새 프로젝트] → 이름에 내 업무 이름, 설명은 비워도 됨 → [만들기]
  2. 지침 붙여넣기: 아래 [바로 해 보기]에서 내 업무와 가까운 예시를 고르거나 칸을 바꾼 뒤 [지침 복사] → 지침(Instructions) 칸에 붙여넣습니다. (아래 "지침 예시"를 복사해 가족 이야기를 내 업무로 바꿔도 됩니다)
  3. 짧게 물어보기: 프로젝트 안에서 대화를 시작하고 아래 한 줄을 입력합니다. 파일을 아직 넣지 않았어도 지침만으로 확인할 수 있습니다.
    이 프로젝트에서 내가 도움받을 수 있는 일 3가지를 제안하고, 각각 어떤 파일을 넣어 두면 좋을지 표로 알려 줘

지침에 적은 말투와 형식(표, "다음에 할 일")대로 답이 나오면 성공입니다. 시간이 부족하면 과정 뒤 과제(과제 안내 4번)로 합니다.

메뉴 이름과 위치는 서비스 업데이트에 따라 조금씩 바뀔 수 있습니다. 프로젝트 공유 범위(나만 / 팀 전체)는 프로젝트를 만들 때나 프로젝트 설정에서 정합니다.

지침(Instructions) 예시 — 복사해서 사용

"우리 가족 여행 실습" 프로젝트에 들어 있는 지침입니다. 내 업무 프로젝트에는 가족 내용을 내 업무에 맞게 바꿔 넣습니다.

너는 우리 가족 여행을 돕는 도우미야.
- 우리 가족: 나, 배우자, 아이(초등 3학년, 차멀미 있음), 할머니(75세, 무릎이 불편해 오래 걷기·계단이 어려움).
- 일정을 짤 때는 하루 2곳 이내로 하고, 계단·오르막이 많은 곳은 빼거나 대안을 함께 적는다.
- 편하게 반말로 답해도 된다. 일정·준비물·장소 비교는 표로 정리한다.
- 프로젝트에 올린 파일 내용을 우선 근거로 삼고, 확인되지 않은 요금·운영시간은 [확인 필요]로 표시한다.
- 답 끝에 "다음에 할 일" 1~3개를 제안한다.

③ 내 업무 폴더 만들기 (2분)

AI에 건넬 자료가 흩어져 있으면 매번 찾느라 시간이 듭니다. 파일 탐색기에서 문서 안에 아래 폴더를 만들어 둡니다. 이 과정에서 만드는 PRD, 결과물, 스킬은 모두 여기에 모읍니다.

📁 AI업무자료
 ├─ 📁 01_기획(PRD)
 ├─ 📁 02_참고자료
 ├─ 📁 03_AI결과물
 ├─ 📁 98_스킬
 └─ 📁 99_프롬프트

💡 이 폴더를 메모 도구 옵시디언으로 열면 MD 파일을 더 편하게 보고 고칠 수 있습니다. 수업에서는 다루지 않고, 익숙해진 뒤 써 볼 수 있게 선택 자료로 남겨 두었습니다(04 옵시디언 (선택)).

과정 뒤에 더 해 보기 혼자 해 보기 (과정 뒤): "우리 가족 여행" 프로젝트 직접 만들기

팀 공유 프로젝트와 같은 것을 내 프로젝트로 직접 만들어 봅니다.

  1. 왼쪽 사이드바 [Projects] → [+ 새 프로젝트]
  2. 이름 우리 가족 여행, 설명은 비워도 됨 → [만들기]
  3. 오른쪽 프로젝트 지식(Project knowledge) 의 [+] → 3-2에서 AI에게 첨부했던 그 파일 PRD_경주 여행 준비물.md (다운로드 폴더) 추가 (후기 예시·관광지 안내 파일도 받았다면 함께)
  4. 지침(Instructions) 에 위 "지침 예시"를 복사해 붙여넣기 → 프로젝트 안에서 둘째 날 비 오면? 입력

실습에서는 3-2에서 첨부했던 파일을 그대로 넣습니다. 실제 업무 프로젝트라면 교육 일정표, 운영 규정 같은 파일을 넣습니다. AI의 답변을 따로 저장할 필요는 없습니다.

💼 업무에서는? 같은 5요소로 안내문·공문 초안을 쓰고, 규정·지침 파일을 건네 요약을 받습니다. 자주 하는 업무는 업무 프로젝트 하나에 자료와 지침을 모아 두면 매번 설명하지 않아도 됩니다.

🪜 업무 자동화 사다리: ① 잘 시키기 ✔ → ② 자료 맡기기 ✔ → ③ 방법 맡기기 → ④ 클릭 맡기기 → ⑤ 내 도구 만들기 → ⑥ 저절로 돌아가게
