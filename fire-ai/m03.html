  • 지뢰찾기 화면 그림 (몸풀기 화면 캡처용)내려받기 열어 보기

이 모듈의 핵심 한 줄:

AI의 답은 내가 건네는 것(질문 + 자료 + 맥락)만큼 좋아진다.

건네는 방법 비유 이번 모듈
프롬프트 업무 지시서 3-1
파일 참고 서류 첨부 3-2
프로젝트(폴더) 담당자 전용 서류함 + 업무 매뉴얼 3-3

3-0. 몸풀기: 말로 만드는 프로그램, HTML 한 장 (15분)

본격적으로 시작하기 전에 AI에게 프로그램을 하나 시켜 봅니다. 코딩은 몰라도 됩니다.

알아 둘 것: AI가 만든 HTML 파일 하나 = 설치 없이 바로 쓰는 프로그램

  • 내려받은 .html 파일을 더블클릭하면 인터넷 창(크롬·엣지)에서 바로 열립니다.
  • 설치도, 관리자 권한도, 인터넷 연결도 필요 없습니다. 파일 하나라 동료에게 그대로 건넬 수 있습니다.
  • 2일차에는 이 파일을 웹 주소로 공개하고(09), 내 업무 화면을 같은 방법으로 만듭니다(12).

① 함께: 공학용 계산기 (Claude, 5분)

Claude 새 채팅에 입력하세요.

공학용 계산기를 HTML 파일 하나로 만들어 줘.
- 사칙연산, 괄호, 제곱, 제곱근, sin·cos·tan(도 단위), log, π
- 버튼은 크게, 키보드로 숫자 입력도 되게
- 계산 기록을 아래에 5줄까지 보여 줘
- 외부 라이브러리 없이 파일 하나로
  1. 오른쪽 미리보기에서 바로 눌러 봅니다. sin 30 = 0.5, √2 ≈ 1.414 가 나오면 성공.
  2. 미리보기 오른쪽 위 다운로드(또는 복사 → 메모장 → 계산기.html로 저장)로 바탕화면에 저장합니다.
  3. 바탕화면의 계산기.html을 더블클릭 → 인터넷 창에서 열리면 내 PC의 프로그램이 된 것입니다.
  4. 고치고 싶으면 말로: "버튼 색을 빨간색 계열로", "단위 변환(℃↔℉) 버튼 추가"

② 골라서 하나: 게임 만들기 (8분)

A. 폭탄 뽑기 (ChatGPT): 회식·워크숍 복불복용

회식·워크숍에서 쓸 '폭탄 뽑기' 게임을 HTML 파일 하나로 만들어 줘.
- 참가자 이름을 쉼표로 입력하면 차례가 순서대로 돌아가
- 카드 12장 중 1장에 폭탄이 숨어 있어. 차례인 사람이 카드를 누르면 뒤집혀
- 폭탄이 나오면 화면이 흔들리고 "펑! ○○○ 당첨"을 크게 보여 줘
- 다시 하기 버튼, 카드 수 조절(6~30장)
- 외부 라이브러리 없이 파일 하나로
캔버스에서 바로 실행해 볼 수 있게 해 줘.
  • 답이 코드로만 나오면 오른쪽 위 미리보기(실행) 를 누르거나 "캔버스로 열어 줘"라고 이어서 입력합니다.

B. 지뢰찾기 (Claude, 화면 캡처로 시키기): 그림 한 장으로 설명하기

  1. 이 모듈 실습 파일의 지뢰찾기 화면 그림을 열어 보기 합니다. → 지뢰찾기 화면 그림
  2. Windows 키 + Shift + S → 그림 부분을 마우스로 끌어 화면 캡처합니다.
  3. Claude 새 채팅 입력창에 Ctrl + V 로 붙여 넣고 아래를 함께 보냅니다.
붙여 넣은 화면처럼 동작하는 지뢰찾기 게임을 HTML 파일 하나로 만들어 줘.
- 9×9 칸, 지뢰 10개, 첫 클릭은 절대 지뢰가 아니게
- 왼쪽 클릭은 열기, 오른쪽 클릭은 깃발, 빈칸을 열면 주변도 자동으로 열기
- 위쪽에 남은 지뢰 수, 걸린 시간, 다시 하기 버튼(웃는 얼굴)
- 색과 칸 테두리는 그림과 비슷하게
  • 긴 설명 대신 그림 한 장을 건넸습니다. 업무에서도 똑같습니다. 기존 양식, 엑셀 표, 오류 창을 캡처해 붙여 넣으면 AI가 훨씬 정확히 알아듣습니다(3-2에서 이어집니다).

③ 정리 (2분)

  • 옆 사람과 비교해 보세요. 같은 AI인데 지시가 다르면 결과가 다릅니다. 그 차이를 만드는 방법이 바로 다음 3-1입니다.
  • 오늘 만든 것은 놀이였지만, 2일차에는 같은 방법으로 강의평가 결과 화면을 만듭니다.
  • 조심할 것: 출처를 모르는 .html 첨부파일은 열지 않습니다(피싱에 자주 쓰입니다). 내가 만들었거나 믿을 수 있는 사람이 준 파일만 엽니다.

"확인했습니다", "수고하셨습니다", "잠시만요" 이모티콘 3개를 만들어 줘.

3-1. 프롬프트: 좋은 지시의 5요소 (30분)

공식: 역할 · 목표 · 맥락 · 형식 · 조건

요소 질문 예시
역할 누구처럼 답할까? "너는 소방학교 교육 담당자야"
목표 무엇을 원하나? "강의평가 참여 요청 안내문을 써 줘"
맥락 배경은? "제12기 40명, 18과목, 10월 2일 17시 마감, 익명"
형식 어떤 모양으로? "제목 + 4개 항목 글머리표, 일정은 표"
조건 지킬 것은? "존댓말, 3분이면 끝난다는 점 강조, 과장 금지"

실습: 나쁜 프롬프트 vs 좋은 프롬프트

나쁜 예

강의평가 안내문 써줘

좋은 예

[역할] 너는 소방학교 교육운영 담당자야.
[목표] 신임소방관 교육생에게 보낼 강의평가 참여 요청 안내문을 써 줘.
[맥락] 제12기 교육생 40명, 3주 과정 18과목. 평가 기간 9월 28일~10월 2일 17시, 휴대폰으로 참여, 익명, 약 3분 소요.
[형식] 제목 1줄, 인사말 2줄, 핵심 안내 4개 항목(글머리표), 평가 일정은 표로.
[조건] 정중한 존댓말, A4 반 장 이내, 확인되지 않은 내용은 [확인 필요]로 표시.

💡 둘을 Claude에서 새 채팅 2개로 나눠 넣고 나란히 비교합니다. 대부분 "좋은 예"가 바로 쓸 수 있는 결과를 냅니다.

첨삭 예시: 공식은 지켰는데 맥락이 빈 프롬프트

교육생 초안

[역할] 너는 교육운영 담당자야.
[목표] 강의평가 결과 보고 메일 써 줘.
[맥락] 이번 기수 강의평가 끝났음.
[형식] 메일로.
[조건] 존댓말.

아래 질문에 스스로 답하며 맥락을 채워 보세요.

요소 강사 질문 고친 내용
역할 "누가 누구에게 보내나요?" 교육운영팀 담당자 → 교육운영과장에게 보고
목표 "보고만? 요청도 있나요?" 결과 보고 + 개선 필요 과목 교관 면담 요청
맥락 "숫자와 날짜는요?" 제12기, 18과목, 응답 38/40명, 전체 평균 4.2, 3.5 미만 2과목 (화재진압 전술 이교관 반 3.3, 소방 관계법규 3.1)
형식 "메일의 어떤 부분이 필요한가요?" 제목 1줄, 본문 3문단, 개선 필요 과목은 표
조건 "지어내면 안 되는 것은요?" 존댓말, 개선 원인과 면담 일정은 [확인 필요]로

고친 프롬프트

[역할] 너는 소방학교 교육운영팀 담당자야. 교육운영과장님께 보고 메일을 쓰는 상황이야.
[목표] 제12기 강의평가 결과를 보고하고, 개선 필요 과목의 교관 면담을 요청하는 메일을 써 줘.
[맥락] 신임소방관 제12기 18과목, 응답 38명/40명, 전체 평균 4.2점(5점 만점).
       평균 3.5 미만 2과목: 화재진압 전술(이교관 반) 3.3, 소방 관계법규(최교관) 3.1.
[형식] 메일 제목 1줄, 본문 3문단(결과 요약 / 개선 필요 과목 / 요청 사항), 개선 필요 과목은 표로.
[조건] 정중한 존댓말. 개선 원인이나 면담 일정처럼 내가 주지 않은 정보는 [확인 필요]로 표시해.

핵심 멘트: "AI는 우리 과정의 평균이 몇 점인지 절대 알 수 없습니다. 내가 아는 사실은 내가 건네야 합니다."

대화로 다듬기 (되묻기 기술)

한 번에 완벽하게 쓰려고 하지 않아도 됩니다. 이어서 지시합니다.

  • "3번 항목을 더 짧게"
  • "표를 날짜순으로 정렬해 줘"
  • "문자 메시지용으로 200자 이내 버전도 만들어 줘"
  • "내가 빠뜨린 정보가 있으면 먼저 질문해 줘" ← 가장 유용한 한 문장

3-2. 파일 건네기 (30분, 자유의견 요약 포함)

방법

  • 입력창의 [+] 버튼(또는 클립 아이콘) → 파일 선택
  • 또는 파일을 입력창으로 끌어다 놓기(드래그 앤 드롭)

어떤 파일이 잘 되나?

잘 됨 주의
PDF, Word, 텍스트(.txt), Markdown(.md), 엑셀/CSV, 이미지(사진·캡처) 스캔한 흐린 PDF, 암호 걸린 파일, 아주 큰 파일

💡 MD 파일이 특히 좋은 이유: 제목·목록·표 구조가 그대로 전달되어 AI가 문서 구조를 정확히 이해합니다. 그래서 모듈 4에서 옵시디언으로 MD 파일을 만듭니다.

실습 프롬프트 (파일 첨부 후)

첨부한 문서를 읽고
1) 핵심 내용 3줄 요약
2) 실제로 해야 할 일(To-do) 목록
3) 문서에서 모호하거나 빠진 부분
을 표로 정리해 줘. 문서에 없는 내용은 지어내지 마.

연습 파일: 예시 PRD 파일 를 첨부해 보세요.

  • 파일을 올리면 입력창 위에 파일 이름 카드가 생깁니다. 카드만 보내지 말고 파일 + 지시를 함께 보냅니다.

🔍 AI가 찾아 주는 구멍: "교관이 여러 명인 과목"

요약표의 3번 "빠진 부분" 에서 AI는 보통 이 PRD의 구멍을 찾아냅니다. 대표적인 것이 교관 구분입니다. PRD 배경에는 "일부 과목은 교관 2~3명이 반별로 나눠 강의한다"고 적혀 있는데, 집계는 과목별로만 하게 되어 있습니다. 그러면 한 교관은 4.7점, 다른 교관은 3.3점이어도 평균 4.0으로 섞여 "양호" 로 나오고, 정작 개선이 필요한 반이 보고서에서 사라집니다.

추가 실습: 서술형 의견 요약 (시간이 남으면)

강의평가에서 시간이 많이 걸리는 일 중 하나가 자유의견 정리입니다. 네이버 폼 결과 엑셀의 서술형 칸을 한 줄씩 읽어야 하기 때문입니다. 예시 파일 자유의견 예시 파일 를 첨부하고 아래처럼 지시합니다.

첨부한 강의평가 자유의견을 과목별로 정리해 줘.
- 과목마다 "좋았던 점 / 바라는 점"을 1~2줄로 요약
- 여러 과목에 공통으로 나온 의견은 따로 모아 줘
- 원문에 없는 의견은 만들지 말고, 표로 정리해 줘

💡 실제 평가 자료를 쓸 때는 이름·연락처를 지우고 올립니다. 모듈 2에서 정한 "민감한 정보는 넣지 않는다" 원칙과 연결하세요.

3-3. 폴더처럼 쓰기: 프로젝트 기능 (20분)

매번 같은 자료를 올리고 같은 설명을 반복하는 일을 없애는 기능입니다.

📁 프로젝트: "교육운영 업무"
 ├─ 📄 지침(Instructions): "너는 소방학교 교육운영 담당자 보조야. 항상 존댓말, 표 활용…"
 ├─ 📎 파일: 교육 일정표.md, 운영 규정.pdf, PRD_강의평가 결과보고.md
 └─ 💬 대화 1, 대화 2, 대화 3 …  ← 모두 위 지침과 파일을 자동으로 참고

  1. 왼쪽 사이드바 [Projects] → [+ 새 프로젝트]
  2. 이름 내 강의평가 실습, 설명은 비워도 됨 → [만들기]
  3. 오른쪽 프로젝트 지식(Project knowledge) 의 [+] → 3-2에서 AI에게 첨부했던 그 파일 PRD_강의평가 결과보고.md (다운로드 폴더) 추가 (자유의견 예시 파일도 받았다면 함께)
  4. 지침(Instructions) 에 바로 아래 "지침 예시"를 복사해 붙여넣기 → 프로젝트 안에서 대화 시작

위 그림의 교육 일정표·운영 규정은 실제 업무에서 넣을 파일의 예입니다. 실습에서는 3-2에서 첨부했던 PRD 파일을 그대로 넣습니다. AI의 답변을 따로 저장할 필요는 없습니다.

메뉴 이름과 위치는 서비스 업데이트에 따라 조금씩 바뀔 수 있습니다. 프로젝트 공유 범위(나만 / 팀 전체)는 프로젝트를 만들 때나 프로젝트 설정에서 정합니다.

지침(Instructions) 예시 — 복사해서 사용

너는 소방학교 교육운영 담당자를 돕는 보조자야.
- 항상 정중한 존댓말로 답한다.
- 프로젝트에 올린 파일 내용을 우선 근거로 삼고, 파일에 없는 내용은 [확인 필요]로 표시한다.
- 일정·인원·준비물은 표로 정리한다.
- 답 끝에 "다음에 할 일" 1~3개를 제안한다.

효과 확인: 짧게 물어보기

프로젝트 안에서 파일도, 역할도 없이 한 줄만 입력합니다.

강의평가 집계 기능을 정리해 줘

PRD 내용을 근거로 표로 정리하고, 끝에 "다음에 할 일" 까지 붙어 나오면 지침과 파일이 제대로 동작하는 것입니다.

Team 계정: 팀 공유 프로젝트

Claude Team에서는 프로젝트를 팀원과 공유할 수 있습니다. 강사가 미리 만든 "강의평가 결과보고 실습" 프로젝트에는 예시 PRD, 자유의견 예시, 아래 "지침 예시"가 들어 있습니다.

  1. Claude 왼쪽 [Projects] → 팀 공유 목록에서 강의평가 결과보고 실습 열기
  2. 파일 없이 한 줄만 입력해 보기: 강의평가 집계 기능을 정리해 줘
  3. 같은 프로젝트를 쓰는 옆 사람과 답을 비교해 보기

실제 업무에서는 부서 공용 자료(규정, 양식, 일정표)를 팀 프로젝트 하나에 넣어 두면, 새로 온 직원도 같은 자료와 지침으로 AI를 쓸 수 있습니다.

마지막으로 내 업무용 프로젝트를 하나 더 만들어 봅니다. 위의 실습용과는 별개로, "교육 일정 관리", "출장·복무 정리"처럼 실제 내 업무 이름으로 만들고 지침을 내 업무에 맞게 바꿔 넣어 보세요. 시간이 부족하면 숙제로 합니다.

내 업무용 프로젝트의 효과 확인도 한 줄로 합니다. 파일을 아직 넣지 않았어도 지침만으로 확인할 수 있습니다.

이 프로젝트에서 내가 도움받을 수 있는 일 3가지를 제안하고, 각각 어떤 파일을 넣어 두면 좋을지 표로 알려 줘

지침에 적은 말투와 형식(표, "다음에 할 일")대로 답이 나오면 성공입니다.
