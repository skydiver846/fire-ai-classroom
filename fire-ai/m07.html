7-1. Gemini Notebook (약 25분)

💡 이름이 바뀌었습니다. 2026년 7월부터 NotebookLM 의 새 이름이 Gemini Notebook 입니다. 기능과 만들어 둔 노트북은 그대로입니다. 인터넷 검색이나 예전 자료에서는 NotebookLM이라는 이름도 계속 보입니다.

시작하기

  1. "업무" Chrome 프로필 창에서 notebooklm.google.com 접속
  2. Google 계정으로 로그인 (별도 가입 없음)
  3. [새 노트북 만들기] (또는 Create new)

소스(자료) 넣기

  1. 소스 추가 창에서 파일 업로드 선택
  2. 옵시디언 보관소 문서 > AI업무자료 > 01_기획(PRD) 의 PRD .md 파일 선택
  3. 02_참고자료 의 강의평가_자유의견_예시.md 도 함께 추가 (없으면 자유의견 예시 파일 를 받아서)
  4. 그 밖에 함께 참고할 자료가 있으면 추가 (PDF, 텍스트, 웹사이트 주소, YouTube 링크, Google 문서 등)

💡 MD 파일을 바로 올릴 수 있다는 것이 옵시디언과 Gemini Notebook 조합의 장점입니다. 형식 변환 없이 옵시디언 노트를 그대로 넣습니다.

해 볼 것

오디오 개요 스튜디오 영역의 오디오 개요 생성 두 사람이 PRD를 대화로 설명하는 팟캐스트형 음성

슬라이드 · 인포그래픽 스튜디오에서 생성 (아래 7-1-1) 발표 자료와 한 장 요약 그림
보고서·학습 가이드 보고서 메뉴에서 형식 선택 브리핑 문서, 학습 가이드, FAQ 등

메뉴 이름과 위치는 업데이트로 바뀔 수 있습니다. 오디오 개요는 생성에 몇 분 걸리고, 출력 언어 설정을 한국어로 확인하세요.

7-1-1. 슬라이드와 인포그래픽 만들기 (15분)

같은 자료(PRD + 자유의견)로 결과보고 발표 자료(슬라이드) 와 한 장짜리 요약 그림(인포그래픽) 을 만듭니다. Gemini Notebook은 넣은 자료(소스)만 근거로 만들기 때문에, PRD에 없는 내용이 끼어들 가능성이 적습니다.

① 슬라이드 (Slide Deck)

  1. 오른쪽 스튜디오 → 슬라이드(Slide Deck) 옆의 연필(맞춤 설정) 아이콘
  2. 설정 고르기
항목 고를 것 뜻
형식 발표자용 슬라이드(Presenter Slides) 글자가 적고 말로 설명하는 발표용. 나눠 줄 자료면 자세한 자료(Detailed Deck)
언어 한국어
길이 짧게 결재·보고용은 짧을수록 좋음
프롬프트 아래 지시문 누구에게, 몇 장, 무엇을 강조할지 
교육운영과장님께 "제12기 강의평가 결과와 집계 도구 도입"을 보고하는 5장짜리 발표 자료로 만들어 줘.
1장: 지금의 문제(네이버 폼 결과를 엑셀로 다시 집계, 반나절), 2장: 자유의견에서 나온 주요 개선 요구,
3장: 집계 도구의 핵심 기능, 4장: 이번에 하지 않는 것, 5장: 성공 기준과 다음 단계.
소스에 없는 숫자는 쓰지 마.
  1. [생성] → 몇 분 기다리기 (오디오 개요와 함께 눌러 두면 시간을 아낄 수 있음)
  2. 고치기: 고치고 싶은 장을 열고 연필 아이콘 → "3장 글자를 더 줄여 줘"처럼 말로 고칩니다
  3. 내려받기: ⋮ → PDF 또는 PowerPoint(.pptx). PPTX는 PowerPoint에서 글자를 직접 고칠 수 있습니다

② 인포그래픽 (Infographic)

  1. 스튜디오 → 인포그래픽 옆 연필 아이콘
  2. 방향(가로 / 세로 / 정사각형), 언어: 한국어, 프롬프트 입력
강의평가 결과보고가 만들어지는 순서(휴대폰으로 평가 입력 → 과목·교관별 자동 집계
→ 평균 3.5 미만 "개선 필요" 표시 → 결과보고서 작성)를 4단계 흐름 그림으로 만들어 줘.
자유의견에서 가장 많이 나온 개선 요구 3개를 아래에 함께 넣어 줘.
소방 적색을 강조색으로, 글자는 크게.
  1. [생성] → 완성되면 이미지로 저장

③ 결과 검토 (꼭 하기)

□ PRD에 없는 숫자나 기능이 들어가지 않았나?
□ 그림 속 한글에 오타나 깨진 글자가 없나? (그림으로 그린 글자라 틀릴 수 있음)
□ "범위 밖"으로 정한 기능이 들어가 있지 않나?
□ 개인정보(실명·연락처)가 보이지 않나?

💡 7-2의 Claude "발표 개요"와 비교해 보세요. Claude는 뼈대(장별 제목·문장) 를 주고, Gemini Notebook은 완성된 슬라이드를 줍니다. 뼈대로 생각을 정리하고, 슬라이드로 바로 보고하는 식으로 함께 쓰면 좋습니다.

내려받은 PDF·PPTX·이미지는 옵시디언 03_AI결과물 폴더에 함께 보관합니다. 옵시디언 안에서 PDF와 이미지도 열어 볼 수 있습니다.

실습 질문 (Gemini Notebook 채팅창)

이 PRD에서 "범위 밖"으로 정한 것과, 성공 기준을 표로 정리해 줘.
그리고 PRD 안에서 서로 모순되거나 빠진 부분이 있으면 알려 줘.

볼 것 두 가지

  1. 출처 번호 [1], [2] 를 눌러 PRD의 어느 문장을 근거로 했는지 확인 (ChatGPT·Claude와 가장 다른 점)
  2. 불일치 찾기: 모듈 5에서 4번 칸만 "과목 + 교관"으로 고쳤다면, 5번 화면 흐름은 아직 "과목 [____] 만족도 [▼]"만 있고 교관 입력칸이 없습니다. Gemini Notebook이 이 불일치를 짚어 주면 옵시디언에서 5·7번 칸을 고치고 v0.3 으로 올립니다.
 옵시디언에서 PRD 수정 ─▶ Gemini Notebook에 다시 넣어 검토 ─▶ 불일치 발견 ─▶ 다시 수정

⚠️ Gemini Notebook에 올린 파일은 복사본입니다. 옵시디언에서 PRD를 고쳐도 Gemini Notebook 안의 파일은 바뀌지 않으니, 다시 검토하려면 기존 소스를 지우고 새로 업로드합니다. 교육생이 가장 헷갈리는 부분입니다.

AI가 불일치를 못 찾으면 "4번과 5번 칸의 입력 항목이 서로 같은지 비교해 줘"처럼 구체적으로 다시 묻게 하세요.

7-2. Claude로 결재 보고서 · 발표 개요 만들기 (약 10분)

PRD.md 를 첨부(또는 모듈 3의 프로젝트에 추가)한 뒤:

① 결재용 보고서: 집계 도구 도입

첨부한 PRD를 바탕으로 상급자 결재용 1페이지 보고서를 써 줘.
형식: 제목 / 추진 배경 / 주요 내용 / 기대 효과 / 향후 일정(표).
PRD에 없는 숫자는 만들지 말고 [확인 필요]로 표시해.

💡 모듈 6-4에서 eval-report 스킬을 만들었다면 자유의견 파일을 첨부하고 "제12기 강의평가 결과보고서 써 줘" 한 문장으로 결과보고서 자체도 만들어 보세요. 점수 숫자는 아직 없으니 [확인 필요]로 나오는 것이 정상입니다. 숫자는 7-3의 화면이 채워 줍니다.

② 발표 개요 (시간이 남으면)

이 PRD로 10분 발표를 하려고 해. 슬라이드 7장 구성으로
장마다 제목, 핵심 문장 1개, 들어갈 그림 아이디어를 표로 정리해 줘.

7-3. Claude로 만들기 — 프로토타입 (약 15분)

PRD를 첨부하고 실제로 눌러 볼 수 있는 화면을 만들게 합니다.

첨부한 PRD를 읽고, 핵심 기능(필수)만 동작하는 프로토타입 웹 화면을 만들어 줘.
- HTML 파일 하나로, 설치 없이 브라우저에서 바로 열리게
- 휴대폰 화면에서도 보기 좋게
- "범위 밖" 기능은 넣지 마
- 처음 열었을 때 예시 데이터 3개를 보여 줘
  • Claude가 만든 화면은 대화 옆 미리보기 창에서 바로 눌러 볼 수 있습니다.
  • 미리보기 창이 빈 화면이면: 미리보기는 claudeusercontent.com 이라는 별도 주소에서 그려지는데, 행정망에서 이 주소가 막혔을 수 있습니다. 코드를 복사해 메모장에 index.html(UTF-8)로 저장하고 Chrome에서 열면 똑같이 동작합니다.
  • 답이 중간에 끊기면 "계속해 줘" 라고 입력합니다. 사용량 한도 안내가 뜨면 ChatGPT에 같은 지시를 넣어 진행합니다(ChatGPT는 캔버스에서 미리보기).
  • 마음에 들지 않는 부분은 대화로 고칩니다: "버튼을 더 크게", "개선 필요 기준을 3.0 미만으로"
  • 결과 코드를 복사해 메모장에 붙여넣고 index.html 로 저장하면 내 컴퓨터에서도 열립니다.

Team 계정은 사용량 여유가 있으니 "버튼 크게", "개선 필요 기준 3.0" 같은 수정 요청을 여러 번 해 보며 PRD와 화면을 맞춰 가는 연습을 충분히 합니다.

PRD의 성공 기준으로 검사하기

미리보기 화면에서 PRD 7번 칸을 그대로 시험해 봅니다.

성공 기준 해 보기 결과
과목·교관·만족도로 평가가 기록된다 화재진압 전술, 김교관, 5 → 평가 제출 ☐
평균 3.5 미만은 "개선 필요"로 표시된다 화재진압 전술, 이교관, 3 을 두 번 제출 ☐
만족도를 고르지 않으면 막힌다 만족도 비우고 제출 ☐
같은 과목이라도 교관이 다르면 따로 집계된다 결과표에 김교관·이교관이 두 줄로 나오는지 ☐

7-4. 결과물 정리 — 다시 옵시디언으로

📁 AI업무자료
 ├─ 📁 01_기획(PRD)      ← PRD_강의평가 결과보고.md (원본)
 ├─ 📁 02_참고자료       ← 강의평가_자유의견_예시.md
 ├─ 📁 03_AI결과물

 │   ├─ 발표 개요.md        (Claude)

 │   └─ 프로토타입/index.html (Claude)

순환 구조: 결과를 보고 → PRD 수정 → 다시 생성. PRD가 좋아질수록 모든 결과물이 함께 좋아집니다.

자주 막히는 곳

상황 해결
Gemini Notebook에서 MD 파일이 안 보임 파일 선택 창 오른쪽 아래 형식이 "모든 파일"인지 확인
슬라이드·인포그래픽 그림 속 한글이 틀림 그림으로 그린 글자라 생깁니다. 연필 아이콘으로 "3장 제목 글자를 정확히 '○○'로"처럼 고치거나, PPTX로 받아 PowerPoint에서 직접 고치기
오디오 개요가 영어로 나옴 출력 언어 설정(설정 메뉴)을 한국어로 변경 후 다시 생성
프로토타입 HTML이 메모장 저장 후 안 열림 저장 시 "파일 형식: 모든 파일", 인코딩 UTF-8 선택, 확장자 .html 확인
결과물마다 내용이 다름 정상입니다. 기준은 PRD. 결과물은 PRD와 대조해 검토
