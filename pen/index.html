강사 판서 도구

줌잇처럼 어느 웹 화면 위에나 펜 · 형광펜 · 사각형 · 원 · 화살표로 표시합니다. Claude, GitHub, Vercel, Firebase, 교안 어디서나.

① 크롬 확장 프로그램으로 설치 권장

아이콘 한 번, 또는 Alt+Shift+D 로 어느 탭에서나 켜고 끕니다.

확장 프로그램 내려받기 (ZIP)

  1. 내려받은 ZIP을 오른쪽 클릭 → 압축 풀기. jg-pen-tool 폴더가 생깁니다. 이 폴더는 지우지 말고 둡니다 (예: 문서 폴더로 옮기기)
  2. Chrome 주소창에 chrome://extensions 를 넣고 엽니다
  3. 오른쪽 위 개발자 모드 스위치를 켭니다
  4. 왼쪽 위 [압축해제된 확장 프로그램을 로드합니다] → jg-pen-tool 폴더를 고릅니다
  5. 주소창 오른쪽 퍼즐 조각(확장 프로그램) 아이콘 → 강사 판서 도구 옆 핀을 눌러 고정합니다
  6. 단축키를 바꾸려면 chrome://extensions/shortcuts

행정망 PC에서 개발자 모드가 막혀 있으면 아래 ② 즐겨찾기 버튼을 씁니다. 크롬 설정 화면(chrome://…), 크롬 웹 스토어, PDF 보기 화면에서는 확장이 들어갈 수 없어 판서가 켜지지 않습니다.

② 즐겨찾기 버튼으로 설치 (확장이 막힌 PC)

  1. Chrome에서 Ctrl+Shift+B 로 즐겨찾기 표시줄을 켭니다
  2. 아래 단추를 마우스로 즐겨찾기 표시줄로 끌어다 놓습니다 (누르지 말고 끌기)
  3. 판서할 화면에서 즐겨찾기 표시줄의 판서를 누르면 켜지고, 한 번 더 누르면 꺼집니다

✏️ 판서

일부 사이트는 보안 설정 때문에 즐겨찾기 버튼이 동작하지 않을 수 있습니다. 그런 곳은 ① 확장 프로그램을 쓰세요.

③ 쓰는 법

켜면 바로 펜입니다. 오른쪽 위 도구상자의 판서 도구 줄을 끌면 위치를 옮길 수 있습니다(사이트마다 기억).
