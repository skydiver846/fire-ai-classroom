단계 2. 계획 받기 (10분)

1차 복습: 바로 만들게 하지 않고 계획부터 받습니다. 계획 단계에서 잘못을 찾으면 1분, 다 만든 뒤면 10분.

claude.ai/code → 저장소 team-tool 선택 → 아래 칸에 PRD를 붙여넣어 보냅니다.

아래 PRD를 저장소에 PRD.md 로 저장하고 커밋해 줘. 그다음 바로 만들지 말고 계획만 알려 줘.

이번 v0.1의 약속:
- 화면은 index.html 하나로 만들어 줘. 휴대폰에서 잘 보이게.
- 데이터는 아직 진짜로 연결하지 않아.
  · DB 트랙이면: 기록을 이 브라우저(localStorage)에 저장하되, 저장·불러오기 코드를 함수 몇 개로 한곳에 모아 줘.
    다음 단계에서 그 부분만 공용 장부(Firestore)로 바꿀 거야.
  · 다듬기 트랙이면: 기록을 이 브라우저(localStorage)에만 저장해 줘.
  · API 트랙이면: 진짜 자료 대신 "예시 자료"를 넣고 화면에 "예시 자료"라고 표시해 줘.
    자료를 받아 오는 코드는 함수 하나로 모아 줘. 다음 단계에서 그 함수만 진짜 주소로 바꿀 거야.
- 외부 사이트에서 무언가를 불러오지 마.

계획에는 이것만 알려 줘:
1. 화면 그림 (글자로 대충)
2. 핵심 기능 3줄
3. 저장할 칸(또는 받아 올 값)의 이름과 종류 표
4. 나에게 확인할 질문

[여기에 PRD 붙여넣기]

💡 왜 가짜 자료로, 함수 한곳에? 홀(화면)이 주문서를 내는 창구를 한곳으로 모아 두면, 3교시에는 그 창구의 주문 받을 곳만 수첩 → 장부(또는 우리 주방)로 바꾸면 됩니다. 화면 전체를 다시 만들지 않아 고장이 적습니다.

계획을 PRD와 비교합니다. PRD에 없는 기능이 끼어 있으면 "○○는 빼 줘". 답한 내용 중 중요한 것은 "이 답을 PRD.md에도 반영해 줘".

단계 4. v0.1 결재하고 배포 (15분)

1차 복습: PR = 결재 요청서. Claude Code에서 [Create PR] 로 올리고, GitHub에서 [Merge] 로 결재합니다.

4-1. 결재 (5분)

  1. Claude Code 채팅 옆 패널의 Changes 카드 → [Create PR] (패널이 안 보이면 세션 제목 줄의 패널 아이콘 또는 ⋮)
  2. 카드에 생긴 결재 요청서를 눌러 GitHub 화면 → [Merge pull request] → [Confirm merge] → 보라색 Merged

4-2. Vercel 연결 (10분, 이 저장소는 처음 한 번)

  1. vercel.com → 로그인(1차처럼 [Continue with GitHub]) → 오른쪽 위 [Add New…] → [Project]
  2. Import Git Repository 목록에서 team-tool 옆 [Import]
    • 목록에 없으면: 목록 아래 Adjust GitHub App Permissions → Repository access 에 team-tool 추가 → [Save] → 돌아와서 다시
  3. Project Name 칸을 주소로 쓸 이름으로 바꿉니다. 예) gear-check-hong → 주소가 https://gear-check-hong.vercel.app 이 됩니다
    • Framework Preset 은 Other, 나머지 설정은 그대로
  4. [Deploy] → 1분쯤 뒤 축하 화면이 나오면 [Continue to Dashboard] → Domains 에 적힌 ○○.vercel.app 주소를 엽니다
  5. 휴대폰으로 주소를 열어 봅니다 (PC Chrome에서 오른쪽 클릭 → QR 코드 생성)

💡 이제 GitHub에서 결재(Merge)할 때마다 Vercel이 저절로 다시 배포합니다. 결재 요청서(PR)를 올리면 결재 전 미리보기(Preview) 주소도 저절로 생깁니다.

4-3. 교안 공모 · 투표 페이지 2번에 v0.1 주소를 제출합니다. 나중에 고친 뒤 다시 내면 덮어씁니다. ✅ 점검 2 (2교시 끝)

막히면 해결
배포 주소가 Page not found "index.html을 저장소 맨 위로 옮겨 줘" → 결재
주소 이름이 이미 있다고 함 뒤에 숫자나 이니셜. 이미 만들었으면 Settings → Domains 에서 ○○.vercel.app 옆 [Edit]
결재했는데 화면이 그대로 1~2분 뒤 새로고침. Vercel 프로젝트의 Deployments 에서 맨 위가 초록 Ready 인지 확인
배포 화면에 Build Failed Framework Preset 이 Other 인지 확인. Claude Code에 "Vercel 배포가 실패했어, 빌드 없이 index.html만 배포되게 고쳐 줘"
