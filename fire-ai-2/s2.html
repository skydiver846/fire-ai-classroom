2-2. PRD 붙여 계획 요청하기

아래를 복사해 맨 아래 [여기에 PRD 붙여넣기] 자리에 메모장의 PRD를 통째로 붙여 보냅니다.

아래 PRD를 저장소에 PRD.md 로 저장하고 커밋해 줘. 그다음 바로 만들지 말고 계획만 알려 줘.

이번 v0.1의 약속:
- 화면은 index.html 하나로 만들어 줘. 휴대폰에서 잘 보이게.
- 데이터는 아직 진짜로 연결하지 않아.
  · DB 트랙이면: 기록을 이 브라우저(localStorage)에 저장하되, 저장·불러오기 코드를 함수 몇 개로 한곳에 모아 줘.
    다음 단계에서 그 부분만 공용 장부(Firestore)로 바꿀 거야.
  · API 트랙이면: 진짜 자료 대신 "예시 자료"를 넣고 화면에 "예시 자료"라고 표시해 줘.
    자료를 받아 오는 코드는 함수 하나로 모아 줘. 다음 단계에서 그 함수만 진짜 주소로 바꿀 거야.
- 외부 사이트에서 무언가를 불러오지 마.

계획에는 이것만 알려 줘:
1. 화면 그림 (글자로 대충)
2. 핵심 기능 3줄
3. 저장할 칸(또는 받아 올 값)의 이름과 종류 표
4. 나에게 확인할 질문

[여기에 PRD 붙여넣기]

💡 왜 가짜 자료로, 함수 한곳에? 홀(화면)이 주문서를 내는 창구를 한곳으로 모아 두면, 3교시에는 그 창구의 주문 받을 곳만 수첩 → 장부(또는 우리 주방)로 바꾸면 됩니다. 화면 전체를 다시 만들지 않아 고장이 적습니다.

단계 4. v0.1 결재하고 배포 (15분)

🎯 목표: v0.1을 원본(main)에 합치고(결재), Vercel로 웹 주소를 만들어 공모에 낸다.

📌 1차 복습: PR = 결재 요청서. Claude Code에서 [Create PR] 로 올리고, GitHub에서 [Merge] 로 결재합니다.

⏭ 끝나면: ✅ 점검 2 (공모 페이지에 v0.1 주소) → 3교시

4-1. 결재 올리고 결재하기 (5분) · ③ Claude Code → ④ GitHub

  1. Claude Code 채팅 옆 패널의 Changes 카드(+120 -0 처럼 바뀐 줄 수가 적힌 카드)에서 [Create PR]
    • 패널이 안 보이면 화면 맨 위 세션 제목 줄의 패널 아이콘 또는 ⋮ 메뉴에서 켭니다
  2. 카드에 생긴 결재 요청서(PR) 제목을 누르면 GitHub 화면이 열립니다
  3. 아래로 내려 초록 [Merge pull request] → [Confirm merge]
  4. 보라색 Merged 가 보이면 결재 끝

4-2. Vercel에 연결해 웹 주소 만들기 (7분, 이 저장소는 처음 한 번) · ⑤ Vercel

  1. vercel.com 오른쪽 위 [Add New…] → [Project]
  2. Import Git Repository 목록에서 team-tool 옆 [Import]
    • 목록에 없으면: 목록 아래 Adjust GitHub App Permissions → Repository access 에 team-tool 추가 → [Save] → Vercel 화면으로 돌아와 다시
  3. Configure Project 화면에서
    • Project Name: 주소로 쓸 이름. 예) gear-check-hong → 주소가 https://gear-check-hong.vercel.app
    • Framework Preset: Other
    • 나머지(Root Directory, Build 설정)는 그대로
  4. [Deploy] → 1분쯤 뒤 축하 화면 → [Continue to Dashboard]
  5. 대시보드의 Domains 에 적힌 ○○.vercel.app 을 눌러 PC에서 화면이 열리는지 봅니다

💡 이제 GitHub에서 결재(Merge)할 때마다 Vercel이 저절로 다시 배포합니다. 결재 요청서(PR)를 올리면 결재 전 미리보기(Preview) 주소도 저절로 생깁니다.

4-3. 미리보기를 휴대폰 · 짝도 볼 수 있게 열기 (1분, 권장)

Vercel의 미리보기 주소는 처음에 Vercel 로그인을 요구합니다(나만 보는 시안이라서). 3교시에 휴대폰으로 미리보기를 보려면 지금 열어 둡니다.

  1. 프로젝트 위쪽 Settings → 왼쪽 Deployment Protection
  2. Vercel Authentication 을 끄고 [Save]

4-4. 휴대폰으로 열어 보기 (1분)

  1. PC Chrome에서 내 주소 화면의 빈 곳을 오른쪽 클릭 → 이 페이지의 QR 코드 생성
  2. 휴대폰 카메라로 찍어 엽니다. 3-3에서 메모한 "눌러 봐야 할 곳 3군데"를 눌러 봅니다

4-5. 공모 페이지에 v0.1 제출 (1분) · ① 교안 탭

  1. 공모 · 투표 → (이름이 안 보이면) 이름 · 비밀번호로 [시작하기]
  2. 내 작품 내기: 도구 이름 · 배포 주소(https://○○.vercel.app) · 한 줄 소개 · 연동(오늘 붙일 것) → [제출하기]
  3. "제출했습니다"가 나오고 모두의 작품에 내 카드가 생기면 됩니다. 다시 내면 고쳐집니다

✅ 다음으로: 휴대폰에서 내 주소가 열리고, 공모 페이지에 내 카드가 있다. ✅ 점검 2 (2교시 끝)

막히면 해결
