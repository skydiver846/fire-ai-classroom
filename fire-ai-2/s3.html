✅ 점검 3 (3교시 끝)

막히면 해결
(DB) [추가]를 눌러도 아무 일 없음 F12 → Console 에 permission-denied 면 규칙과 코드의 칸이 다른 것 → "firestore.rules와 index.html의 칸 이름·종류가 같은지 표로 비교하고 맞춰 줘". 규칙을 고쳤으면 콘솔에 다시 붙여넣고 [게시]
(DB) 위치 칸이 비어 있고 눌리지 않음 ① 버전 선택의 연필을 눌러 Standard를 다시 고르고 [다음], 그래도 안 되면 창을 닫고 F5 후 처음부터. 10초쯤 기다리면 켜지기도 함
(DB) 오른쪽에 Gemini 창이 열림 쓰지 않으니 닫아도 됨
(DB) "The query requires an index" "정렬·계산은 화면에서 하게 고쳐 줘"
(API) "서비스 키가 설정되지 않았습니다" 환경 변수 이름이 DATA_GO_KR_KEY 인지, Preview에도 체크했는지 확인. 넣은 뒤에 배포가 다시 돼야 함 → Vercel Deployments → 맨 위 배포의 ⋯ → [Redeploy]
(API) SERVICE_KEY_IS_NOT_REGISTERED_ERROR 승인 직후라 반영 전이거나 Encoding/Decoding 키를 바꿔 넣은 것. 바로 안 되면 (나) 강사 공용 주소로 바꾸기
(API) 결과가 XML로 옴 / 읽기 오류 "요청 변수 표대로 JSON 형식 요청 이름(type 또는 returnType)을 고쳐 줘"
(API) 함수 주소가 404 함수 파일이 저장소 맨 위 api/ 폴더에 있는지(api/data.js). PC에서 index.html 더블클릭으로는 동작하지 않고 미리보기·운영 주소에서만 됨
미리보기 주소가 안 보임 결재 요청서 아래 확인 목록이 끝날 때까지 1~2분. Vercel Deployments 에도 "Preview"로 보임
미리보기를 열면 Vercel 로그인 화면 나만 보는 시안이라 그렇습니다. PC에서 로그인한 Chrome으로 열거나, Settings → Deployment Protection → Vercel Authentication 끄기
잘못 결재했음 Vercel Deployments → 이전 배포의 ⋯ → [Promote to Production](또는 Instant Rollback) 으로 즉시 되돌리기
