8-3. 결재 (4분)

  1. [Create PR] → [Visit Preview] 로 고친 점 확인 → [Merge pull request] → [Confirm merge]
  2. 1~2분 뒤 운영 주소를 새로고침해 고친 것이 보이는지 봅니다

8-4. 업로드 (2분) · ① 교안 탭

  1. 공모 · 투표 → (이름이 안 보이면) 이름 · 비밀번호로 [시작하기]
  2. 내 작품 내기 의 도구 이름 · 배포 주소 · 한 줄 소개 · 연동(DB / API / 둘 다) 을 최종본으로 고쳐 [제출하기] (다시 내면 덮어씀)

한 줄 소개: "나는 (무엇)을 만들어 (누가) (어디에) 쓴다."

마감이 급하면 8-2 · 8-3 은 건너뛰고 8-4 업로드부터 합니다. 연동이 안 되면 API (나) 강사 공용 주소로라도 연결합니다.
