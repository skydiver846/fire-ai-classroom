2차 접속 점검

행정망(강의장) PC의 Chrome에서 이 페이지를 열면, 2차 수업의 공모 · 투표, Firebase(DB 트랙), 공공데이터 API(API 트랙)가 이 PC에서 되는지 확인합니다. 결과는 이 PC에서만 보이고 어디에도 보내지 않습니다.

1단계: 자동 점검

열림은 주소에 닿았다는 뜻, 응답 확인은 서버의 답을 실제로 읽었다는 뜻입니다. 보안 장비가 차단 안내 화면을 대신 보여 줘도 "열림"으로 보일 수 있으니, 중요한 곳은 주소를 눌러 직접 열어 보세요.

구분용도주소결과

2단계 (선택): Firebase 실제 쓰기 · 읽기 · 실시간 시험

1단계가 "응답 확인"이어도, 실시간 목록(다른 사람이 넣은 기록이 바로 보이는 것)은 보안 장비에 따라 막힐 수 있습니다. 연습용 Firebase 프로젝트가 있으면 아래로 끝까지 시험합니다.

준비: 연습용 프로젝트의 Firestore 규칙에 시험용 칸 열기

Firebase 콘솔 → Firestore → 규칙에서 match /databases/{database}/documents { 안에 아래 세 줄을 넣고 [게시]합니다. 시험이 끝나면 지웁니다.

match /network-check/{id} {
  allow read, write: if true;
}

    3단계 (선택): 공공데이터 API 직접 불러 보기

    공공데이터 API는 서버(Vercel 함수)가 부르므로 수업에서는 행정망 영향을 받지 않습니다. 사전 학습 연구 B처럼 내 브라우저 주소창에서 불러 볼 때만 이 PC를 거칩니다. 승인된 소방청_화재정보서비스 서비스 키(Decoding)를 넣고 버튼을 누르면 새 탭에서 결과가 열립니다. 키는 이 페이지 밖으로 보내지 않습니다.

    새 탭에 "resultCode":"00" 과 시도별 화재 건수(SIDO_NM, FIRE_RCPT_MNB …)가 보이면 성공입니다. SERVICE_KEY_IS_NOT_REGISTERED 는 키 문제(승인 반영 전)이고 행정망과는 관계없습니다. 탭이 아예 열리지 않거나 차단 화면이 나오면 행정망이 막은 것입니다.
