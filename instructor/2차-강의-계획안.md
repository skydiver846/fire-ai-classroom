### 0-2. 강사 공용 주소 만들기 (API 트랙 예비 경로)

강사 GitHub 저장소 하나(예: `fire-api-proxy`)에 아래 파일 하나를 두고 Netlify에 연결한 뒤, 환경 변수 `DATA_GO_KR_KEY` 에 강사의 에어코리아 서비스 키(Decoding)를 넣습니다.

```js
// netlify/functions/air.mjs
// 사용: https://(강사 사이트)/.netlify/functions/air?sido=서울
const SIDO = ["서울","부산","대구","인천","광주","대전","울산","경기","강원","충북","충남","전북","전남","경북","경남","제주","세종"];

export default async (req) => {
  const cors = { "Access-Control-Allow-Origin": "*" };   // 교육생 화면(다른 주소)에서 부를 수 있게
  const sido = new URL(req.url).searchParams.get("sido") || "서울";
  if (!SIDO.includes(sido)) return Response.json({ error: "sido 값이 올바르지 않습니다" }, { status: 400, headers: cors });

  const key = process.env.DATA_GO_KR_KEY;
  if (!key) return Response.json({ error: "서비스 키가 설정되지 않았습니다" }, { status: 500, headers: cors });

  const url = new URL("https://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty");
  url.searchParams.set("serviceKey", key);   // Decoding 키를 넣으면 여기서 알맞게 인코딩됨
  url.searchParams.set("returnType", "json");
  url.searchParams.set("sidoName", sido);
  url.searchParams.set("numOfRows", "100");
  url.searchParams.set("ver", "1.0");

  const text = await (await fetch(url)).text();
  let body;
  try { body = JSON.parse(text); }
  catch { return Response.json({ error: "공공데이터포털 응답 오류", detail: text.slice(0, 200) }, { status: 502, headers: cors }); }

  const items = (body?.response?.body?.items ?? []).map(i => ({
    station: i.stationName, time: i.dataTime, pm10: i.pm10Value, pm25: i.pm25Value, grade: i.khaiGrade,
  }));
  return Response.json(
    { source: "공공데이터포털 · 한국환경공단 에어코리아", sido, items },
    { headers: {
        ...cors,
        "Cache-Control": "public, max-age=600",
        "Netlify-CDN-Cache-Control": "public, durable, s-maxage=600",   // 10분 캐시: 교육생 20명이 눌러도 호출 한도 절약
        "Netlify-Vary": "query=sido",
    } }
  );
};
```

- 에어코리아 개발계정 하루 호출 한도가 있으므로 캐시를 꼭 둡니다. 강의 전날 몇 번 불러 캐시·한도를 확인합니다.
- 서비스·파라미터 이름은 활용신청 상세 화면의 명세가 우선입니다. Netlify(해외 서버)에서 호출이 막히는 서비스라면 다른 API로 바꿉니다.
- 이 파일은 교육생 API 트랙 (가)의 **정답 예시**이기도 합니다. 막힌 교육생에게 보여 줄 수 있습니다.

> 화면 자료는 **[2차-흐름도.md](2차-흐름도.md)** 의 1장(흐름도)·2장(식당 지도)을 그대로 띄웁니다. 설명을 두 번으로 나눈 이유는 흐름도 문서 3장(검토)에 정리했습니다: **설명은 결정하기 직전에.** 트랙은 PRD에서 정하므로 개념은 1교시에, 열쇠·규칙은 3교시 준비 단계에서 다루므로 보안은 3교시에.

### 설명 ① 흐름도와 식당 지도 (1교시 시작, 10분)

**(1) 1차에서 남긴 질문 (1분)**: 1차에서 짝이 내 화면에 기록을 넣었는데 **내 휴대폰에는 보이지 않았습니다.** 1차 마무리의 사다리 ⑥ "저절로 돌아가게(백엔드, 공공데이터 API)"를 다음 단계로 남겼는데, 오늘 그 칸을 엽니다.

**(2) 오늘의 흐름도 (3분)**: 흐름도 문서 1장. 강조할 것 세 가지.
- ①~⑤는 **1차와 같은 길**입니다. 오늘은 이 길을 혼자 갑니다.
- ⑥에서 두 갈래로 나뉘었다가 ⑧ 검증 → ⑨ 결재에서 **다시 같은 길**로 합쳐집니다. 결재·배포 방법은 트랙과 상관없이 같습니다.
- 📢 표시 두 곳만 강사가 말합니다. 나머지는 실습지.

**(3) 식당 지도 (4분, 완성본 두 개를 휴대폰 두 대로 보여 주며)**: 흐름도 문서 2장.
- 식당 비유 소개 (사전 학습에서 읽고 왔지만, 뿌리 강의를 듣지 않은 분들이라 처음 듣는다고 생각하고 천천히): 홀 = 화면, 주문서 = API, 주방 = 백엔드, 장부 = DB, 개업 = 배포.
- 1차는 홀 + 손님 수첩(localStorage)뿐이었다 → 짝 휴대폰에 안 보인 이유.
- **DB 트랙** = 우리가 함께 쓰는 **우리 장부**. 시연: 휴대폰 두 대로 DB 완성본을 열고 한쪽에서 체크 → 다른 쪽이 바로 바뀜.
- **API 트랙** = 기관이 관리하는 **남의 장부를 읽기만**. 홀이 거래처에 직접 주문하지 않고 **우리 주방(서버 함수)** 을 거침. 시연: API 완성본의 값·측정 시각·출처.
- 한 줄 정리: "두 트랙 모두 주문서(API)를 씁니다. 차이는 **누구의 장부냐**입니다."

**(4) 내 주제는 어느 트랙? (2분)**: 여러 사람이 같이 채우면 DB, 매일 바뀌는 공공 자료가 쓸모 있으면 API. 실습지 단계 0의 주제 예시 표.

> 💡 사전 학습 퀴즈(02·03)에서 많이 틀린 문항이 있으면 이 자리에서 짚습니다. 뿌리 강의 사이트(`/ai-literacy/`)는 과정 뒤 더 읽을거리로 안내합니다.

### 설명 ② 열쇠와 규칙 (3교시 시작, 5분)

연동 준비(실습지 단계 5) 바로 앞입니다. 흐름도의 ⑥ "사람이 직접"을 가리키며 시작합니다. "지금부터 10분은 AI에게 맡기지 않고 내 손으로 합니다. 열쇠와 규칙은 사람이 관리합니다."

| | DB 트랙 | API 트랙 |
|---|---|---|
| 손에 쥐는 것 | Firebase **설정값**(`apiKey` 포함) | 공공데이터포털 **서비스 키** |
| 비밀인가 | **아님.** 홀 메뉴판에 적힌 가게 주소 같은 것 | **진짜 비밀.** 거래처 출입증 |
| 어디에 두나 | 화면 코드에 그대로 | **우리 주방 금고(Netlify 환경 변수)** 에만. 채팅·GitHub·화면 어디에도 X |
| 무엇이 지키나 | **장부 규칙**: PRD의 "누가 무엇을 쓰고 고치나"를 옮긴 것. 화면의 검사는 누구나 고칠 수 있어 마지막 문지기는 규칙 (뿌리 강의 2강 인가, 3강 RLS) | 키가 홀에 나오지 않는 구조. F12 Network 응답에 키가 없어야 함 |
| 오늘의 한계 | 로그인이 없어 주소를 아는 누구나 씀. 업무 자료는 기관 규정 검토 필요 | 거래처 하루 주문 한도가 있음 → 우리 주방에서 10분 동안 담아 두기(캐시, 2강 7-2) |

```
 ✗ 홀(키가 코드에 보임) ──▶ 거래처      · F12로 누구나 키를 봄 · 브라우저가 남의 주소를 직접 부르는 것도 대부분 막힘
 ✓ 홀 ──▶ 우리 주방(서버 함수, 금고에 키) ──▶ 거래처
```

- 1차 "깃허브에 올리지 않는 것: 비밀번호, API 키, .env 파일", 뿌리 강의 4강 "환경 변수"와 같은 이야기입니다.
- 승인이 안 된 분은 강사 공용 주소를 칠판에서 확인합니다. 그 주방의 금고(키)는 강사 쪽에만 있습니다.
- (CORS라는 용어는 쓰지 않습니다. 뿌리 강의에 없는 말이라 "홀 직원은 거래처에 직접 주문하지 않는다"로만.)
