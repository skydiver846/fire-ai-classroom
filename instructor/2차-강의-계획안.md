## 4. 짧은 설명: 데이터베이스와 공공데이터 API (3교시, 20분)

### 4-0. 방금 겪은 일로 시작 (2분)

교차 검증에서 짝이 내 화면에 기록을 넣었는데 **내 휴대폰에는 보이지 않았습니다**(1차 ⑧-6과 같음). 1차 마무리의 사다리 ⑥ "저절로 돌아가게(백엔드, 공공데이터 API)"를 "다음 단계"로 남겼는데, 오늘 그 칸이 무엇인지 봅니다.

### 4-1. 기록을 어디에 두나: 세 가지 장부 (5분)

```
 ① 내 브라우저(localStorage)   [내 휴대폰 장부]  [짝 휴대폰 장부]        ← 1차·오늘 만든 것. 따로따로
 ② 데이터베이스(공용 장부)     [내 휴대폰] ─┐
                               [짝 휴대폰] ─┼──▶ Firebase (공용 장부)   ← 모두가 같은 기록
                               [팀장 PC]  ─┘
 ③ 공공데이터 API(남의 장부)   [내 화면] ──▶ [내 서버 함수] ──▶ 공공데이터포털  ← 기관이 관리하는 최신 자료를 읽기만
```

| | ① 내 브라우저 | ② 데이터베이스 | ③ 공공데이터 API |
|---|---|---|---|
| 업무로 치면 | 내 수첩 | 부서 공용 대장 | 다른 기관에서 받는 자료 |
| 누가 쓰나 | 나만 | 주소를 아는 우리 모두 | 기관이 올리고, 나는 읽기만 |
| 맞는 주제 | 개인 기록, 체크리스트 | 여러 사람이 함께 채우는 점검표·신청 현황 | 날씨·대기질·화재 통계처럼 매일 바뀌는 자료 |
| 지키는 것 | 없음 (내 휴대폰 안) | **장부 규칙** (누가 무엇을 쓸 수 있나) | **서비스 키** (비밀번호처럼 숨김) |

### 4-2. 꼭 기억할 두 가지 (3분)

**① 데이터베이스: 마지막 문지기는 장부 규칙** (1차 모듈 11의 3단계)

- 화면(JavaScript)에서 검사해도, 화면 코드는 누구나 고칠 수 있습니다. 장부 규칙이 PRD의 "누가 무엇을 할 수 있나"를 그대로 옮긴 것이어야 합니다.
- Firebase의 `apiKey` 는 이름과 달리 **비밀이 아닙니다**(화면에 들어가는 설정값). 지키는 것은 규칙입니다.
- 업무 자료를 해외 클라우드에 저장하려면 기관의 개인정보·클라우드 규정 검토가 필요합니다.

**② 공공데이터 API: 서비스 키는 진짜 비밀, 그래서 "심부름꾼(서버 함수)"을 둔다**

```
 ✗ 안 되는 방법:  내 화면(키가 코드에 보임) ──▶ 공공데이터포털
                  · 누구나 F12로 키를 보고 가져갈 수 있음
                  · 대부분 브라우저가 직접 부르는 것을 막음(CORS)

 ✓ 맞는 방법:     내 화면 ──▶ Netlify 서버 함수(심부름꾼) ──▶ 공공데이터포털
                              키는 Netlify 설정(환경 변수)에만, GitHub에도 올리지 않음
```

- 1차 ③ 읽을거리 "깃허브에 올리지 않는 것 = 비밀번호, API 키, .env 파일"을 다시 보여 줍니다.

## 부록 B. 더 해 보기: 공공데이터 API 붙이기 (과정 뒤 권장)

준비: data.go.kr 가입 → 쓰고 싶은 API [활용신청]. **승인 후 실제로 쓸 수 있기까지 1시간~하루** 걸리므로 강의 중보다는 과정 뒤에 권합니다.

| API (공공데이터포털 검색어) | 보여 줄 값 | 주제 예 |
|---|---|---|
| 한국환경공단_에어코리아_대기오염정보 | 시도별 실시간 PM10·PM2.5 | 야외 훈련 가능 여부 |
| 기상청_단기예보 조회서비스 | 기온·강수확률 (격자 좌표 필요) | 오늘 훈련장 날씨 |
| 소방청 관련 통계 (검색어 "소방청") | 화재 건수 등 | 화재 현황판 (파일 데이터면 1차 12 부록처럼 API 없이도 됨) |

① 서비스 키 넣기 (사람이 직접)

- data.go.kr → 마이페이지 → 활용신청 현황 → 해당 API → **일반 인증키(Decoding)** 복사
- app.netlify.com → 내 사이트 → **Site configuration → Environment variables → Add a variable** → Key `DATA_GO_KR_KEY`, Value 복사한 키
- ⚠️ 키를 Claude Code 채팅, GitHub, 화면 코드 어디에도 붙여넣지 않습니다.

② Claude Code 지시문

```
PRD.md에 공공데이터포털 API 값을 보여 주는 기능을 더하고 싶어.
API: (API 이름)  /  요청 주소: (활용신청 상세 화면의 End Point와 상세기능 이름)
보여 줄 값: (예: 서울의 PM10, PM2.5, 측정 시각)

- 서비스 키는 Netlify 환경 변수 DATA_GO_KR_KEY에 이미 넣어 두었어. 키 값은 묻지 마.
- 브라우저가 공공데이터포털을 직접 부르지 말고, Netlify 서버 함수
  netlify/functions/data.mjs 가 대신 불러서 필요한 값만 JSON으로 돌려주게 해 줘.
- 서비스 키는 함수 안에서 process.env.DATA_GO_KR_KEY 로만 읽고, 응답이나 화면에 절대 넣지 마.
- 실패하면 화면에 "자료를 불러오지 못했습니다"처럼 알기 쉽게 보여 줘.
- 화면 아래에 출처(공공데이터포털, 제공기관, 기준 시각)를 적어 줘.
- 추가 라이브러리는 쓰지 마. PRD.md와 변경 기록도 고쳐 줘.
- 내 환경에는 키가 없어서 실제 호출 시험은 못 할 거야. 시험하지 못한 것은 못 했다고 표에 적어 줘.
```

③ 확인: 미리보기 주소에서 값이 나오는지, F12 → Network 에서 화면이 부르는 주소가 `/.netlify/functions/data` 이고 응답에 키가 없는지 → 결재

| 막힘 | 해결 |
|---|---|
| `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 승인 직후 키 반영 전. 1시간~하루 기다림. 계속되면 Encoding/Decoding 키를 바꿔 넣어 봄 |
| "서비스 키가 설정되지 않았습니다" | 환경 변수 이름 확인 → 넣은 **뒤에** 다시 배포: Deploys → [Trigger deploy] → Deploy site |
| 결과가 XML로 옴 | API마다 `type=json` / `returnType=json` 이름이 다름. 활용신청 상세 화면의 요청 변수 표를 Claude에게 붙여넣고 "이 명세에 맞게 고쳐 줘" |

> 💡 강사 시연용 서버 함수 예시 (에어코리아 시도별 실시간 측정정보). 강의 전 내 저장소에서 미리 시험해 둡니다. 서비스·파라미터 이름은 활용신청 상세 화면의 명세가 우선입니다.
>
> ```js
> // netlify/functions/data.mjs
> export default async (req) => {
>   const key = process.env.DATA_GO_KR_KEY;
>   if (!key) return Response.json({ error: "서비스 키가 설정되지 않았습니다" }, { status: 500 });
>   const url = new URL("https://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty");
>   url.searchParams.set("serviceKey", key);       // Decoding 키를 넣으면 여기서 알맞게 인코딩됨
>   url.searchParams.set("returnType", "json");
>   url.searchParams.set("sidoName", "서울");
>   url.searchParams.set("numOfRows", "100");
>   url.searchParams.set("ver", "1.0");
>   const res = await fetch(url);
>   const text = await res.text();
>   let body;
>   try { body = JSON.parse(text); }
>   catch { return Response.json({ error: "공공데이터포털 응답 오류", detail: text.slice(0, 200) }, { status: 502 }); }
>   const items = body?.response?.body?.items ?? [];
>   return Response.json(
>     items.map(i => ({ station: i.stationName, time: i.dataTime, pm10: i.pm10Value, pm25: i.pm25Value })),
>     { headers: { "Cache-Control": "public, max-age=600" } }  // 10분 캐시: 하루 호출 한도 아끼기
>   );
> };
> ```
