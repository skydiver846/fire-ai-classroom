# 04 내용 구성과 시간 배분 — 만드는 시간을 어떻게 확보할까

## 1. 산출물 강의의 시간표는 거꾸로 짠다

도구 강의는 "기능 1 → 기능 2 → 기능 3 → (남는 시간에) 응용"으로 흐릅니다. 그러면 정작 **내 것을 만드는 시간**이 맨 끝에 밀려 미완성으로 끝납니다.

산출물 강의는 **완성 시간부터** 확보하고 거꾸로 채웁니다.

```text
  도구 중심:  [기능 설명 ████████████████][따라 하기 ██████][내 것 ▌]  ← 미완성
  산출물 중심: [동기 ██][완성본 보기 ██][만들기 ████████████████][나누기 ████]
```

> [!tip] 한 줄 정리
> 전체 시간의 **절반 이상**을 교육생이 **직접 만드는 시간**으로 둡니다. 설명은 "그걸 만드는 데 꼭 필요한 만큼만".

## 2. 산출물 강의의 다섯 덩어리

| 덩어리 | 할 일 | 비율 |
|---|---|---|
| **① 열기** | 마음 열기 · 왜 필요한지 공감 · 오늘 만들 것 보여 주기 | 10% |
| **② 완성본 보기** | 강사가 만든 예시 산출물을 먼저 보여 주기 ("이걸 만들어 갑니다") | 10% |
| **③ 따라 만들기** | 예시 데이터로 함께 한 번 (도구 사용은 여기서만) | 20% |
| **④ 내 것 만들기** | 각자 내 상황 · 감정 · 업무로 만들기, 강사 순회 | 40% |
| **⑤ 나누기 · 닫기** | 보여 주기(원하는 사람만), 다음에 쓸 곳, 마음 정리 | 20% |

## 3. 세 교육생의 90분

| 덩어리 | 🌱 마음 돌봄 (그림책) | 🗂 행정 공무원 (엑셀 병합) | 🤝 조직문화 (풍자 4컷) |
|---|---|---|---|
| ① 열기 10분 | 오늘의 마음 날씨 한 단어로 | "취합에 몇 분 걸려요?" 투표 | 직장 공감 밈 3장 보며 웃기 |
| ② 완성본 5분 | 강사의 그림책 4쪽 | 1분 만에 합쳐지는 시연 | 강사가 만든 예시 4컷 |
| ③ 따라 만들기 20분 | 날씨 → 장면 요청 연습 1장 | 예시 파일 3개로 AI에게 요청 → 실행 | 4컷 틀 + 첫 컷 함께 |
| ④ 내 것 만들기 40분 | 내 그림책 4장면 (상담사 순회) | 내 업무 파일 구조로 고치기 | 나만의 4컷 (익명 규칙) |
| ⑤ 나누기 15분 | 원하는 사람만 한 장면 소개, 마음 닫기 | 다음 달 쓸 위치 정하기, 오류 대처 | 갤러리 워크, 상사에게 바라는 점 한 줄 |

> [!warning] 줌으로 한다면
> 화면 너머의 집중은 더 빨리 떨어집니다. 설명은 **7~10분 안에**, 만들기 중에는 "5분 남았습니다" 같은 **중간 안내**를 넣고, 정서 활동은 **카메라 · 마이크를 강요하지 않습니다.**

### 대상에 따라 조절하기: 시니어 · 청소년

| | 👵 시니어 | 🧒 청소년 |
|---|---|---|
| 설명 | 더 천천히, **한 번에 한 단계**, 큰 화면 · 큰 글씨 | 더 짧게 (**5~7분**), 질문 · 퀴즈로 끊기 |
| 따라 만들기 | 시간을 늘리고 보조 강사가 옆에서 | 짝 대결 · 미션 카드로 게임처럼 |
| 내 것 만들기 | 완성보다 "보냈다 · 해냈다"의 경험을 우선 | 시간 제한 + 완성하면 다음 미션 |
| 나누기 | 카드를 실제로 가족에게 보내 보기 | 대피 지도를 집에 가져가 가족과 확인하기 (과제) |

## 4. 설명은 10분 규칙

사람의 집중은 설명만 들을 때 10~15분이 지나면 눈에 띄게 떨어집니다. 설명 블록 사이에 **짧은 활동**을 끼웁니다.

| 활동 | 시간 | 예 |
|---|---|---|
| 질문 하나 | 1~2분 | "이 장면에 어울리는 날씨는?" |
| 짝 확인 | 3분 | 짝의 4컷 첫 컷 보고 한마디 |
| 짧은 시연 · 따라 하기 | 5~10분 | AI에게 첫 요청 보내 보기 |

## 5. 내용은 산출물에서 거꾸로 고른다

| 원 | 기준 | 엑셀 병합 예 |
|---|---|---|
| 🎯 **꼭 필요한 것** | 이것 없이는 산출물을 못 만든다 | AI에게 요청하는 법, 실행 · 확인하는 법 |
| 👍 **있으면 좋은 것** | 도움은 되지만 없어도 만들 수는 있다 | 매크로의 원리, 다른 자동화 사례 |
| 📚 **빼도 되는 것** | 산출물과 관계없다 | 엑셀의 역사, 모든 함수 목록 |

## 정리

1. 시간표는 **만드는 시간부터** 확보하고 거꾸로 짭니다 (절반 이상).
2. **열기 → 완성본 보기 → 따라 만들기 → 내 것 만들기 → 나누기**.
3. 설명은 10분(줌은 7분)을 넘기지 않고, 내용은 산출물에 **꼭 필요한 것**만.
