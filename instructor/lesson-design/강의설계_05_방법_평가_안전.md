# 05 방법 · 평가 · 안전 — 산출물로 확인하고, 사람을 지키기

## 1. 목표 · 방법 · 평가를 한 줄로

목표의 동사, 수업 활동, 평가가 **같은 행동**을 가리켜야 합니다(정렬). 산출물 강의라면 평가는 대부분 **산출물을 보는 것**입니다.

| 목표 | 방법 | 평가 | 정렬? |
|---|---|---|---|
| 엑셀 병합 도구를 **만든다** | 시연 → 따라 만들기 → 내 것 만들기 | 도구가 예시 파일 3개를 합치는지 **실행 확인** | ✅ |
| 엑셀 병합 도구를 **만든다** | 슬라이드 설명만 | 객관식 퀴즈 | ❌ |
| 감정에 날씨 이름을 붙여 **표현한다** | 예시 보기 → 내 그림책 | 4장면 완성 여부 + **스스로 고른** 소감 한 줄 | ✅ |

> [!tip] 한 줄 정리
> "만든다"가 목표면 **만든 것을 보고** 확인합니다. 시험지는 산출물을 확인하지 못합니다.

## 2. 교육생에 맞는 방법

| 교육생 | 잘 맞는 방법 | 피할 것 |
|---|---|---|
| 🗂 업무형 (바쁘고 실용적) | 짧은 시연 → 내 파일로 실습, 막히는 곳 해결표 | 긴 원리 설명, 나와 무관한 예시 |
| 🌱 정서형 (조심스러움) | 예시 먼저, 혼자 만들 시간, 선택적 나눔 | 발표 강요, 경쟁 · 점수, 사연 캐묻기 |
| 🤝 관계형 (어색함) | 웃음으로 열기, 짝 · 소그룹, 갤러리 워크 | 특정인 지목, 상하 서열 드러내는 활동 |
| 👵 시니어 (낯설고 조심스러움) | 시범을 천천히 두 번, 보조 강사 1:3, 바로 칭찬 | 전문 용어, 빠른 화면 전환, "이것도 몰라요?" |
| 🧒 청소년 (짧은 집중) | 미션 · 게임, 짝 활동, 결과물을 집으로 가져가는 과제 | 긴 설명, 성적처럼 느껴지는 평가 |

## 3. 산출물 평가 방법

| 평가 | 무엇을 보나 | 어울리는 교육생 |
|---|---|---|
| **실행 확인 (체크리스트)** | 도구가 제대로 돌아가나 | 업무 자동화 |
| **루브릭** | 수준별 기준 (잘함 · 보통 · 다시) | 보고서 · 디자인 산출물 |
| **자기평가 · 소감 척도** | "만들기 전보다 마음이 ○○해졌다" (1~5) | 정서 · 표현 활동 |
| **갤러리 워크 · 동료 스티커** | 서로의 작품에 한 줄 응원 | 관계 · 문화 |
| **사후 확인 (1~4주 뒤)** | 실제로 썼는가, 시간이 줄었는가 | 업무 자동화 (효과 측정) |

> [!example] 생활 속 비유
> 그림 교실은 시험을 보지 않습니다. 다 그린 그림을 벽에 걸고 함께 봅니다. 그게 평가이자 칭찬입니다.

## 4. 정서 · 관계 활동의 평가는 다르게

정서 · 관계 산출물에는 **점수를 매기지 않습니다.** 대신 이렇게 확인합니다.

| 하지 않을 것 | 대신 할 것 |
|---|---|
| 작품에 점수 · 순위 매기기 | 완성 여부 + 스스로 고른 소감 한 줄 |
| "치료 효과가 있었다"고 강사가 판단 | 전문가가 정한 척도(예: 기분 척도 전 · 후)로, 전문가와 함께 해석 |
| 상사 풍자 4컷 투표로 1등 뽑기 | 갤러리 워크에서 "공감 스티커"만 |

## 5. 안전 설계 체크리스트

| 점검 | 질문 |
|---|---|
| ✅ 선택권 | 나눔 · 발표 · 카메라를 **원하는 사람만** 하나? 중간에 멈출 수 있나? |
| ✅ 익명 · 존중 | 풍자 · 사례에서 **특정인을 알아볼 수 없나**? 비하 · 외모 · 성별 놀림이 없나? |
| ✅ 전문가 | 정서 · 심리 대상이면 **전문가가 기획 · 동석**하나? 위기 시 연락 체계가 있나? |
| ✅ 데이터 | 업무 실습은 **예시 데이터**로 하나? 개인정보 · 내부 자료가 AI에 들어가지 않나? |
| ✅ 도구 | 기관 보안 규정상 쓸 수 있는 도구인가? 계정 · 비용 문제가 없나? |
| ✅ 연령 | 시니어는 사기 예방 안내를 함께 했나? 미성년자는 보호자 · 학교 동의와 AI 서비스 이용 가능 연령을 확인했나? |

> [!question] 채팅에 한 줄
> 내 강의에서 가장 조심해야 할 안전 포인트 하나를 채팅에 적어 보세요.

## 정리

1. 목표 · 방법 · 평가는 같은 행동을 가리킵니다. 산출물 강의는 **산출물을 보고** 평가합니다.
2. 교육생 유형(업무 · 정서 · 관계)에 맞게 방법을 고르고, 정서 · 관계 산출물에는 **점수를 매기지 않습니다**.
3. **선택권 · 익명 · 전문가 · 데이터 · 도구 · 연령** 여섯 가지 안전 장치를 계획서에 넣습니다.
