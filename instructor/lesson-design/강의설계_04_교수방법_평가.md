# 04 교수방법과 평가 — 무엇으로 가르치고 무엇으로 확인할까

## 1. 목표 · 방법 · 평가를 한 줄로

강의 설계에서 가장 중요한 원칙은 **정렬**(일치)입니다. 목표의 동사, 수업 활동, 평가가 **같은 행동**을 가리켜야 합니다.

| 목표 (동사) | 수업 활동 | 평가 | 정렬? |
|---|---|---|---|
| 점검 5단계를 **수행한다** | 시범 → 짝 실습 | 체크리스트로 실기 관찰 | ✅ 맞음 |
| 점검 5단계를 **수행한다** | 슬라이드 설명만 | 객관식 시험 | ❌ 어긋남 |
| 점검 항목을 **나열한다** | 설명 · 반복 말하기 | 단답 퀴즈 | ✅ 맞음 |

> [!tip] 한 줄 정리
> "수행한다"가 목표면 수업에서 **수행하게** 하고, 평가도 **수행을 보고** 합니다. 시험지는 "수행"을 확인하지 못합니다.

## 2. 방법 고르기

| 방법 | 언제 좋은가 | 주의 |
|---|---|---|
| **강의(설명)** | 새로운 개념 · 기준을 짧게 전달 | 10분을 넘기지 않기 |
| **시범** | 순서 · 동작이 있는 기술 | 느리게 한 번, 보통 속도로 한 번 |
| **실습** | "수행한다 · 작성한다" 목표 | 체크리스트를 먼저 나눠 주기 |
| **토의** | 판단 · 태도, 여러 관점이 필요한 주제 | 질문과 시간을 정해 두기 |
| **사례 · 시뮬레이션** | 원인 찾기 · 판단하기 | 실제 사례는 개인정보 지우고 |

> [!example] 생활 속 비유
> 수영을 가르칠 때 강의(호흡 원리) → 시범(강사가 물에서) → 실습(직접 물에)으로 갑니다. 강의만 듣고 수영할 수 있게 된 사람은 없습니다.

## 3. 평가: 언제 무엇을 확인하나

| 평가 | 언제 | 목적 | 예 (교실 / 줌) |
|---|---|---|---|
| **진단평가** | 시작 전 | 대상의 지금 수준 확인 | 사전 퀴즈 3문항 / 줌 투표 |
| **형성평가** | 수업 중간 | 이해 정도를 보고 바로 고쳐 주기 | 짝 확인, 손 신호 / 채팅 한 줄 |
| **총괄평가** | 끝 | 목표 달성 여부 판단 | 3분 점검 실연 / 시연 영상 판정 |

## 4. 체크리스트와 루브릭

"수행한다" 목표는 **체크리스트**로 보면 누가 봐도 같은 결과가 나옵니다.

| 점검 항목 | 했다 | 안 했다 |
|---|---|---|
| ① 용기 압력 확인 (기준 이상) | ☐ | ☐ |
| ② 고압 · 중압 호스 손상 확인 | ☐ | ☐ |
| ③ 면체 밀착 (음압) 확인 | ☐ | ☐ |
| ④ 경보기 작동 확인 | ☐ | ☐ |
| ⑤ 등지게 · 끈 조임 확인 | ☐ | ☐ |
| 기준: 3분 안에 5개 모두 | 통과 ☐ | 재실습 ☐ |

> [!warning] 주의
> 위 점검 항목은 강의 설계를 설명하기 위한 **예시**입니다. 실제 교육에서는 소속 기관의 장비 매뉴얼과 지침을 기준으로 항목을 정합니다.

판단이 필요한 목표(예: "사용 가능 여부를 판단한다")는 수준별 설명을 붙인 **루브릭**(잘함 · 보통 · 부족)이 더 알맞습니다.

> [!question] 채팅에 한 줄
> 내 강의의 핵심 목표는 무엇으로 확인하면 좋을까요? "실기 관찰 / 퀴즈 / 결과물 / 토의 발표" 중 하나와 이유를 채팅에 적어 보세요.

## 정리

1. 목표 · 방법 · 평가는 **같은 행동**을 가리켜야 합니다(정렬).
2. 방법은 목표 동사에 맞춰 고릅니다: 수행 → 시범 · 실습, 판단 → 사례 · 토의.
3. 진단 · 형성 · 총괄 평가를 시간표에 넣고, 수행 목표는 **체크리스트**로 봅니다.
