# 05 AI로 강의계획서 완성하기 — 초안은 AI, 판단은 나

## 1. 강의계획서 한 장에 들어갈 것

앞의 네 장에서 정한 것이 그대로 계획서의 칸이 됩니다.

| 칸 | 어디서 왔나 | 예 |
|---|---|---|
| 강의명 · 대상 · 시간 | 01 주제 선정 | 공기호흡기 착용 전 점검 · 신임 교육생 24명 · 50분 |
| 교육 요구 (왜 필요한가) | 01 주제 선정 | 실습 중 점검 누락 · 순서 혼동이 반복됨 |
| 학습목표 1~3개 | 02 학습목표 | 점검표를 보며 3분 안에 5단계를 빠짐없이 수행한다 |
| 차시 구성 (시간 · 내용 · 방법) | 03 내용 구성 | 도입 5 · 전개 10 · 실습 10 · … |
| 평가 방법 | 04 방법 · 평가 | 체크리스트 실기 관찰 |
| 준비물 · 안전 유의사항 | 내가 정리 | 공기호흡기 12세트, 점검표, 소독 티슈 |

## 2. AI에게 맡길 일, 내가 할 일

| AI에게 맡기면 좋은 일 | 반드시 내가 할 일 |
|---|---|
| 빈칸 채운 초안 만들기 | 교육 요구가 **진짜인지** 판단 |
| 목표 문장 다듬기 (ABCD 점검) | 장비 · 절차 · 수치가 **기관 기준과 맞는지** 확인 |
| 활동 아이디어 여러 개 뽑기 | 대상 수준과 **안전**에 맞는 활동 고르기 |
| 시간표 합계 · 형식 정리 | 실제 시간 안에 되는지 **직접 한 번 해 보기** |
| 퀴즈 · 체크리스트 초안 | 정답과 기준을 **근거로 확인** |

> [!warning] AI는 그럴듯하게 틀립니다
> AI는 없는 규정, 틀린 수치, 존재하지 않는 사고 사례를 자연스럽게 지어낼 수 있습니다. 장비 수치 · 법령 · 지침은 **반드시 원문으로 확인**하고, 내부 문서 원문과 개인정보는 붙여넣지 않습니다.

## 3. 좋은 요청의 다섯 칸

| 칸 | 넣을 것 | 예 |
|---|---|---|
| **역할** | AI가 맡을 전문가 | 소방학교 교수설계 전문가 |
| **대상** | 누구에게, 수준은? | 신임 교육생 24명, 처음 다룸 |
| **목표** | ABCD 목표 | 3분 안에 5단계를 빠짐없이 수행 |
| **조건** | 시간 · 장소 · 제약 | 50분, 실습장, 장비 12세트 (2인 1조) |
| **형식** | 받고 싶은 모양 | 표 하나: 시간 · 단계 · 내용 · 방법 · 자료 |

```
너는 소방학교 교수설계 전문가야. 아래 조건으로 1차시 강의계획서 초안을 만들어 줘.
- 강의명: [공기호흡기 착용 전 점검]
- 대상: [신임 교육생 24명, 공기호흡기를 처음 다룸]
- 교육 요구: [실습 중 착용 전 점검 누락 · 순서 혼동이 반복됨]
- 학습목표: [교육생은 점검표를 보며 3분 안에 착용 전 점검 5단계를 빠짐없이 수행한다]
- 조건: [50분, 실습장, 장비 12세트(2인 1조)]
형식:
1) 도입 · 전개 · 정리로 나눈 시간표 (시간 | 단계 | 내용 | 방법 | 자료) — 시간 합계가 정확히 50분
2) 설명이 10분을 넘지 않게 중간에 활동 넣기
3) 목표와 같은 행동으로 확인하는 평가 방법과 체크리스트 초안
4) 안전 유의사항
장비 수치나 규정은 지어내지 말고, 확인이 필요한 곳은 "[확인 필요]"로 표시해 줘.
```

## 4. AI 초안 검토 체크리스트

AI가 준 초안은 아래 여섯 가지를 보고 고칩니다.

| 점검 | 질문 |
|---|---|
| ✅ 사실 | 장비 수치 · 절차 · 규정이 기관 기준과 같은가? "[확인 필요]"를 모두 확인했나? |
| ✅ 대상 수준 | 처음 다루는 사람에게 너무 어렵거나 쉽지 않은가? |
| ✅ 정렬 | 목표 · 활동 · 평가가 같은 행동을 가리키나? |
| ✅ 시간 | 합계가 맞나? 설명 블록이 10분을 넘지 않나? |
| ✅ 안전 | 실습에 안전 유의사항과 담당자가 있나? |
| ✅ 보안 | 개인정보 · 내부 문서 원문이 들어가지 않았나? |

## 5. 다음 단계

1. 아래 **바로 해 보기**에서 내 강의계획서를 완성하고 PDF로 저장합니다.
2. 동료 한 명에게 보여 주고 "목표만 보고 평가 방법을 맞혀 보라"고 해 봅니다. 맞히면 정렬이 잘 된 계획서입니다.
3. 첫 강의가 끝나면 형성평가와 강의평가를 보고 계획서를 고칩니다. 계획서는 **한 번 쓰고 끝나는 문서가 아니라 고쳐 가는 문서**입니다.

## 정리

1. 계획서의 칸은 01~04에서 정한 것들입니다. 빈칸만 채우면 됩니다.
2. AI에게는 **역할 · 대상 · 목표 · 조건 · 형식** 다섯 칸으로 요청합니다.
3. 초안은 AI, **판단과 확인은 나** — 사실 · 대상 · 정렬 · 시간 · 안전 · 보안 여섯 가지로 검토합니다.
