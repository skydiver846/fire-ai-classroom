# 06 AI로 강의계획서 완성하기 — 초안은 AI, 판단은 나

## 1. 맞춤 강의계획서 한 장에 들어갈 것

앞의 장에서 정한 것이 그대로 계획서의 칸이 됩니다.

| 칸 | 어디서 왔나 | 🗂 행정 공무원 예 |
|---|---|---|
| 교육생 (누구 · 필요 · 마음 · 환경) | 01 교육생 이해 | 엑셀 취합에 지친 주무관 15명, 바로 쓸 걸 원함, 업무 PC |
| 산출물과 기대 효과 | 02 산출물 | 엑셀 병합 자동화 도구 → 매달 30분을 1분으로 |
| 학습목표 1~3개 | 03 학습목표 | 예시 파일 3개를 20분 안에 오류 없이 합치는 도구를 만든다 |
| 시간표 | 04 내용 · 시간 | 열기 10 · 완성본 5 · 따라 20 · 내 것 40 · 나누기 15 |
| 평가 · 안전 | 05 방법 · 평가 · 안전 | 실행 확인 체크리스트, 예시 데이터만 사용 |

## 2. AI에게 맡길 일, 내가 할 일

| AI에게 맡기면 좋은 일 | 반드시 내가 할 일 |
|---|---|
| 산출물 아이디어 여러 개 뽑기 | 교육생에게 **정말 맞는지** 판단 |
| 예시 산출물 만들기 (그림책 · 4컷 · 노래 · 음성 편지 · 도구) | 예시가 교육생에게 **상처나 곤란을 주지 않는지** 확인 |
| 시간표 · 계획서 초안, 형식 정리 | 시간 안에 **실제로 완성되는지** 직접 한 번 만들어 보기 |
| 막히는 곳 해결표, 요청문 예시 | 보안 · 개인정보 · 저작권 확인 |
| 활동 아이디어, 열기 질문 | 정서 · 심리 대상이면 **전문가와 함께 검토** |

> [!warning] AI는 그럴듯하게 틀립니다
> AI는 없는 연구 결과("○○ 활동은 우울감을 40% 줄인다")나 틀린 기능 설명을 자연스럽게 지어낼 수 있습니다. 효과에 대한 주장은 **근거를 확인**하고, 실제 교육생 정보는 붙여넣지 않습니다.

## 3. 좋은 요청의 여섯 칸

| 칸 | 넣을 것 | 예 |
|---|---|---|
| **역할** | AI가 맡을 전문가 | 교육생 맞춤 강의를 설계하는 교수설계 전문가 |
| **교육생** | 누구 · 필요 · 마음 · 환경 | 세대 · 직급이 섞인 직원 20명, 어색함 |
| **산출물 · 효과** | 무엇을 만들어 무엇이 달라지나 | 상사와 나 풍자 4컷 → 웃음으로 대화의 계기 |
| **목표** | ABCD 목표 | 특정인을 알아볼 수 없게 4컷을 그린다 |
| **조건 · 안전** | 시간 · 장소 · 지킬 것 | 90분, 노트북, 익명 · 비하 금지 |
| **형식** | 받고 싶은 모양 | 시간표 표 + 평가 + 안전 장치 |

```
너는 교육생 맞춤 강의를 설계하는 교수설계 전문가야. 아래 조건으로 강의계획서 초안을 만들어 줘.
- 교육생: [세대 · 직급이 섞인 한 부서 직원 20명. 상사와 대화가 어렵고 분위기가 무거움. 억지 참여를 싫어함]
- 산출물과 효과: [상사와 나, 풍자 4컷 만화 → 불편함을 웃음으로 꺼내고 대화의 계기 만들기]
- 학습목표: [참여 직원은 이미지 생성 AI와 4컷 틀로 특정인을 알아볼 수 없게 상사와 나의 4컷 만화를 그린다]
- 조건: [90분, 강당, 노트북 일부(2인 1대)]
- 안전: [특정인 식별 금지, 외모 · 성별 · 나이 비하 금지, 공유는 원하는 사람만]
형식:
1) 열기 · 완성본 보기 · 따라 만들기 · 내 것 만들기 · 나누기로 나눈 시간표 (시간 | 단계 | 활동 | 자료) — 합계 정확히 90분, 만들기가 절반 이상
2) 목표와 같은 행동으로 확인하는 평가 (점수 대신 갤러리 워크 등)
3) 안전 장치와 강사 멘트 예시
효과에 대한 연구 · 통계는 지어내지 말고, 근거가 필요한 곳은 "[확인 필요]"로 표시해 줘.
```

## 4. AI 초안 검토 체크리스트

| 점검 | 질문 |
|---|---|
| ✅ 교육생 | 이 사람들의 필요 · 마음 · 환경에 맞나? 다른 교육생에게도 똑같이 쓸 수 있는 계획이면 ✕ |
| ✅ 산출물 | 각자 **내 것**이 되나? 시간 안에 **완성**되나? |
| ✅ 정렬 | 목표 · 활동 · 평가가 같은 행동(만든다)을 가리키나? |
| ✅ 시간 | 만들기가 절반 이상인가? 설명이 10분을 넘지 않나? |
| ✅ 안전 | 선택권 · 익명 · 전문가 · 데이터 · 도구 · 연령 여섯 가지가 들어 있나? |
| ✅ 근거 | 효과에 대한 주장, "[확인 필요]"를 모두 확인했나? |

## 5. 다음 단계

1. 아래 **바로 해 보기**에서 내 맞춤 강의계획서를 완성하고 PDF로 저장합니다.
2. **예시 산출물을 직접 한 번 만들어 봅니다.** 강사가 만들어 보지 않은 산출물은 시간 안에 완성되지 않습니다.
3. 동료에게 보여 주고 "이 계획서, 다른 교육생에게도 그대로 쓸 수 있을까?"를 물어봅니다. "아니요"라면 잘 맞춘 계획서입니다.

## 정리

1. 계획서의 칸은 **교육생 → 산출물 → 목표 → 시간 → 평가 · 안전**입니다.
2. AI에게는 **역할 · 교육생 · 산출물 · 목표 · 조건 · 형식** 여섯 칸으로 요청합니다.
3. 초안은 AI, **맞는지 · 안전한지 · 근거 있는지 판단은 나**입니다.
