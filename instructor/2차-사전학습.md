## ④ 실습 A. 1차 내 화면에 데이터베이스(Firebase) 붙여 보기 (11. 17.(화)까지, 60분)

3. Gemini(AI 도우미) 질문이 나오면 원하는 대로 → [계속]
4. **"이 프로젝트에서 Google 애널리틱스 사용 설정" 스위치를 끕니다** → **[프로젝트 만들기]**

2. 네 단계를 차례로 고릅니다

   - ③ **구성**: **프로덕션 모드에서 시작** → [만들기] (또는 [다음])
   - ④ **예약된 백업**: 하지 않음
3. 위쪽에 **데이터 · 규칙 · 색인** 탭이 보이면 됩니다

> 💡 **프로덕션 모드** = 처음에는 아무도 장부를 못 쓰게 잠근 상태입니다. 4-5에서 정한 규칙대로만 열어 줍니다.

2. 아래 지시문의 `[ ]` 를 채워 보냅니다

```
이 저장소의 index.html은 기록을 이 브라우저(localStorage)에만 저장하는 화면이야.
여러 사람이 같은 기록을 보도록 Firebase Firestore에 저장하게 바꾸고 싶어. 먼저 계획을 알려 주고, 내가 승인하면 만들어 줘.

1. PRD.md에 맞는 Firestore 보안 규칙을 firestore.rules 파일로 써 줘.
   - 컬렉션 이름과 칸(필드) 이름·종류를 표로 정리하고, 표에 있는 칸만 쓸 수 있게 해 줘.
   - 글자 칸에는 길이 제한을 넣고, 각 줄을 PRD 말로 설명하는 표도 보여 줘.
2. index.html의 저장·불러오기를 Firestore로 바꿔 줘.
   - 내 Firebase 설정값 (웹 앱 설정값이라 비밀이 아닌 것은 알고 있어):
     [firebaseConfig 붙여넣기]
   - Firebase는 공식 CDN(gstatic.com)의 모듈 방식으로, HTML 파일 하나로 유지해 줘.
   - 목록은 실시간으로 받아 와서 다른 사람이 바꾸면 새로고침 없이 보이게 해 줘.
   - 칸 이름·종류는 firestore.rules와 정확히 같게, 계산·정렬은 화면에서 해 줘.
3. PRD.md 변경 기록에 "Firestore 공용 장부 연결"을 적어 줘.
```

3. 계획을 읽고 PRD에 없는 기능이 있으면 "빼 줘" → 괜찮으면 **"계획대로 만들어 줘"**

## ⑤ 실습 B. 1차 내 화면에 공공데이터 API 붙여 보기 (11. 17.(화)까지, 40분)

> 🎯 **목표**: 1차 화면 한쪽에 **공공데이터포털의 실제 대기질 값**을 띄운다. 서비스 키는 화면 코드가 아니라 **Vercel 금고(환경 변수)** 에만 둔다.
> 🧭 **흐름**: 주소창에서 자료 미리 보기 → Vercel 금고에 키 넣기 → Claude Code로 서버 함수·화면 연결 → 결재 → 키가 안 보이는지 확인

> 💡 **내 화면과 관련이 없어도 괜찮습니다.** 운동 기록 · 여행 준비물 화면에 대기질이 어울리지 않아도, 한쪽에 "오늘 우리 지역 미세먼지"를 띄우면 됩니다. **"남의 장부(공공데이터)를 우리 주방(서버 함수)을 거쳐 받아 오는" 연동 자체에 의미**를 둡니다. 당일 산출물도 마찬가지입니다.

### 5-1. 주소창에서 자료 미리 보기 (10분)

1. 활용신청 현황 → 에어코리아 API 상세 화면 → **시도별 실시간 측정정보 조회** 옆 **[확인]**(미리보기)이 있으면 `sidoName` 에 `서울`, `returnType` 에 `json` 을 넣고 실행합니다
2. [확인]이 없으면 아래 주소의 `여기에키` 자리에 **Decoding 키**를 붙여 **내 Chrome 주소창**에서 엽니다 (이 주소는 어디에도 공유하지 않습니다)

```
https://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty?serviceKey=여기에키&returnType=json&sidoName=서울&numOfRows=3&ver=1.0
```

3. 글자 덩어리(JSON)에서 `"resultCode":"00"` 과 `stationName`(측정소), `pm10Value`, `pm25Value`, `dataTime`(측정 시각)을 찾습니다. 이 칸들을 화면에 띄웁니다.

### 5-2. Vercel 금고(환경 변수)에 키 넣기 (5분)

1. **vercel.com** → 1차 프로젝트 → 위쪽 **Settings** → 왼쪽 **Environment Variables**
2. **Key**: `DATA_GO_KR_KEY` / **Value**: Decoding 키 / **Environments**: Production · Preview · Development **모두 체크** → **[Save]**

### 5-3. Claude Code로 서버 함수와 화면 연결 (15분)

**claude.ai/code** → 저장소 `my-tool` → 새 대화에 보냅니다.

```
화면 한쪽에 공공데이터포털 에어코리아의 실시간 대기질을 보여 주고 싶어. 먼저 계획을 알려 줘.
API: 한국환경공단_에어코리아_대기오염정보 / 시도별 실시간 측정정보 조회
요청 주소: https://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty
요청 변수: serviceKey, returnType=json, sidoName=[우리 시도, 예: 서울], numOfRows=100, ver=1.0
보여 줄 값: 측정소 이름(stationName), PM10(pm10Value), PM2.5(pm25Value), 측정 시각(dataTime)

- 서비스 키는 Vercel 환경 변수 DATA_GO_KR_KEY 에 이미 넣어 두었어. 키 값은 묻지 마.
- 브라우저가 공공데이터포털을 직접 부르지 말고, Vercel 서버 함수 api/data.js 가 대신 불러서 필요한 값만 JSON으로 돌려줘.
  함수는 module.exports = async (req, res) => { … } 모양으로, package.json 없이 동작하게 해 줘.
- 키는 함수 안에서 process.env.DATA_GO_KR_KEY 로만 읽고, 응답이나 화면에 절대 넣지 마.
- 함수 응답에 Cache-Control: s-maxage=600 을 붙여 10분 동안 캐시해 줘.
- index.html 은 /api/data 를 불러 한쪽에 작게 보여 주고, 실패하면 "대기질 자료를 불러오지 못했습니다"라고 보여 줘.
- 화면 아래에 출처(공공데이터포털 · 한국환경공단 에어코리아, 측정 시각)를 적어 줘. 기존 기능은 그대로 둬.
- 네 환경에는 키가 없어서 실제 호출 시험은 못 할 거야. 시험하지 못한 것은 못 했다고 알려 줘.
```

계획이 괜찮으면 **"계획대로 만들어 줘"**.

### 5-4. 결재하고 확인 (10분)

1. **Changes** 카드 → **[Create PR]** → GitHub 결재 요청서 → **Vercel 봇 댓글 [Visit Preview]**
2. 미리보기에서 대기질 값과 측정 시각이 보이면 → **[Merge pull request] → [Confirm merge]**
3. 운영 주소를 PC Chrome으로 열고 **F12 → Network** → 목록에서 `data` 를 눌러 **Response** 를 봅니다. 측정값만 있고 **서비스 키가 없으면** 성공입니다.

**✅ ⑤가 끝나면**
- [ ] 화면에 실제 값과 측정 시각, 출처가 보인다
- [ ] Network 에서 화면이 부르는 주소가 `/api/data` 이고, 응답에 서비스 키가 없다

| 막히면 | 해결 |
|---|---|
| 5-1 결과에 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 승인 뒤 반영 전입니다(1시간~하루). 그동안은 5-3 지시문의 요청 주소를 강사 공용 주소 `https://www.jg-sobang.com/api/air?sido=서울` 로 바꾸고 "이 주소를 그대로 불러 줘, 서버 함수는 만들지 마"라고 해서 화면 연결만 먼저 해 봅니다 |
| 화면에 "불러오지 못했습니다" | 5-2에서 Preview까지 체크했는지 → Vercel **Deployments** → 맨 위 배포 ⋯ → **[Redeploy]** (환경 변수는 넣은 뒤 다시 배포해야 반영) |
| `/api/data` 가 404 | 함수 파일이 저장소 맨 위 `api/data.js` 인지. PC에서 index.html 을 더블클릭하면 안 되고 미리보기 · 운영 주소에서만 됩니다 |
| 결과가 XML로 옴 | "returnType=json 으로 요청하도록 고쳐 줘" |
| 키를 실수로 채팅 · GitHub에 붙였음 | 데이터포털 마이페이지에서 키 **재발급** 후 Vercel 값 바꾸기 |
