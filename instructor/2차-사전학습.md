## ③ 웹 서비스의 뿌리, 꼭 필요한 부분만 (11. 17.(화)까지, 50분)

2차에서는 **데이터베이스**와 **공공데이터 API**를 내 화면에 붙입니다. 그 전에 "웹 서비스가 어떤 부품으로 이루어져 있나"를 식당 하나에 빗대어 봅니다.

강의 사이트: **www.jg-sobang.com/ai-literacy/** (AI 리터러시 · 웹 서비스의 뿌리)
원래 2시간 강의지만, **아래 표의 절만** 읽으면 됩니다. 나머지는 관심 있을 때 보세요.

### 먼저 한 장 요약: 웹 서비스 = 식당

| 웹 서비스 | 식당 | 2차에서 만나는 곳 |
|---|---|---|
| **프론트엔드** | 홀, 메뉴판, 주문 태블릿 | 내가 만드는 화면 `index.html` |
| **API** | 홀과 주방 사이의 **주문서** | 화면이 자료를 달라고 보내는 요청 |
| **백엔드** | 주방 | API 트랙의 "우리 주방"(Netlify 서버 함수) |
| **데이터베이스** | 장부 | DB 트랙의 "공용 장부"(Firebase) |
| **환경 변수** | 주방 금고 | API 트랙의 서비스 키를 넣어 두는 곳 |
| **배포** | 가게 개업 | GitHub에 결재 → Netlify가 자동으로 공개 (1차에서 해 봄) |

1차에서 만든 화면은 **홀만 있고, 손님이 각자 수첩에 적는 가게**였습니다. 그래서 짝이 적은 기록이 내 휴대폰에는 보이지 않았습니다. 2차에서는 여기에 **장부**(DB 트랙) 또는 **주방과 거래처**(API 트랙)를 붙입니다.

## ⑥ 선택 연구 (가점 대상, 40~60분)

당일 3교시에 데이터를 붙일 시간(약 25분)이 있지만, 처음 해 보면 빠듯합니다. **미리 한 번 해 본 사람은 당일 훨씬 여유롭게 붙이고, 산출물에 반영하면 가점**을 받습니다. 둘 중 하나만 해도 됩니다.

### 연구 A. Firebase 공용 장부 (약 60분)

**목표**: 1차에 만든 내 화면(`my-tool`)의 기록을, 내 휴대폰과 다른 사람 휴대폰에서 **같이 보이게** 만들어 본다.

1. 1차 강의 **11번 페이지**(www.jg-sobang.com/fire-ai/m11.html, Firebase로 "공용 장부" 연결하기)를 엽니다.
2. **1~4단계**를 그대로 따라 합니다: 프로젝트 만들기 → Firestore(서울, 프로덕션 모드) → 규칙 → 설정값.
   - 3단계 규칙은 페이지의 예시(여행 준비물용)를 그대로 쓰지 말고, 내 화면에 맞게 Claude Code에 초안을 받습니다: "내 PRD.md에 맞는 Firestore 보안 규칙을 써 주고, 각 줄을 PRD 말로 설명해 줘"
3. 5~6단계는 페이지 맨 아래 💡 **"Claude Code로 해도 됩니다"** 방법으로 합니다. claude.ai/code → `my-tool` → "PRD에 맞게 index.html을 Firestore에 저장하도록 고쳐 줘" + 설정값 → [Create PR] → 미리보기 확인 → [Merge].
4. 7단계: 두 휴대폰으로 같은 주소를 열고 한쪽에서 넣은 기록이 다른 쪽에 바로 생기는지 확인합니다.

> ⚠️ 연습용 자료만 넣습니다. 결제 정보·Blaze 업그레이드 안내는 누르지 않습니다. 행정망 PC에서 저장이 안 되면 휴대폰 LTE나 집 PC로 확인합니다.

### 연구 B. 공공데이터 API (약 40분, ② 활용신청이 승인된 뒤)

**목표**: 공공데이터포털에서 실제 자료를 받아 보고, 내 화면에 보여 줄 값을 정한다.

1. data.go.kr → 마이페이지 → Open API 활용신청 현황 → 승인된 API를 엽니다.
2. 상세 화면에서 **상세기능 하나**(예: 시도별 실시간 측정정보 조회)의 요청 변수 표를 봅니다. 화면에 요청 변수를 넣어 바로 실행해 보는 기능(미리보기 또는 [확인])이 있으면 써 봅니다.
   - 없으면 Claude 일반 대화에 요청 변수 표를 붙여넣고 "이 API를 브라우저 주소창에서 JSON으로 불러 보는 주소를 만들어 줘. 서비스 키 자리는 SERVICE_KEY 라고 비워 둬"라고 합니다. 받은 주소의 `SERVICE_KEY` 자리에 **내 키를 직접** 넣어 주소창에서 엽니다. (이 주소는 어디에도 공유하지 않습니다)
3. 나온 글자 덩어리(JSON)에서 내 화면에 보여 줄 값 **3개**와 **측정·기준 시각**이 어느 칸에 있는지 찾습니다. (예: `pm10Value`, `pm25Value`, `dataTime`)
4. **(심화)** 1차 `my-tool` 저장소에서 실제로 붙여 봅니다. Netlify 내 사이트 → Site configuration → Environment variables 에 `DATA_GO_KR_KEY` 로 키를 넣고, claude.ai/code 에 "Netlify 서버 함수가 공공데이터포털을 대신 부르고 키는 process.env.DATA_GO_KR_KEY 로만 읽게 해서, 이 값들을 화면에 보여 줘" + 요청 변수 표 → [Create PR] → 미리보기 확인.

> ⚠️ 서비스 키는 Netlify 설정 화면과 내 브라우저 주소창에만 넣습니다. Claude 채팅·GitHub·메신저에는 넣지 않습니다.

**연구 메모 3줄** (⑤ 폼에 붙여넣기)
