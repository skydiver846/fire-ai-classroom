# PRD: 오늘의 화재 현황 (API 트랙 시연 완성본)

## 1. 한 줄 소개
우리 시도의 오늘 화재 접수 · 진행 중 · 상황 종료 건수를 휴대폰으로 바로 보는 화면.

## 2. 쓰는 사람
- 당직 · 상황 근무 직원 (출근길에 휴대폰으로 확인)
- 교육 담당 (교육 시작 전 오늘 현황 한 줄 소개)

## 3. 해결할 문제
그날 화재 현황을 보려면 여러 사이트를 열어야 하고, 우리 시도 숫자만 빨리 보기 어렵다.

## 4. 핵심 기능
1. 시도를 고르면 그 시도의 화재 접수 · 진행 중 · 상황 종료 건수를 크게 보여 줌
2. 자체 진화 · 허위 신고 · 오보 처리 건수를 작게 함께 보여 줌
3. 기준 날짜와 출처를 화면에 표시
4. 마지막에 고른 시도를 기억 (이 브라우저에만)

## 5. 데이터
- 공공데이터포털 · 소방청_화재정보서비스 · 시도단위 화재발생현황 목록조회 (`getOcBysidoFireSmrzPcnd`)
- 요청 변수: serviceKey, pageNo, numOfRows, resultType=json, ocrn_ymd(YYYYMMDD)
- 서비스 키는 Vercel 환경 변수 `DATA_GO_KR_KEY` 에만 두고, 서버 함수 `api/data.js` 가 대신 부름
- 오늘 자료가 비어 있으면 어제 자료를 보여 줌, 10분 캐시

## 6. 화면
휴대폰 한 화면. 큰 숫자 세 개(빨강 · 주황 · 초록).

## 7. 하지 않는 것
지도, 과거 통계 그래프, 알림

## 변경 기록
- v0.1: 예시 자료로 화면 만들기
- v0.2: 서버 함수(api/data.js)로 공공데이터포털 진짜 자료 연결
